## 2. 实现迭代

### v0.1 · 纯逻辑移植（先行验证）

- 新建 `game_model.gd` + `map_data.gd` + `map_info.gd` + `game_data.gd`；完全用 field px 复刻路径/可建造格/道具/塔/敌人/波次/AI。
- 复刻 `mulberry32`、`hash2`（含 JS double 乘法/ToInt32 行为）与 Fisher-Yates；第一次 headless 对照就得到：灰烬 **559.67s/72 决策/12 塔位完全一致**，冻苔 **443.73s vs 444.75s/61 决策/塔位完全一致**。
- 发现/修复：GDScript `const` 内自引用 class_name 在未导入项目时不可用 → 全部跨脚本改为 `preload` 常量；`Math.hypot` 用 `sqrt` 复刻的亚秒级差异（冻苔 −1.02s）保留并记录。
- 此时 smoke 先只测模型，确保“玩法正确”再动视觉。

### v0.2 · 3D 场景与模型

- `MeshKit` 程序化 box/cyl/sphere/octa/disc/ring/chevron；合并顶点色网格控制 draw call。
- `MapView`：68×52 地形、三层路径 ribbon、磨损石板/边石/3D chevron、8 个阻挡道具、出生门、灯塔、边界岩/枯树、草/碎石 MultiMesh、余烬/霜点粒子；`TowerView` / `EnemyView` / `ProjectileView` / `VFX` 拆分场景。
- `main.tscn`：`SubViewport` 3D 战场 + 自定义自绘 HUD（1280×720 中文），正交 3/4 相机、灯光、雾、接触阴影。
- 修复：Godot 4.6 `SurfaceTool` 无 `get_vertex_count()`（用显式构建，不再依赖计数）；多处 Variant 类型推断错误；3D 暂停层点击被全屏 block 吞掉（block 必须在按钮之前登记）。

### v0.3 · 亮度/材质与视觉可读性

问题：HTML 调色板是给 sRGB 像素显示用的，直接进 PBR 顶点色会暗 3–4 倍；场景像黑屏。

- 方案：`MeshKit.lift()` gamma 0.48 + 饱和度 1.22；地面/路径专用材质（albedo 1.45–1.55、顶点色）+ 方向光/环境光/雾重新调色；地形改用平滑 coarse noise，去掉 1 格棋盘。
- 塔/道具尺寸与对比：塔 1.3×、Boss 1.55×；道具从过大缩到 0.5–0.9×；每个塔/敌人/道具加程序化接触阴影；出生门/灯塔加光束和发光环。
- 相机：47 正交、yaw −11°、pitch −57°，地形向战场外延伸 5 单位，减少黑边。
- 结果：3D 战场从“几乎不可见”变为可读的绿/蓝低模地图；1920 截图可辨认塔、敌人、门、灯塔和路径。

### v0.4 · 性能与 HUD

- Intel HD 6000 上，实时方向光阴影（512/1024）代价约 15–25ms/帧；关掉后 1280 全 HUD 从 ~25 提升到 40–48。
- CJK 系统字体每帧全量 `_draw` 很贵；HUD 改为 10Hz 重绘 + 文本宽度缓存；交互下一步立即重绘。隐藏 HUD 的 3D-only 为 51 FPS。
- 3D 战场按窗口宽度 1–2× 扩：1280 原生，1920 用 1392×1008 再缩放；`FieldBox.stretch=false` 避免 Godot 的“SubViewport 尺寸不可改”警告。
- 最终保留：方向光+环境光+雾+接触阴影默认；实时阴影 `-- --shadows` 可选（文档标注）。
- 早期一次 bench 受其它 worker 的 ffmpeg 载入影响（loadavg 10），最终在 loadavg≈3.0 下记录：1280 全 HUD **39.9/47.6/47.4**，1920 **39.2**，3D-only **51.0**。

## 4. 取舍与已知问题

- **实时阴影默认关**：为了 Intel HD 30fps+；接触阴影+光照+雾保留。`-- --shadows` 可开。
- **截图中的 FPS 低**（3–19）：1920 高分辨率离屏 + PNG 读回 + 共享机器负载，不代表真实游戏；以 bench 为准。
- **Boss 远景辨识度**：Boss 已放大，但在固定大视野中仍不如 Boss 血条显眼；后续美术 pass 可继续加强轮廓/发光。
- **冻苔 −1.02s**：纯 sim 时间差异；决策/塔位/击杀一致。
- **autotest 与整局时间不可直接比**：首波 prep 2.5 vs 5.6 导致 AI 建塔时序分化；整局 09:54 是正常对局。
- **HUD 10Hz**：数字刷新有约 100ms 量化；点击/选择在下一次绘制立即响应。
- **道具/地表低模仍偏简**：程序化初版；T-030 美术 pass 可替换 scenes/materials。
- HTML 版 `index.html` 与其文档 **未改动**。
