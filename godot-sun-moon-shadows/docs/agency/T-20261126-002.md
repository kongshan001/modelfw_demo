## 3. 关键参数

- 太阳：05:00–19:00；`arc=(h-12)/7`；`elev=68·cos(arc·π/2)`；`az=90+arc·90`。
- 月亮：18:30–06:30；最高 52°（00:30）；同向南天弧；颜色 `(0.62,0.75,1)`。
- 影向：`(-arc,0.55).norm`；影长 `H/tan`；`cap=3H`；`knee=0.6·cap=1.8H`。
- 软膝：`knee+span·(1-e^{-(raw-knee)/span})`；硬截开关 `min(raw,cap)`。
- 3 个全局向量：`u_light_dir`、`u_light_color`、`u_ambient_sub`（见 TECH §4）。
- 高度图：640×360 R8（GLES3 无稳定 R16F 的等价 fallback），归一化 160px。
- 夜景：月亮强度 0.55，月影 alpha 0.46；路灯/窗光/萤火 z 44–55 > 影子 z 30。
- 世界 640×360 → 1280=2×、1920=3×；HUD 同一整数倍；Nearest。
- 默认 08:00 / 16× / 播放；影子、软膝、路灯默认开。

## 5. 风险 / 已知问题

1. R8 高度图 256 级，不是 RHalf；视频是单通道高度图，我们按 GL 兼容性用 R8 等价，
   已在 UI/TECH 记录。
2. 并集块高度取 max caster；同一块内高/矮投影体不可分。场景布局避开了
   会在可见区域产生冲突的组合。
3. 阴影为 alpha 混合而非乘法层；探针用开/关影反解 alpha 验证一层覆盖。
4. 交班点主光方向翻转，但强度/alpha 在 19:00/05:00 为 0，随后淡入；太阳/月亮
   仍可同时在天上（有意的天象）。
5. UI 顶部条在 UI 模式会挡住高角度太阳/月亮的一部分；H 隐藏 UI 可看全。
6. 视频月亮 19:12 标签 3°，本工程 19:12 约 9.6°；为 21:00 月影与 00:30 52°
   的取舍，已在 TECH/迭代记录说明。
7. 未实现鼠标悬停高度读数；调试信息集中在 HUD/日志/截图，避免增加复杂交互。
