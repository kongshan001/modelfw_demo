## 2. 实现迭代

### 2.1 模型与数据

- `light_model.gd`：太阳 05:00–19:00，`arc=(h-12)/7`，最高 68°；月亮
  18:30–06:30，`arc=2p-1`，最高 52°；同一 x 扫掠的南天弧。
- 影向 `(-arc, 0.55)`，影长 `H/tan`，3H 上限、60% 膝点。
- 3 个全局量的镜像 + `RenderingServer.global_shader_parameter_set`。
- 验证：smoke 检查 12:00 68°、18:20 10.2°、17:18 25.4°（视频 26°）、
  00:30 52°、22:00 41.3° 等关键点。

### 2.2 场景 / 像素素材

- `pixel_art.gd`：640×360 全部程序化绘制。地面图 640×272，房屋 196×150、
  橡树 124×140、松树 68×124、路灯 30×104、石柱、木桶、灌木、角色、前景草。
- 第一版截图发现：
  1. HUD 垂直面板过高，遮住了房屋；改为“两块天空条 + 底部控制条”，
     UI 不再压住房屋/树/角色；
  2. 前景草画在影子之上，房屋/树的长影被遮没；改为草 z=25（接收影子），
     底部另加 30px 草缘 z=58（遮挡影子），同时保留视频的“高草影”；
  3. 阴影 alpha 0.36 偏淡且偏绿；提高到 0.42–0.46、色相更冷；
  4. 路灯池太弱；灯池/光晕纹理放大，强度随 night 提升，21:00 变成明显的暖池；
  5. 远山松树 Tier 画反（上宽下窄）像城垛；修正为下宽上窄；
  6. 8px 中文用 12px 字体缩小时字形粘连；改用 Fusion Pixel 10px（小字）+
     12px（标题/时钟），UI 全部回到字体原生像素网格。
- 结果：`01_0800_clean` / `03_dusk_clean` / `04_night_2100_clean` 等 1920 截图。

### 2.3 影子几何

- `shadow_builder.gd`：12 个 caster；足迹 + 高度层；每层沿影向偏移
  `L·h/H`；凸包；并集；三角化；单 mesh。
- 检查时发现并集点探测最初优先返回 house+lamp 重叠；增加 preferred
  `["oak","pine"]` 过滤，08:00 找到两棵树的重叠点：
  单影 (459.5,306.5) / 重叠 (505.7,307.9)。
- 08:00 统计：12 个凸包 → 6 块并集，327 顶点；原始面积 38614 → 35982 px²。
- smoke 检查并集块两两面积 <0.25 px²、coverage≤1、顶点高度偏移单调。
- GPU 探针开/关影反解 alpha：单 0.443 / 重 0.431 / 配置 0.444，确认只叠一层。

### 2.4 2.5D 高度图

- `_build_heightmap`：逐像素 `(base_y - y)/160` 写入 R8；按 z 顺序覆盖。
- 屋顶 112px、墙 32px、木桶 32px、树 140px；shader 接收面测试：
  桶影 32 vs 屋顶 112 → 截断；树影 140 vs 地面 0 → 落影。
- 调试：G 高度图、O 遮挡热力、B 网格线框、V 重叠采样；HUD 显示格式/尺寸/
  归一值/遮挡对照/coverage。
- GLES3 不稳定的 RHalf/R16F 未使用；工程与文档明确 R8 fallback。

### 2.5 软膝

- 最初 smoke 在黎明 05:00 抓到一次“月亮主光强度 0.55”的跳变；加入
  04:30–05:00 月影淡出 + 05:00–06:00 日光淡入后修复。
- 黄昏 19:00–20:00 同样淡入；交班点主光方向翻转但影 alpha≈0。
- 曲线图同时画软/硬两条；10/11 截图对比。
- 数值：18:20 橡树 raw 779.2、soft 412.7、cap 420、hard 420；

## 4. 已知取舍

- 高度图 R8（256 级）而非 RHalf；GLES3 稳定优先。
- 并集块顶点色取 max caster 高度；同一块内无法区分高/矮投影体。
- 软膝曲线用 C1 指数，不是视频的二次式；膝点/封顶数值一致。
- 日月不同时作为主光；交班用零强度淡入淡出，天空仍可同时看到两颗天体。
- UI 顶部条在 UI 模式下会遮住高角度太阳/月亮的一部分；H 隐藏 UI 即完整。
- 视频月亮 19:12 标签 3°，本工程约 9.6°；为 21:00 月影与 00:30 52° 的平衡取舍，
  已在 TECH 记录。
