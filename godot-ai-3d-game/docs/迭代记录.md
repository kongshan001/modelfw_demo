## Cycle 4：视频与资产管线记录

- 视频首轮录制发现两个问题：
  1. 1080p PNG 回读期间帧耗增大，`RaceWorld._process` 的 0.05s dt 上限把仿真拖慢，55s 只录到 9.55s 仿真；
  2. 工具侧用 Input 每 0.3s 才更新一次转向，低采样下自动驾驶会撞护栏。
- 修复：新增仅调试/录制用的 `RaceKart.auto_drive`（正常默认 false，仍由真实 Input 驾驶），并把录制完成条件改为“冲线后固定 46 帧”，保证结算画面时长。录制在 20fps 采样下完成整圈，再编码成 10s MP4。
- 又发现追尾相机在世界坐标弹簧下会抄内线穿过车身；改为“平滑朝向 + 固定距离”的追尾支架后，车在整圈和加速时始终保持在镜头内。视频录制期间隐藏 FPS 标签，因为逐帧 PNG 回读会把 Engine FPS 拉到个位数；真实性能由 perf 工具单独记录。
- 资产管线最终结论：Hyper3D 不可用、允许的 Tripo 凭据来源（env/team secret）为空；**0 credits** 消耗。保留 CC0/CC-BY Fox + 全程序化替代，并在 TECH/CREDITS/`assets/ai/README.md` 写明差异与后续接入方法。
