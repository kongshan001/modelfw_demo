## Cycle 4：视频与资产管线记录

- 视频首轮录制发现两个问题：
  1. 1080p PNG 回读期间帧耗增大，`RaceWorld._process` 的 0.05s dt 上限把仿真拖慢，55s 只录到 9.55s 仿真；
  2. 工具侧用 Input 每 0.3s 才更新一次转向，低采样下自动驾驶会撞护栏。
- 修复：新增仅调试/录制用的 `RaceKart.auto_drive`（正常默认 false，仍由真实 Input 驾驶），并把录制完成条件改为“冲线后固定 46 帧”，保证结算画面时长。录制在 20fps 采样下完成整圈，再编码成 10s MP4。
- 又发现追尾相机在世界坐标弹簧下会抄内线穿过车身；改为“平滑朝向 + 固定距离”的追尾支架后，车在整圈和加速时始终保持在镜头内。视频录制期间隐藏 FPS 标签，因为逐帧 PNG 回读会把 Engine FPS 拉到个位数；真实性能由 perf 工具单独记录。
- 资产管线最终结论（Cycle 4，已被 Cycle 5 的 Tripo 接入取代）：Hyper3D 不可用、当时允许的 Tripo 凭据来源（env/team secret）为空；**0 credits** 消耗。Cycle 4 保留 CC0/CC-BY Fox + 全程序化替代，并在 TECH/CREDITS/`assets/ai/README.md` 写明差异与后续接入方法。

- 目标（T-20261125-002）：用户追加“真实感汽车”。用 Tripo H3.1 生成原创无品牌跑车，替换 P2 卡丁车车体，保留玩法/相机/性能；Tripo 余额 **65**，不得超预算。
- 预算比较：H3.1 image-to-model 在 face_limit=20k/50k/100k 下，`--for game-pc` 为 40 credits 但 pbr=false 且链一个 FBX convert；显式 PBR + detailed 同为 40 且直接 GLB；standard + PBR 为 30。选显式 100k + PBR + detailed = 40，余额 **65 → 25**；未充值、未超预算。
- 参考图：新增 `tools/blender/realistic_car_refs.py`，用 Blender 3.4.1 从零建模一台无品牌双座跑车（loft 截面车身、boolean 轮拱/座舱、风挡扫掠框、灯/镜/扩散器/排气/尾翼），Cycles CPU 渲染 1024² 的 front/side/3q/rear3q + 2×2 多视图。刻意**不画车轮**，轮拱留空；输入 Tripo 的是 `realistic_car_3q.png`。没有使用真实车照片、车标、参考视频或第三方素材。
- 生成：H3.1 (v3.1-20260211)，task `856e0f6e-f6aa-49ff-bdd5-c056c3d662ff`，face_limit=100000、texture=detailed、pbr=true，源 **94,256 tris**，40 credits；直接交付 GLB，无 convert/失败/重试。
- 降面：Blender 3.4.1 Decimate（COLLAPSE，ratio 0.318，use_collapse_triangulate）→ **30,000 tris**；脚本 `tools/blender/decimate_car.py`。Blender 重新导出 GLB 后，Godot 抽出的 Color/ORM/NormalGL 贴图与源文件同尺寸，PBR 材质完整保留。
- 贴图：源 PBR 三张 4096²；Godot 导入 `.import` 设 `process/size_limit=2048`，并修正法线贴图 `compress/normal_map=1`，降低 Intel HD 的带宽/内存。
- 接入：
  - 源 AABB 1.0 × 0.2749 × 0.5178m（长×高×宽，车头 +X）→ 3.25 × 0.95 × 1.80m；scale `(3.25, 3.4557, 3.4762)`，`rotation.y=+90°`，offset `(0, 0.595, 0)`（车底离地 0.12m）。
  - 程序化轮组升级：20 边形轮胎 r=0.345m/宽 0.24m + 深色轮辋 + 银色轮圈/5 辐条 + 车队色中心盖；轮距 ±0.735m、轴距 ±0.95m。前轮转向 pivot 和所有轮 spinner 的滚动逻辑不变。
  - Fox 驾驶员 `(0,0.80,0.42)`、围巾 `(0,1.10,0.64)`、方向盘 `(0,0.86,0.10)`；boost 尾焰/尾灯/尾旗移到车尾；缺 GLB 仍回退 `ProceduralBody`。
  - 新增 `shaders/tripo_car.gdshader`：保留 base color + ORM（G=roughness / B=metallic）+ NormalGL，只把高亮度中性漆面重着成车队色；用饱和度蒙版保护红尾灯/蓝玻璃，用亮度蒙版保护头灯。三辆车共用 GLB。
- 视觉问题与修复：
  1. **轮圈/辐条看不见**：实心轮胎圆柱的侧面盖住了轮圈；把轮辋/轮圈/辐条/中心盖移到轮胎外侧面，轮胎变成黑色胎侧 + 银色轮心。
  2. **尾灯像发光方块**：把尾灯从 0.18×0.08×0.04 改成 0.22×0.05×0.022 的细条，发光强度 0.9→0.55，贴合车尾。
  3. **红尾灯被车队色染掉**：车漆蒙版只按亮度，红色尾灯亮度够高被误染；加入 `sat` 蒙版（饱和度高的像素保留原贴图）。
  4. **贴图过大/法线导入设置不对**：4096→2048，normal map 按法线导入；视觉不变，显存/带宽下降。
  5. **94k 高模**：decimate 到 30k，轮廓/轮拱/UV 保留；三辆车合计 90k，不再用原始 282k。
