# Credits / 资产与许可

## 项目

**雾屿守望 / Mistbound Watch** — 原创极简实时岛屿防守 vertical slice。

- 引擎：Godot Engine 4.6（MIT License）。
- 代码、程序化模型、地形、贴图纹理、UI、粒子、文字编排：本项目原创，随项目代码。
- 无第三方运行时库。

## 美术与音视频

- **未使用任何外部 2D/3D 模型、贴图、音频或动画。**
- 士兵、敌人、房屋、登陆艇、树木、岩石、草地、栅栏、栈桥、箭矢、选中/射程环均由 `scripts/models.gd` 在运行时用基础几何体合并生成。
- 水面泡沫、接触阴影、软粒子纹理、烟雾/火灾同样由代码即时生成。
- 视频使用 FFmpeg 编码；FFmpeg 只在构建机使用，不是本项目的运行时依赖。

## 字体

通过 Godot `SystemFont` 调用系统字体，不随项目分发字体文件：

- PingFang SC / Hiragino Sans GB / Noto Sans CJK SC / Microsoft YaHei / WenQuanYi Micro Hei / sans-serif。
- 若目标机器缺少上述 CJK 字体，中文可能回退或显示方框；发布版建议另行引入 OFL 许可的 CJK 字体。

## 玩法参考与原创声明

- 设计参考：B 站视频 `BV1GTyLzfE96`（《1w＋93%好评！8年前的宝藏游戏出DLC了？》，UP 以子OvO，14:11），其中演示的游戏《迷雾北境》的极简实时岛屿防守类型。
- 仅研究其抽象机制：分队实时布防、海上登陆、房屋防线、兵种克制、永久死亡、倍速。
- **未使用 Bad North / 迷雾北境 的名称、角色、阵营、UI、美术、音频、关卡布局、商标或任何原游戏素材。**
- 本项目全部命名均为原创：雾屿守望 / Mistbound Watch、青崖岛、暮火湾、苔盾队、风弦队、潮枪队、海掠者、潮汐首领等。
- 所有岛屿布局、数值、文案与视觉均由本项目设计。
