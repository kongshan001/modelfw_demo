## 关键参数

- 逻辑 1280×720，GL Compatibility；真实 GPU 1920×1080 通过 SubViewport 输出。
- 小队 3 × 4 人；盾卫 74HP / 2.6m，弓手 34HP / 15.5m，矛手 48HP / 3.35m。
- 克制 ×1.8 / ×0.62；高度 +20% / -15%；盾卫/重盾挡箭 50%；首领 35%。
- 房屋 150 HP；3 座/岛；全毁或全队阵亡失败。
- 岛 1：3 波（5 / 7 / 11 敌）；岛 2：4 波（6 / 8 / 12 / 17 敌，含潮汐首领）。
- 布防 20s，波间 8s，登陆艇 3.1s 靠岸，每 0.55s 投放 1 人，每艇 ≤5 人。
- 永久死亡：成员阵亡永久减员；整队阵亡本岛不可复活；下一岛仅幸存队补员。
- 相机：正交，yaw -38°，pitch 50°，size 18–62；WASD/中键平移、Q/E 旋转、滚轮缩放。
- 输入坐标通过 `Viewport.get_final_transform().affine_inverse()` 归一化到 1280 逻辑空间，HUD 与相机共用，支持非 16:9 letterbox。
