# 技术说明 · 雾屿守望 / Mistbound Watch

## 1. 引擎与呈现

- Godot **4.6.stable**，`gl_compatibility`（Mobile/Vulkan 兼容目标下的低配路径）。
- 项目逻辑画布 **1280×720**，`canvas_items` + `keep` 拉伸；真实 1920×1080 通过 SubViewport 截图/录像，3D 与 HUD 均以 1080p 渲染（HUD 使用 1280×720 逻辑覆盖层）。
- 无外部运行库、无外部模型/贴图/字体包；字体通过 `SystemFont` 调用系统 CJK 字体。
- 60 FPS 目标；本机 Intel HD 6000 实测 1280×720 **43.9 fps**，1920×1080 **31.4 fps**（600 帧平均，见 `docs/fps.txt`）。

## 3. 状态机

### 3.1 单局

```
intro --开始布防/空格--> playing --波次全清--> victory --登船--> 下一岛 playing
                                |--房屋全毁/全队阵亡--> defeat --重新布防--> playing
                                |--R/暂停面板重开--> playing (island 0)
victory/defeat --重开本局--> playing (island 0)
```

- `intro`：相机缓慢环绕，HUD 只显示原创开场页与开始按钮；不推进模拟。
- `playing`：固定步长 1/60 模拟；`paused` 仅冻结模拟，相机与 HUD 可操作。
- `victory` / `defeat`：模拟停止，显示结算与重开/下一岛按钮；所有世界点击被 HUD 拦截。
- 胜负互斥，`_end_run` 只允许从 `playing` 进入一次。

### 3.2 波次状态

`wave_state ∈ {prep, active, done}`

- `prep`：倒计时 `prep_timer`；初始 20s，波间 8s。
- `active`：从波次数据创建登陆艇（每艇 ≤5 人），逐步登陆；当 `boats.is_empty() && enemies.is_empty()` 时视为清空。
- 清空第 1/2…波后 `waves_cleared += 1`，进入下一波 `prep`；
- `waves_cleared >= waves_total` 后 `done` + 胜利；
- 岛 1 三波，岛 2 四波。

## 4. 输入与选择

- 鼠标在世界内的**左键按下/拖拽/释放**由 `game._input` 优先处理；坐标通过 `Viewport.get_final_transform().affine_inverse()` 从窗口原生坐标归一到 1280×720 逻辑坐标。这样：
  - 相机 `unproject_position` 与 HUD 使用同一逻辑坐标；
  - 非 16:9 窗口的 letterbox 也能正确命中；
  - 卡牌/按钮/面板区域先查询 `hud.is_blocking_point()`，避免世界选择抢 UI。
- 点选：比较每个存活成员/小队中心的屏幕距离；拖框：将屏幕位置在框内的整队选中。
- 右键：屏幕射线与高度场迭代求交，再夹到最近可行走 AStar 点；多队时沿相机右向量排开。
- 1/2/3：选中并平滑聚焦；Space 暂停；T 1×/2×；Q/E 旋转；滚轮缩放；WASD/中键平移；R 重开；Esc 暂停。
- 暂停/开场/结算时，HUD 拦截所有世界点击；`label` 与按钮均可正常响应。
- 交互探针：1280×720 全 15 项通过（开始、卡片、右键移动、数字选队、暂停/继续、T、滚轮、框选、R）。详见 `verification.txt`。

## 5. 岛屿与地形

### 5.1 高度场

- 确定性 `FastNoiseLite` + 径向平滑阶地：中心高地 7.2/7.9m，外缘沙滩降到水面以下。
- 水面 `WATER_LEVEL = 0.55`；外缘 `rr > 1` 时快速降到海床。
- 岛 1：`seed 31415`，半径 40；岛 2：`seed 90210`，半径 43，中央三峰，布局与房屋/登陆角度不同。

### 5.2 地形网格

- 以 2.0m 步长、54m 半径生成手工三角网格（~5.8k tris），每个三角形独立法线/顶点色，形成 flat-shaded low-poly。
- 颜色按高度/坡度：湿沙、沙、草低/草高、岩壁、路径土色；路径由登陆点→最近房屋、房屋之间的线段距离染色。
- 地形材质关闭背面剔除（`CULL_DISABLED`，避免手写三角绕序问题），无外部贴图。
- 水面：`PlaneMesh` + 自定义 spatial shader，渐变、移动色带和近岸泡沫；白色泡沫合并为两圈带状网格，位于真实水线。
- 植被/岩石/草/栅栏/栈桥合并为 1–2 个静态网格，控制 draw call；每个树/石有暗色接触阴影，单位/房屋另有半透明 blob 阴影，弥补兼容渲染路径下的阴影缺失/过弱。

### 5.3 登陆点与房屋

- 登陆点由 `landing_angles` 从海侧向内扫到水线，再向内退到可行走坡度；记录 `pos / shore / boat / outward`。
- 房屋位置优先使用数据坐标，坡度 < 0.34、高于水面 2.4m、彼此 >5.5m；房屋周围 2.7m 的 AStar 节点被屏蔽，防止单位穿屋。
- 房屋节点带 150 HP、窗户自发光、暖光、烟囱/火灾粒子、世界空间 HP 标签。

## 6. 导航与小队

- AStar3D：2m 网格、八邻接、八方向对角要求两侧正交点可通行、高差 >2.4m 不连边。
- 路径先取 AStar 点，再做 1m 采样的贪心直线平滑；目标点若不可达会夹到最近点。
- 小队中心沿路径以兵种速度移动；4 名成员在本地 2×2 编队，按地形高度贴地并做行走 bob。
- 每名成员独立攻击冷却；索敌用平面距离，进入射程自动攻击：
  - 近战立即结算伤害 + 刀光/火星；
  - 弓手生成箭矢投射物，目标位置逐帧追踪，到达后结算。
- 成员 HP 独立；成员阵亡隐藏模型与接触阴影；全队阵亡 → `alive=false`、不可再选中、本岛不可复活。
- 下一岛仅携带存活队伍，并把成员补满至 4 人；整队阵亡不会被补回。

### 7.2 伤害管线

```
damage = base × counter × height × ranged_resist
height = 1.20 if 攻方高 ≥1.5m; 0.85 if 低 ≥1.5m; else 1.0
ranged_resist：盾卫 0.5；重盾蛮兵 0.5；潮汐首领 0.35；其余 1.0
```

- 飘字：`克制 ×1.8` / `被克 ×0.62` / `盾挡` / `居高` / `仰攻`，按目标 0.9s 节流，避免刷屏。
- 房屋伤害使用敌人 `damage × house_mult`：海掠者 1.0、重盾 1.6、掷斧 0.6、首领 2.0。

## 8. 敌人与波次

- 每个敌人独立 AI：优先索敌（近战 7.3m / 远程 12m 内最近成员），否则寻路最近未焚毁房屋；距房屋 ≤3.15m 时攻击房屋，房屋全毁则重选。
- 登陆艇从海侧 15m 外出发，3.1s 靠岸，每 0.55s 投放一人；靠岸点向栈桥两侧偏移，避免与码头重叠。
- 波次船按编组拆分，每艇 ≤5 人，级联延迟 1.35s，形成连续登陆压力。
- 波次编排（`balance.gd`）：
  - 岛 1：5 海掠者；5 海掠者 + 2 重盾；6 海掠者 + 2 重盾 + 2 掷斧 + 1 首领。
  - 岛 2：6 海掠者；6 海掠者 + 2 重盾；7 海掠者 + 3 掷斧 + 2 重盾；8 海掠者 + 4 重盾 + 4 掷斧 + 1 首领。
- 敌人之间做简单 0.82m 分离；不会穿水，按地形可走性滑动。

## 9. 相机

- 正交 Camera3D，默认 yaw -38°、pitch 50°、size 46；范围 18–62。
- `pivot` 使用**地形高度**而非 y=0，使画面中心对准地面（早期问题：pivot 在 0 导致地面整体偏上）。
- WASD 在相机水平面平移；Q/E 连续旋转；滚轮指数缩放；中键按像素平移；空闲时平滑插值。
- 屏幕射线：`project_ray_origin/normal` 沿射线以 1.2m 步进找与高度场交点，再做 8 次二分细化；用于点选/右键移动。
- 受击时轻微 camera shake（房屋焚毁更强）。

## 10. HUD 与视觉

- 原创海雾青 + 米白 + 琥珀色板；没有使用原游戏 UI 结构或图标。
- 顶部：品牌/岛名、房屋防线（3 个图标与 HP 条）、波次/倒计时/剩余敌人、暂停/倍速。
- 底部：3 张队伍卡（热键、兵种图标、人数点、HP、状态），点击卡片选中并聚焦；右侧操作/克制提示。
- 世界内：选中环、弓/矛射程环、敌人 HP 条、房屋 HP 标签、克制/高差飘字。
- 开场、暂停、胜负结算均为独立覆盖层；按钮走统一 `MistUI` 样式。
- 低模角色由盒/柱/球/锥合并为单一顶点色表面，独立兵种轮廓（盾/弓/矛/首领旗）。

## 11. 性能

- 全部程序化网格；地形 1 draw、植被/岩石 1、草 1、泡沫 2、水面 1；单位/房屋/船/箭各自合并；HUD 为 draw 调用为主。
- 无 MSAA/TAA；1 个主方向光 + 1 个无阴影补光；2 分裂方向阴影，最大距离 72m；避免后处理。
- 软粒子纹理由代码生成；房屋烟雾/火灾仅在需要时增加粒子；FX 总效果上限 140。
- 实测（600 帧平均，真实 GPU，见 `docs/fps.txt`）：
  - 1280×720 **43.9 fps**
  - 1920×1080 **31.4 fps**
  - GPU：Intel HD Graphics 6000（OpenGL 4.1 Compatibility）
- 1920×1080 截图为 SubViewport 真实渲染；本机系统窗口把请求的 1920 限制为 1440×762，因此交互测试以 1280×720 与 1440 窗口补充验证。

## 13. 已知限制 / 设计取舍

- 无声音与存档；无手柄映射；无建筑/招募/道具系统（保持 vertical slice 范围）。
- 无真实物理：单位贴合程序化高度场，移动靠 AStar + 手动可走性判断；单位之间只有小队内编队，行走中不做软碰撞（敌人之间有简单分离）。
- 远程攻击不做视线遮挡（可穿过房屋/山丘命中）；高差只简化成伤害倍率，不改变射程。
- 地图为两张手工 seed 的确定性岛，不是无限 roguelite；无 DLC/无尽模式。
- 兼容渲染路径下地面投影阴影较弱，因此使用暗色接触阴影补足；未做屏幕空间 AO。
- 合成输入测试在非 16:9 的 1440×762 窗口中，最顶部暂停按钮的合成点击有 1 项落点偏移；真实 1280×720 鼠标点击 15/15 通过，Space 暂停与暂停面板继续均通过。输入本身按 `final_transform` 归一化，真实鼠标不受该合成偏移影响。
- 系统字体依赖平台；在无 CJK 字体的机器上会回退到 sans-serif 并可能出现方框，需要自行提供字体。
