### 1. 骨架与数据层

- 新建 `godot-island-defense/`：Godot 4.6、GL Compatibility、1280×720 逻辑画布、无第三方运行库。
- 先落 `balance.gd`（唯一事实来源）与 `ui_style.gd`（系统 CJK 字体 + 原创色板）。
- 程序化模型：盒/柱/球/锥/环合并为顶点色单材质，减少 draw call；加入软粒子纹理、低模房屋、长船、树木、岩石、栈桥。
- 早期问题：
  - 新项目首次 headless 运行时 `class_name` 跨脚本未注册，改为显式 `preload`，避免依赖全局类缓存。
  - 若干 GDScript 类型推断错误（来自 Dictionary/Variant 算术），逐处显式标注。
  - 模型材质 Godot 3 遗留属性 `specular` 触发警告，改用 `metallic_specular`。

### 2. 岛屿 / 相机 / 导航

- 高度场 + 手写三角网格 + 顶点色；海岸、沙、草、岩壁、路径土色；水面 shader + 泡沫带。
- AStar3D 2m 网格、房屋 2.7m 障碍、直线平滑；登陆点由水线扫描产生；房屋选址检查坡度/高度/间距。
- 正交相机：WASD/中键平移、滚轮缩放、Q/E 旋转；屏幕射线迭代求高度场交点。
- 发现并修复：
  - 登陆点初版取“水面上 0.32m”导致落在过高的滩地；改为先找水线，再向内退 1.6m 找可行走沙滩。
  - 相机 `pivot` 固定在 y=0，导致地面整体出现在画面偏上；改为使用地形高度。战斗/房屋截图随之居中对齐。
  - 登陆艇在靠岸后继续 `look_at` 相同位置，反复报错；加水平距离守卫。
- 码头初版是一串分离木板，视觉上像漂浮；重做为连续甲板、横板缝、护栏和系缆桩，登陆艇靠岸点向栈桥两侧偏移，避免重叠。

### 3. 小队 / 战斗 / 永久死亡

- 3 队 ×4 人：盾卫/弓手/矛手；编队、贴地、bob、独立冷却、自动索敌、近战立即结算、弓手箭矢、成员阵亡、全队阵亡永久损失。
- 克制三角 + 高差 + 盾卫/重盾远程减伤在 `compute_damage` 中统一；飘字显示“克制 / 被克 / 盾挡 / 居高”。
- 早期问题：
  - 全模型受击红色闪烁在持续受击时让首领变成大块红色剪影；改为受击轻微缩放脉冲 + 火星，不再整体换材质。
  - 世界飘字字号过小；调整为 32 号、世界尺度放大，并降低节流频率。
  - 房屋标签过小；改为“房屋 HP / 150”，放大并随血量变色。
- 敌人：海掠者/重盾/掷斧手/潮汐首领；优先索敌或在 3.15m 内烧屋；简单分离避免完全重叠。

### 4. 波次 / 输入 / 结算

- 3 波（青崖岛）+ 4 波（暮火湾），登陆艇逐名投放，波间 8s，布防 20s；房屋全毁或全队阵亡失败，三波清空胜利。
- 交互：
  - `_input` 处理世界鼠标选择，使用 `Viewport.get_final_transform()` 把窗口原生坐标归一到 1280 逻辑坐标；HUD 面板/卡片/按钮先用 `is_blocking_point` 排除，避免抢 UI。
  - 左键/拖框、右键移动、1–3 选队、Space 暂停、T 1×/2×、Q/E 旋转、滚轮缩放、WASD/中键平移、R 重开。
  - 发现并修复：HUD 卡片按下被 UI 消费后，世界只收到左键释放，旧逻辑会立刻清空选择；改为仅当游戏自己启动了拖拽才在释放时结算。该问题由真实窗口输入探针复现；修复后 15/15 通过。
  - 真实窗口输入探针还暴露了测试脚本自身的时序问题（异步拖拽未 await、合成鼠标释放的缓冲顺序），修正测试脚本后才得到可信结果。

### 5. 视觉与性能打磨

- 初版环境光+曝光过亮，地形几乎与背景融在一起；降低环境光、调整 filmic 曝光/对比/饱和，改用更深的草/沙/水色板，加入接触阴影。
- 连续调试中发现：把材质临时替换为纯色/无光照版本可确认地形几何本身正确；最终通过整体光照与色板调整解决“画面发白”的问题。
- 地形材质在首次 1920 截图时出现过淡出；截图工具增加 20–30 帧预热并复跑后稳定，游戏内未复现。
- 加入软圆粒子纹理、烟囱轻烟、房屋火灾、栈桥、房屋山墙、窗户木框、接触阴影、选中环与射程环。
- 将登陆艇容量从 4 提高到 5，减少单波船数，改善登陆画面与性能。

### 6. 平衡观察（非正式自动测试）

- 使用临时脚本（未交付）做简单“追击最近敌人”的自动防御，模拟 3 波：约 82.8s 内清空三波胜利，击杀 23，剩余 2/3 房屋、2/3 小队；过程有队伍被全灭、房屋被焚毁。
- 说明无微操也能勉强守住，人类玩家通过暂停、站位、克制与高地应更从容；难度落在可玩区间，但仍需要正式的人机 playtest。
