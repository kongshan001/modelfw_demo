## 1. 模型 / 骨骼 / 蒙皮 / 动画清单

### 资产

| 项 | 值 |
| --- | --- |
| 工程 | `blender-wukong-ultimate/wukong_ultimate.blend`（7.7 MB） |
| 游戏资产 | `blender-wukong-ultimate/wukong_ultimate.glb`（3.17 MB，Godot 内 md5 一致） |
| 比例 | 英雄比例，约 6.5 头身；含发高 2.26 m，脚底 y=0 |
| 网格 | 单一蒙皮网格，56,072 tris，约 28.6k verts |
| 材质/贴图 | 15 材质分区；5 张程序化贴图（橙布/蓝布/银发/银毛/金）；肌体带顶点色 |
| 渲染 | `docs/poster_front.png` / `poster_charge.png` / `poster_cast.png`（1920×1080，Blender 3.4.1 EEVEE，40 samples） |
| 对比图 | `docs/before_after.png`（1920×540，首版海报 vs 极意蓄力定帧） |

**造型要点**：银白后掠尖发（分片、发根到发梢渐变）、银白斗气 + 浮空碎石、赤膊肌肉躯干、破损橙裤、蓝腰带/护腕/靴、金箍/金饰/背棍、猴脸/尾巴、蓝色眼纹。原创五官与比例；无《龙珠》悟空的脸型、发型轮廓、服装/标志。

**建模管线**：肌体用肌肉体块的 union → Voxel Remesh（0.009）→ Smooth ×3 → Decimate 到目标三角面；服装/发片/尾巴/金箍棒用自定义 ring-tube / flat blade / ribbon 网格；显式按骨段距离权重 + rigid 配件权重。纹理为 Python 生成并 pack 进 .blend、嵌入 GLB。

### 骨架与蒙皮

- `.blend`：41 骨（可继续用 IK 编辑）
  - 29 根导出骨（root + 28 变形）：hips/spine/chest/neck/head/jaw；肩/上臂/前臂/手 ×2；大腿/小腿/脚/趾 ×2；tail1–4；sash.L/R。
  - 12 根非变形控制骨：ctrl_hand/elbow/foot/knee/hand_aim/foot_aim ×2。
- IK：手臂/腿各 2 骨 IK + pole；手/脚 Copy Rotation 控腕/踝；导出前逐 action `visual_keying` 烘焙，删除约束和控制骨，GLB 为纯 FK。
- 蒙皮：显式顶点组 + Armature；body 按最近 2 骨段距离权重，布料按区域骨骼权重，配件 rigid；顶点组归一。
- 修复过一处根因：基元对象位置未 apply，join 后顶点局部坐标与骨骼世界坐标错位 1.36 m，导致裤腿被藏进大腿；改为 apply location + world-space 权重后恢复。

### 动画（GLB）

| Clip | 时长 | 用途 |
| --- | --- | --- |
| Idle | 2.000 s | 待机呼吸/尾巴摆 |
| Run | 0.667 s | 原地跑循环 |
| Charge | 1.333 s | 胸前聚气、蓄力颤抖 |
| Cast | 1.208 s | 双手前推放波 |
| Hit | 0.542 s | 受击后仰 |
| Victory | 2.000 s | 起身举拳 |

- Blender 24 fps 编辑，逐帧 bake；所有 clip 从 0 s 开始（导出前关键帧整体 −1 帧），Godot 导入长度精确。
- Godot `AnimationPlayer`：6 clips、26 tracks/clip；Idle/Run/Charge 循环，Cast/Hit/Victory 单次。

## 2. Godot 可玩展示：操作与验证

### 运行

```bash
cd godot-wukong-ultimate
godot --headless --path . --editor --quit
godot --path . --resolution 1280x720
```

### 操作 / 规则

- WASD/方向键：相机相对移动；鼠标拖拽环绕，滚轮 3.2–8.6 m。
- 长按空格蓄力（1.15 s 满），松开放气功波；伤害 `30+90×power`，耗气 `22+28×power`，气回复 12/s。
- 石傀 240 HP；每 6.6 s 可能蓄力红圈脉冲（1.15 s 预警、半径 3.4 m、14 伤害），可走位躲开；命中玩家播放 Hit。
- 命中：扣血、视觉击退、橙色爆炸/碎石/火花、屏幕震动、伤害数字、连击（2.4 s 窗口）。
- 石傀 0 HP → 崩塌、Victory 动画、结算（用时/最高连击/命中数）、R 重置。
- 玩家 0 HP → 力竭结算；R 重置。
- HUD：气血/气/蓄力、石傀血条、连击环、红圈警告、教学、胜负面板；全部自绘，无外部 UI 素材。

### 已验证（headless）

```text
WUKONG_ULT_READY bones=29 clips=["Cast", "Charge", "Hit", "Idle", "Run", "Victory"] sentinel_hp=240
SMOKE_COMBAT hp=120 hits=2 combo=2
SMOKE_PULSE player_hp=86 clip=Hit trauma=0.64
ULT_VICTORY time=5.27 hits=3 max_combo=3
SMOKE_VICTORY victory=true max_combo=3
ULT_RESET OK
WUKONG_ULT_SMOKE_OK
```

覆盖：

- GLB 结构：29 骨、6 clip、Idle 起始、track 数 >10；
- 真实 InputMap：W 前进 >0.35 m，动画进入 Run，松开回 Idle；
- 蓄力→Charge clip→释放→Cast clip；
- 蓄力释放气功弹命中石傀；脚本弹定向造成 120；
- 石傀脉冲命中玩家 → HP 100→86、Hit clip；
- 石傀归零 → victory、Victory clip；
- reset → 满血/回 Idle/石傀重置。

其它：

- `godot --headless --path . --quit-after 600`：exit 0，无 SCRIPT ERROR；
- `bash tools/verify.sh`：退出 0，打印 `WUKONG_ULT_SMOKE_OK` / `WUKONG_ULT_VERIFY_OK`；
- 真实 GPU 截图 7 张（含光束在飞）；GIF/MP4 8.0 s；FPS 达标（见下）。

## 5. 风险 / 限制 / 下一步

### 工作区说明

- 本任务只写入 `blender-wukong-ultimate/` 与 `godot-wukong-ultimate/`；未触碰 `blender-wukong/`、`godot-garden/`、`docs/task-plans/`。
- `git status` 中 `godot-battle/` 的若干既有修改/未跟踪目录是任务开始前就存在的工作区状态，与本任务无关，未做改动。

### 风险与限制

1. **美术边界**：风格化程序化角色，不是影视级雕刻；肩背/躯干有少量体素块面感，手指简化，无面部 blendshape、无布料/毛发模拟。静态截图表现优于极限特写。
2. **性能短时抖动**：多轮 avg 39–43 > 30，但压力测试 `min` 低至 11–22（命中爆发的瞬时掉帧）；VFX 每次命中新建材质/粒子/灯光。需要时可做对象池与粒子降级。
3. **画质妥协**：为 Intel 集显关闭实时阴影（blob 阴影）、环境 glow、使用 0.9 3D 缩放；高端 GPU 可恢复阴影/glow/1.0 缩放。
4. **玩法边界**：单场地 Demo，无音频、触控、设置/存档；石傀击退为视觉回弹，非刚体推挤。
5. **字体**：中文 HUD 依赖系统 CJK 字体（PingFang/Hiragino/Noto CJK/雅黑）；缺字体环境会回退，可能显示不全。
6. **首次入场**：有一个很小银色闪光用于 shader 预热，非 bug。

### 下一步建议

- VFX 对象池 + 预实例化，消除命中短时掉帧；
- 可选高画质档：恢复阴影/glow/1.0 缩放；
- 增加音频（蓄力 loop、放波、命中、崩塌、UI）；
- 增加第二段敌人行为/阶段与手柄/触控；
- 若外放：把当前“训练场”扩展成 3–5 分钟关卡，并补设置/暂停/重开 UI。
