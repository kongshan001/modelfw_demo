## 2026-11-25 · 2D 阴影失败与隔离实验

- 第一版使用标准 `LightOccluder2D`：
  - 真实 GPU 日志无错误，遮挡体数量/遮罩/多边形都正确；
  - 方向光和点光都没有任何阴影；
  - 关闭后处理、把环境光压到 0.16、方向光加到 2.2 仍无阴影。
- 隔离最小场景（Sprite2D 地面 + 4 个立柱遮挡体 + PointLight2D + 双向绕序 + Camera2D）：
  - GL Compatibility：无阴影；
  - Vulkan Mobile：同一场景立刻出现平行长影（影向随光角）。
- 结论：目标机 GL Compatibility 的 2D Light2D shadow 路径不出图；不是场景配置问题。
- 方案：
  - 保留 LightOccluder2D + shadow_enabled 的真实阴影代码；
  - 用 `RenderingServer.get_rendering_device() != null` 判断；
  - GL 下运行时生成“沿光向压扁的剪影 sprite”投影；
  - Vulkan 下自动隐藏剪影，启用真实 2D 阴影。

## 2026-11-25 · 长影第二版

- 先尝试凸包多边形投影：能证明方向随光角变化，但影子像巨大的几何色块，
  树冠/屋顶外形完全丢失，且长度过大。
- 改为 texture-shear 投影：以原始 sprite 作为剪影，沿光方向做仿射压扁，
  底边锚在物体脚下；保留树冠/屋顶/人物外形。长度降到 56–128px，透明度降到 0.38/0.30。
- 结果：
  - 树影可辨认出树冠，房影可辨认出屋顶；
  - 光方向 -38° ↔ +38° 时影子整体换向；
  - 农夫行走时影子随位置/朝向更新；灯笼有细长影。

## 2026-11-25 · 视觉第三版

- 近景：底部左右前景草叶剪影（不透明度低的深绿），配合移轴形成景深框。
- 中景：加稻草人（带独立遮挡体/长影）、木栈桥、灌木、干草捆、踩实土院。
- 远端：改动林带为渐变 + 小尺度树冠剪影 + 晨雾，删掉规则的“圣诞树三角形”
  和竖直黑线（后者在第二次截图中仍可见）。
- 水面：减少横向白条，glint 阈值提高，避免像雨点/泳道线。
- 夜灯：缩小 glow、降低窗光，保留暖色点光 + 萤火 + 蓝夜环境。
- 字体：最初使用系统 fallback；后改为 Noto Sans SC SIL OFL 子集，中文 HUD
  在 1920 截图中可读且不受移轴影响。
