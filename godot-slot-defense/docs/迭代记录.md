# 迭代记录 — Reelward / 转轮守卫

## 2026-11-19 · 第 1 轮：Godot 版老虎机自动战斗 vertical slice

**参考**：Slotbound（转运军团）公开演示的玩法循环——老虎机转出单位、单位自动守线、
波次之间用商店改变转轮概率。本工程为 **Godot 4.6 净室实现**：名字、符号、角色、
数值、UI 布局、文案、代码与全部图形/音效均为原创，未复制对方素材与品牌。

### 本轮实现

- **3×3 转轮**：3 行 × 3 列、8 条赔付线；拉杆 / `SPIN` 按钮 / `SPACE` 均可旋转，
  每次 2 金币；每列错峰停下，滚动中符号快速切换并有轻微上下抖动。
- **6 个原创符号**：剑/弓/盾/马/球/冠，每个都是运行时 `Image` 逐像素绘制的
  16×16 图标（放大 4.5 倍显示）。3 连召唤或升级；2 连 1 金币；Crown 万能且
  3 Crown 直接升级；多线同时结算。
- **seeded RNG**：同一 seed 的转轮序列完全可复现（纯逻辑层与游戏层都验证）。
- **单战线自动战斗**：5 个格位，角色偏好格位（弓/球后排、剑中前、盾/马前排）；
  5 种单位各自攻击节奏与射程；敌人从右侧推进，接触前排后近战互殴，漏怪扣心。
- **5 波 + 1 Boss**：固定出现表 + 血量/伤害随波次缩放；Boss 齿轮暴君 900 HP，
  漏过扣 3 心；Boss 死亡直接进入胜利流程。
- **商店**：每波 3 件、4 类道具池（改概率 / 改符号 / 加经济 / 加属性）、
  重摇 1 金币；购买效果（权重、旋转成本、击杀金币、攻防倍率）跨波保留。
- **胜负与重开**：7 心、漏完失败；Boss 击破胜利；`R` / 结束画面 `SPACE` 重开。
- **手感**：受击闪白、飘伤害数字、粒子、屏震、旋转停轮音、召唤/升级/金币/受击/
  胜利等 15 个运行时合成音效；`F` 1×/2× 倍速。
- **程序化像素美术**：天空色带、星月、废墟剪影、地砖、铜框机台、程序化单位/敌人；
  1280×720、GL Compatibility、nearest 过滤；无外部图片/字体/音频文件。
- **测试与出片**：94 项无头 smoke、8 seed 平衡探针、6 张真实 GPU 截图、
  200 帧 20fps 巡览 → 10 秒 GIF/MP4、`tools/verify.sh` 一键验收。

### 问题与修复

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | “单三连”测试网格实际判定出 2 条线 | Crown 是万能牌，测试网格的其它行/对角线自己凑出了三连/二连 | 手工构造每条线都不重复的测试网格，并补充万能、3 Crown、行列交叉用例 |
| 2 | 部分种子单波拖到 20–40 秒，极端种子 240 秒仍卡在第 5 波 | 敌人停在最右侧单位；当时其它单位射程够不到接敌点，实际只有前排盾在输出；大量低血量敌人排队被逐个磨死 | 格位从 0–4 的 100px 间距收紧到 840/910/980/1050/1120；按角色分配格位；弓/球射程提到 520/500，剑/马 210/220 |
| 3 | 自动探针金币刷到 500–1150、单局 200+ 次旋转 | 二连每条线赔 2 金币，8 条线的期望收入高于旋转成本 | 二连改为每条线 1 金币；复查 8 seed 通关时间 68–76 秒、期末金币 115–386 |
| 4 | 第一版截图战斗画面只有 1 个敌人、商店遮罩不够“停顿” | 波次自然节奏下敌人被很快清完；商店只是普通面板 | 截图脚本单独摆出 4 个敌人；商店加 88% 全屏遮罩、标题与金币重新排布 |
| 5 | 无头运行不应创建音频节点 | AudioServer 在 headless 下无意义且可能出噪声 | `DisplayServer.get_name() == "headless"` 时跳过音效构建 |
| 6 | 截图中单位召唤飘字与敌人受击白闪叠在一起 | 截图动作间隔太短，多个敌人重叠在同一点 | 等待 1.1 秒让飘字消失；敌人按 30px 间隔摆放，再等 0.16 秒抓拍 |

### 验证结果（2026-11-19 实跑）

- **导入**：`godot --headless --path godot-slot-defense --editor --quit` 无脚本错误。

  覆盖 seeded 一致/差异、权重合计 100、三连/二连/Crown 万能/3 Crown/多线、

  清波进店、Boss 出场与胜利、漏怪失败、重开重置，以及 `SPACE` / `F` / `1-3` /
  `R` / SPIN 按钮的输入接线。

## 2026-11-19 · 第 2 轮：暗色霓虹像素风整体美术升级

**触发**：用户反馈第 1 轮美术“太差”。本轮只改视觉与表现层，**玩法/数值/测试保持不变**：
3×3 转轮、8 条赔付线、5 格位、5 波 + Boss、商店/金币/心数、胜负/倍速、94 项断言全部原样。
所有美术仍为原创程序化生成，参考的情绪板是“暗色霓虹像素幻想”（深靛/紫黑、青蓝发光、
熔金暖橙、少量红），未复制 Slotbound 的任何素材、角色、符号设计、UI 或文案。

### 本轮实现（按类别）

- **符号**：6 个符号从 16×16 升到 **32×32**，自动 1px 墨色描边 + 受光面/阴影面/高光/符文点缀；
  格位内以 96×96（3×）显示。心形重绘为 16×14 带描边/高光；新增金币图标。
- **背景**：启动时烘焙 `build_page_sky()`（整屏渐变+星点+星云）、战场天空（月晕/星点/极光）、
  云 ×2、远山、神殿（窗光/门光/挂旗/藤蔓）、近景废墟、地砖、雾；不同层以不同速度漂移形成
  视差，另有月光束、流星、雾带、浮尘、余烬与地砖符文闪光。波次/商店/Boss/胜负通过
  `_atmo()` 改变天空、云、雾、地砖与 UI 强调色（Boss 红橙、商店暖金、胜利薄荷、失败红）。
- **机台**：金属外框 + 黄铜倒角 + 四角包边 + 铆钉 + 跑马灯 + 玻璃反光 + 卷轴深槽 +
  拉杆底板，全部烘焙成 580×596 纹理；跑马灯只画点亮的灯泡，中奖线灯只在点亮时绘制。
- **卷轴**：九宫格底板烘焙为 416×408 纹理，滚动时符号快速切换 + 竖向残影 + 模糊条，
  每列错峰停下并回弹闪光；中奖线双层描边 + 行进光点；SPIN 按钮有 hover / 按下闪光 /
  光泽扫描；拉杆有弹簧摆动并限制在机台内。
- **UI/排版**：改用 SystemFont（SF Mono/Menlo/Consolas + Avenir Next + PingFang SC 回退，
  不打包字体），标题带光晕和细描边；HUD 重排（心、金币、波次菱形、seed、倍速 chip）；
  底栏改为键帽提示；商店卡片有稀有度色、图标底座、hover 抬升/扫光/描边、错峰入场、
  售罄印章、金币价格胶囊；胜负面板有滑入、旋转光芒、点线统计表、键帽提示。
- **单位/敌人**：保留图元拼装但重绘轮廓与受光；idle 呼吸/摆动、攻击前倾 + 近战弧光 /
  弓箭与法球投射物、受击闪白 + 击退 + 火花、死亡溶解剪影 + 余烬。Boss“齿轮暴君”有
  旋转齿轮轮廓、独眼核心、金色齿轮冠、双臂、光环与余烬；绘制锚点左移避免出画。
- **VFX/手感**：命中火花拖尾、描边伤害数字、投射物拖尾、屏震、全屏闪白/红闪、
  金币喷射、胜利彩带、胜利旋转光芒；波次/Boss 入场横幅、商店/胜负过渡。
- **性能**：首版升级后 Intel HD 6000 压力场景只有 **22fps**。将整屏天空、机台外壳、
  卷轴底板、按钮、影子全部预烘焙；逐符号光晕只在中奖时绘制；小字号取消描边；
  环境粒子限量。最终同一压力场景在空闲时 **37–40fps**，正常对局更高；
  本机后台高负载时 5 次采样中位数 **36.7fps**（4/5 次 >30，1 次受外部占用掉到 19.7）。

### 未解决 / 风险

- 单位/敌人仍是图元分层拼装，没有骨骼或逐帧贴图动画；若继续提升动作精度，建议做
  角色精灵缓存（同时能进一步降低 draw call）。
- 压力场景最低帧偶有抖动（low≈11–12），主要来自首次创建粒子/纹理上传；平均帧达标。
- 系统字体在不同平台的字形宽度略有差异（中文回退字体不同），布局按 1280×720 调整，
  跨平台需要复测排版。
- GIF 体积从第 1 轮的 739KB 增至 2.6MB（细节与彩带更多）；如需更小可降色/降帧。
- 本机为共享环境：后台飞书/其他 worker 高负载时压力场景可能跌破 30fps（5 次中 1 次）。
  若要在任意负载下稳住 30fps，下一步应做角色精灵缓存与自适应画质。
