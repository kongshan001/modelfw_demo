## T-20261121-011 · 审计级性能复测与优化消融（2026-11-21）

### 背景

T-009 的性能结论来自单次累计对比（1000 智能体：19.7 → 31.5 → 47.0 FPS），缺少独立轮次、P50/P95/P99、hitch、引擎计数、1080p 与方差。本任务补齐审计级数据；只改/新增 bench 与结果文档，不改玩法/默认视觉。

### 实现

- `scripts/flow_sim.gd`：新增 `large_group_10hz`（默认 true，>700 时每 3 拍刷新；false = 初版每 2 拍）与精确逻辑步计数 `step_count/step_total_usec/step_max_usec`。
- `scripts/flow_view.gd`：新增 `trail_antialias`（默认 false）与 `trail_half_sampling`（默认 true），仅影响拖尾绘制；默认值与 T-009 一致。
- 新工具：`tools/bench_ablation.gd`（8 配置 × 5 轮 × 2 分辨率 + 500 对照 + 图层隔离，写 CSV/JSON）、`tools/plot_ablation.gd`（对比图）、`tools/summarize_ablation.py`（Markdown 汇总）、`tools/run_ablation.sh`（一键复测）。

### 方法

- 地图 medium / 种子 421 / 1000 智能体（500 对照）；每配置每轮 60 帧预热 + 300 帧采样，5 轮独立运行，轮次主序 + 配置顺序循环左移。
- 垂直同步关闭；1280×720 真实窗口；1920×1080 因屏幕仅 1440×900 改为离屏 SubViewport（完整 1080p 渲染，present 不计）。
- 记录每轮 load1/load5、`pmset` CPU_Speed_Limit、RenderingServer 与 Performance 的 draw calls/objects/primitives/显存。环境：load1 5.23–24.68（中位 9.34），swap 已用约 4.3–4.5 GB，飞书/浏览器/其他 worker 同时运行。

### 结果（1000 智能体；中位 [min–max]）

| 配置 | 1280×720 FPS | P95 ms | 1920×1080 FPS | P95 ms |
| --- | ---: | ---: | ---: | ---: |
| 初版 B（AA on / 15Hz / 全拖尾） | 11.0 [9.5–12.7] | 145.4 | 8.6 [4.7–10.2] | 181.1 |
| -AA | 15.7 [10.5–26.2] | 98.7 | 11.9 [7.0–19.3] | 109.0 |
| 10Hz | 11.4 [8.2–15.3] | 145.4 | 10.5 [6.4–14.2] | 120.8 |
| 1/2 trail | 14.1 [9.2–17.2] | 112.1 | 11.7 [7.8–13.6] | 131.4 |
| ALL（默认） | **26.4** [17.0–32.2] | **57.9** | **16.8** [13.7–23.4] | **129.2** |

- 同轮归一（抵消跨轮负载漂移）：仅关 AA 1.65×/1.46×；仅半采样 1.25×/1.35×；仅 10Hz 1.13×/1.22×（720/1080）；全开 2.17×（两档一致）。
- 500 对照：B 26.0、-AA 40.7、1/2 27.1、-AA+1/2 42.6 FPS → 半采样/10Hz 的 >700 阈值不生效，AA 仍是主因（+56%）。
- 引擎计数：拖尾 AA 开→关，objects 138,088→58,087、primitives 151,438→71,436；半采样再减 5k（AA 关时）/40k（AA 开时）。图层归因：默认配置下隐藏箭头层 +27.5 FPS（primitives 66,436→21,400），隐藏 agents+trails +6.8 FPS，隐藏拖尾 −0.7 FPS（噪声内）——箭头是剩余最大渲染项，拖尾已接近免费。
- 10Hz 逻辑步长中位 18.28→16.17 ms（720）/22.84→16.92 ms（1080），预算 55%→48% / 68%→51%。
- GPU time 在 GL Compatibility 不可得；RenderDoc 未安装且不支持 macOS；Xcode GPU Capture 仅 Metal，GL 路径不可捕。用图层隔离 + RenderingServer 计数 + 同轮归一替代。

### 发现并修复的问题

| # | 问题 | 现象 | 修复 |
| --- | --- | --- | --- |
| 1 | 拖尾/叠加层在错误节点绘制 | headless 启动即刷屏 `Drawing is only allowed inside this node's _draw()` | `draw` 信号 bind 子节点，绘制函数接收 `CanvasItem` 并在其上调用 `draw_*`；删除两个未使用且引用不存在方法的旧层脚本 |
| 2 | MultiMesh 缺少 mesh | 智能体不可见；GLES3 刷屏 `mesh.is_null()` | 为 MultiMesh 设置 `QuadMesh(64×64)` |
| 3 | 拖尾抗锯齿过重 | 1000 智能体基线约 19.7 FPS，最差帧约 79 ms | 关闭拖尾抗锯齿；>700 群时拖尾半采样、10Hz 刷新；方向/分离缓存降到 10Hz（移动仍 30Hz） |
| 4 | 样例地图种子标签不一致 | 随机地图后再载入样例，抬头仍显示随机种子 | `load_sample()` 使用 `SAMPLE_SEED = 421`，并允许 `setup()` 透传种子 |
| 5 | 积分场箭头与数字重叠 | 1920×1080 截图可读性差 | 切换积分场时默认关闭箭头（用户可手动开启） |
| 6 | 临时脚本散落 | `_bench*.gd`、`_dev_check.gd` 无统一验收入口 | 整合为 `tools/smoke_flowfield.gd` + `tools/bench_flowfield.gd`，新增 `tools/capture_flowfield.gd` |
