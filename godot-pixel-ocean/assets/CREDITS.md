# Credits / 素材与许可

## 原创声明

- 本工程的全部 GDScript、场景、shader、程序化波形、像素水纹、天空/海床、
  木筏、水手、猫、灯笼和所有程序化贴图，均为本项目原创、由代码在运行时生成。
- 没有引入任何第三方模型、贴图、字体文件、音频或运行时库。

## 参考

- 效果配方参考：B 站《我做了一个很酷的效果》，UP：大肥鱼的开发日记，
  BV1ehsm69EnT（https://www.bilibili.com/video/BV1ehsm69EnT）。
  仅学习“3 道浪 / 五点浮力 / 像素水纹 / 倒影 / 碎金 / 透明”等公开的效果构成，
  **未复制视频的画面、贴图、音频或工程文件**。
- 本项目与视频作者无隶属关系。

## 工具

- Godot Engine 4.6（MIT License）——引擎本身不随本工程分发。
- ffmpeg——仅用于离线把帧序列编码为 MP4/GIF，不是运行时依赖。
- 系统字体（macOS PingFang SC 等）仅由 HUD 通过 `SystemFont` 引用，不随工程分发。

## 使用

本工程作为学习/演示用途。若要复用代码，请保留本 CREDITS 与原创声明。
