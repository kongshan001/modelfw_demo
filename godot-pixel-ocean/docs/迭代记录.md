# Pixel Ocean 迭代记录

日期：2026-11-20 · Godot 4.6 · GL Compatibility · Intel HD Graphics 6000

## 0. 目标与约束

复刻 B 站视频《我做了一个很酷的效果》的像素海 + 木筏配方，但不复制视频素材/工程。
只做效果展示，不做完整游戏；要求参数可调、有镜像倒影、五点浮力、9 张 GPU 截图、
6–10s 视频、headless smoke 与 30 FPS+（Intel 集显）。

## 1. 首版管线

- 1280×720 → 3D 世界 640×360 SubViewport → 最近邻 2×；HUD 1280×720。
- `PlaneMesh` 140×140 / 219 细分；3 道 Gerstner 式波；stretch/bend/grouping。
- 5 点高度采样驱动木筏 y/pitch/roll。
- 独立 320×180 倒影视口共享 World3D，镜像相机 + 水面 x 翻转采样。
- 初版截图：配方元素齐全，但存在 4 个明显问题：
  1. 木筏在逆光下几乎全黑，船板细节丢失；
  2. 浪尖泡沫在部分波面形成巨大白片，像浮冰；
  3. 低机位时倒影把海面洗成灰白大色块；
  4. 远处海平线出现深色“岛屿”带。

见：`docs/shots/01_sunset_wide.png`、`docs/shots/03_noon_clear.png`。

## 2. 光照与调色

- 新增镜头方向无阴影补光 `CameraFill`，随调色板暖/冷变化；环境光能量整体提高；
- 木材/帆布反照率提亮，逆光下木筏、水手、猫、灯笼仍可读；
- 夕照水色从亮紫灰改为深靛 + 紫 + 珊瑚浪脊，受光阶梯阈值上移，
  亮色只出现在朝太阳的浪面/浪尖；
- 天空太阳光晕收敛、星点变小、量化级数从 18 提到 28，减弱同心圆台阶。

## 3. 泡沫诊断：三次隔离

问题“白色浮冰”难以定位，做了三组隔离截图（仅用于内部调试，未入库）：

| 隔离 | 方法 | 结论 |
| --- | --- | --- |
| 反射 vs 基准 | 黑底 + 关闭泡沫/碎金/阳光 | 前景大块来自泡沫，不是反射 |
| 反射纹理 | 把倒影 SubViewport 直接存 PNG | 倒影本身正确，帆影在反射图中 |
| 白沫遮罩 | 提高压缩阈值 + 低频斑块 | 大片泡沫被切成碎块 |

最终方案：
- Jacobian 压缩阈值从 0.62 提到 0.78，`v_crest` 增益 3.0；
- 两层低频世界网格（0.55 / 1.9）× 高频噪声，把白沫切成不规则小斑；
- 泡沫颜色混入少量水色与细颗粒，不再纯白；
- 木筏边泡沫从宽椭环改成圆角矩形 SDF 窄环（0–0.2 单位），随波扭动、强度降低。

## 4. 倒影与海平线

- 倒影视口缩小到 320×180，采样改 `filter_linear`，扭曲量降到 0.012，
  避免 320×180 最近邻反射在 640×360 水面上形成方块噪点；
- 反射权重改为 `fres^3 * 1.15 + 0.24`：
  - 0.24 基础反射保证低机位能看到帆/船体倒影；
  - 掠射角增强保留海平线整片晚霞；
- 倒影乘 `mix(1, sun_color, 0.22)` 做暖冷色调贴合；
- 海面网格边缘波幅在 52→66 收回、颜色 32→58 融入天际；海床从 200×200 缩到 70×70，
  去掉远处深色“岛屿”；
- 天穹水下部分从 horizon×0.52 提到 ×0.93，海面边缘与天空过渡干净。

## 5. 最终效果

- 晚霞：深靛海面、珊瑚色浪脊、金色 glints、暗色船影倒影、筏边一圈碎沫；
- 正午：青绿海面、白色浪花斑、暖色木筏；
- 夜间：月晕、星点、冷色碎光、暖色灯笼照亮水手和帆；
- 五点调试：中心青点 + 四角黄点，可穿透甲板查看采样位置；
- 参数面板：7 个滑杆 + 3 个预设 + 调试/暂停开关，中文 SystemFont。

## 7. 已知问题 / 下一步

- 倒影没有斜裁剪面，离水面极近的几何可能出现轻微漏影；
- 水面 alpha 混合、不写深度：没有折射/水深吸收，透明只是海床混色；
- 泡沫低频斑块在个别大浪上仍会形成较大的白色块，可再引入“浪峰线”距离场；
- 白沫与像素水纹在 640×360 下已接近可读性极限；若想更接近视频，
  可把模式改成“水纹贴图 + 调色板查找”，但会增加美术资源依赖；
- 无阴影、无泛光，夜景靠自发光灯笼与月晕营造；
- 截图/视频工具必须在真实 GPU 窗口下运行。

## 8. 对比视频的差距

| 视频配方 | 差距 |
| --- | --- |
| 3 道浪 + 拉长/拧弯 | 已复刻；视频可能叠加了更多细节层 |
| 浪尖挤尖 | 已用水平 Jacobian；尖锐度可再调 `choppiness` |
| 五点浮沉 | 已复刻，俯仰/横滚平滑跟随 |
| 像素水纹 | 已程序化生成，风格更“格点短划线”，视频更像手绘水纹 |
| 逆光白沫 | 已具备；泡沫形状仍略碎 |
| 镜面倒影 | 已用镜像相机；受低分辨率和无裁剪面限制，帆影较淡 |
| 碎金 | 已具备，密度可调 |
| 透明 | 已具备但较克制；视频可能使用更深的海床/折射 |
| 晚霞 | 已做连续 0–24h 调色，构图接近 |

下一步最值得做的是：给倒影加斜裁剪面、给水面加一层低频“手绘水纹”贴图，
以及把泡沫约束到浪峰线附近。

## 9. Follow-up（2026-11-20）：倒影悬空 / 水线接缝修复

用户反馈 `01_sunset_wide.png`：“这个倒影效果有问题，看着像船都飞起来了”。

### 9.1 根因（量化）

- 截图 pose（wave clock 2.4）五点水位平均 **0.448**；木筏旧逻辑
  `target_y = 平均 + 0.10 = 0.548`，浮木半径 0.14 → 浮木底部 y=**0.408**，
  比当地水面（中心 0.401）还高 **0.007**：船根本没有入水，只是“贴”在水面上。
- 倒影相机固定在 **y=0** 镜像，而船所在水面在 y≈**0.45–0.63**。
  固定镜像面使整个倒影下移 `2h≈0.9–1.3` 个世界单位，倒影顶部与水线之间
  露出一段水带；低机位 `02_sunset_reflection.png` 更明显。
- 接触泡沫环 `ring *= 0.45` 且被两层噪声压掉，几乎不可见，接缝没有遮挡。

### 9.2 修复

- 木筏：`FLOAT_OFFSET = +0.10` → `DRAFT = 0.06`（`target_y = 平均 - 0.06`）；
  浮木半径 0.14→0.17、中心抬到 +0.06，约一半没入水中；甲板抬到 +0.20，
  水手/猫/道具/灯笼基准同步 +0.12，保持干舷，避免浪尖漫过甲板。
- 倒影：镜像平面改为 `raft.get_waterline_y()`（五点平均水位，随浮力平滑），
  clamp 到主相机下方 0.35；镜像相机 `y = 2*plane - cam_y`，不再用 y=0。
- 水面倒影：3 次纵向采样平均（±0.0035 uv）做轻微模糊；保留法线/正弦扰动和 0.70 色调。
- 水线：SDF 半尺寸 1.13×1.55，亮沫线（0.04 带宽、世界空间哈希打碎）
  + 0.30 范围 32% 接触暗边（乘在倒影之上）。
- 新增 smoke 断言：木筏根节点低于平均水位、浮木底部没入当地水面、
  镜像平面 = 水线、反射相机严格镜像，防止回归。

### 9.5 仍存在的限制

- 镜像面取木筏水线；水面局部高度与它相差 Δh 时，倒影仍有约 2Δh 的残余偏移
  （木筏附近通常 <0.15，肉眼不可见；远处天空反射的角度误差可忽略）。
- 镜像面随木筏上下浮动，理论上会让远处天空反射轻微漂移；当前幅度不可见。
- 倒影仍无斜裁剪面；极低机位贴近水面时可能出现轻微漏影（首版已知问题）。
