## R1 · 可玩骨架与首轮真实截图（17:20–17:35）

- 建立 640×360 世界 SubViewport + 1280×720 原生 HUD；人物/木桩/金币/事件总线与 JSON 播放器。
- 四组触发、命中停顿、震屏、伤害数字、灼烧/冰冻状态、分数、0.5×/1×/2× 全部接上。
- 首轮真实截图暴露的问题：
  1. 四枚金币动画同相，截图全是侧面细条；
  2. 天空/中景空旷，右侧边缘有 1px 藤蔓虚线，像渲染错误；
  3. 四枚金币的 collect burst 完全同相叠在一起，像四个白圈；
  4. 火球爆炸 5.433s 的尾部烟柱会长时间遮住木桩；
  5. 大 tick 下 hit-stop 会吞掉整段 delta，冒烟测试的清理时间对不上；
  6. HiDPI 1280×720 窗口在同负载下只有约 20–30 fps，不够稳。
- 画面基线：`docs/shots/00_overview.png`（此时 HUD FPS 还是占位值，后续已改为实测代表值）。

## R2 · 视觉与手感整改（17:35–17:50）

参数级改动：

| 项 | 改前 | 改后 | 目的/证据 |
|---|---|---|---|
| 金币相位 | 全部 0s | `i × 0.37s` | 四枚朝向不同，overview 不再全侧面 |
| 金币反馈 | 同帧 4 个 burst | 0/45/90/135 ms 错峰 | 保留“一次拾取 4 枚 +40”，burst 可读、不糊成白圈 |
| 灼烧时长 | 2.2 s | **3.0 s** | 爆炸剪到 2.2 s 后仍有 0.8 s 火焰 tint/火星，截图 `07_burn` |
| hit-stop | 命中后吞掉整个 tick | 只消耗 hitstop 所属 delta，剩余继续；命中当帧冻结世界 | smoke 中 0.05s@2× = 0.10s 特效时间，0.2s@0.5× = 0.10s |
| 爆炸播放 | 全 5.433 s | `max_time=2.2s`（仍保留完整 sheet/JSON） | 烟柱不再长时间遮挡；smoke 断言清理 |
| 天空 | 近乎空 | 双层极光、月束、飞鸟、更多星点 | 1920 截图中心不再空 |
| 中景 | 山体剪影 | 遗迹描边、破旗、常春藤、木栅栏、草垛/木桶/蘑菇 | 增加纵深与地标 |
| 右缘 | 1px 藤蔓虚线 | 拆除，改为 26×104 破布横幅 + 金色符文 | 去掉“像 bug”的线 |
| 冻结表现 | 仅 4s 冰壳 | 冰壳 + 蓝色 tint 0.42 + 脚边/肩部原创冰晶 + HUD/头顶 2.9s 计时 | `03_freeze` |
| macOS 性能 | `allow_hidpi=true` | **`allow_hidpi=false`** | 同负载 1280×720 由约 23–30 提升到 **66.4 fps 平均**；README/TECH 说明取舍 |

实现细节：世界绘制全部整数 `draw_rect`/多边形（无 AA）；金币/特效位置取整；相机的震动为整数偏移；HUD 中文改为 GRAY AA 的可读方案，标题/分数/伤害仍为原创 5×7 位图。
