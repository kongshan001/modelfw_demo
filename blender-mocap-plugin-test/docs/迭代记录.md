## 08:30–08:45 第一版动作 → 发现头部 bug

- Pose VIDEO 模式：148/148 检测；init 0.776 s；0.104 s/帧（p95 0.121）；总 17.28 s。
- 第一版 `build_motion.py` 把 `head_top` 设为 nose；结果 head 骨朝前下 ~60°，Rogue 明显低头；30 帧测试截图确认。
- **修正**：`head_top = ears + (0,0,0.18)`（skull up）。重跑 30 帧 → 头部恢复直立。

## 08:45–09:05 接地 / 重定向 / 全量

- MediaPipe world landmarks 以髋为中心，原始 hip Z 几乎不动；增加 **最低脚接地**（每帧整体平移，5 帧平滑）：髋起伏 5.06 cm，脚底 ~0，代价是平滑后约 -2.7 cm 的源穿地。
- 18 骨 Mixamo 源骨架：Damped Track → bake → GLB；`animation-retarget-kit` 显式 18 骨 map → Rogue。
- 全量 148 帧：Rogue 41 骨 / 12 mesh / 26 轨 / 4.9333 s；root XZ 1.7 mm；脚底 -0.84 cm；支撑滑 0.2315 m。
- RDP 精简 ε=0.002：60,680 → 5,346 keys（-91.19%），最大通道误差 0.002；时长/骨架不变。
- 第一次导出忘了 `export_force_sampling=False`，GLB 又被逐帧采样（660K，与 raw 几乎同大小）；改为关闭采样 + 优化动画大小后，simp 输出 **422,432 B（-36%）**，Godot 轨 26→24。导出器仍对 key 数不一致的通道烘焙（日志 warning），记录在 pitfall。
