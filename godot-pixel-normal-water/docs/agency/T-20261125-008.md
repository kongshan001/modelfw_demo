# T-20261125-008 · 实现说明

## 任务

把 B 站《硬核源码拆解｜拒绝塑料贴纸感！单人手搓 Unity 2D 像素法线受光 + 零额外
相机水面夜景反射》的数学/渲染思路，在 Godot 4.6 复刻成可交互 2D 像素夜景 demo：
原创场景；法线正交受光；沿脚底/水线锚点的单 Mesh 倒影；共享 mask；`round()`
量化水波；单 Camera2D、零额外 Viewport；可调光/水/灯/倒影/时间，带调试视图。

参考只抽取了技术要点，参考视频音视频文件只放在 `/tmp/bili_normal_water`，未入库，
没有复制任何 Unity/C# 源码或素材。

## 实施计划与完成情况

1. 先 yt-dlp 抽元数据/帧确认效果与术语 → 完成，提取到 `/tmp`。
2. 程序化像素夜景 + 四层贴图（albedo/height/roughness/emission）→ 完成，
   11 个受光物件；正常/粗糙/自发光图全部运行时生成。
3. 2D 法线正交受光 shader + 两盏暖灯点光 → 完成；并加了每像素大形 normal bias
   解决“平面贴纸感”。
4. 单 Mesh 倒影（512×128 图集、6 quads、1 surface）+ mask 裁切 +
   round() 量化水波 + additive 波光 overlay → 完成。
5. HUD/调试/暂停/时流/截图/视频工具与验收 → 完成；`NORMAL_WATER_VERIFY_OK`。

## 关键实现

- **单相机/单 Viewport**：`main.tscn` 只有 1 个 Camera2D，运行中无 SubViewport；
  smoke 断言 `cameras=1`、无 SubViewport / 嵌套 Viewport。倒影不使用第二相机或抓屏。
- **法线受光**：`lit_sprite.gdshader` 用 `(right, up, basis)` 正交基重组 normal；
  环境光 + 冷月方向光 + 2 盏暖灯点光 + roughness 控制的 Blinn-Phong 高光；
  emission 放在 normal map alpha，只点亮灯窗/灯芯。全局方向/强度/颜色预设与
  法线开关均由 HUD 实时更新。
- **法线贴图**：`PixelSurface` 高度场中心差分 + 每像素 normal bias；屋顶左右坡、
  树冠中心向外、石头圆顶等大形方向先写入 bias，再叠加木梁/窗框/叶簇细节。
- **倒影**：`reflection_field.gd` 将 6 个近岸物件按水线 `y=120` 镜像；近水边顶点
  对应源图底部 UV；6 quads → 36 顶点 → 1 个 ArrayMesh surface、1 draw call；
  共享 320×180 1-bit mask；`reflection.gdshader` 中硬裁切 + 冷色压暗 + 暖像素
  保留 + 深度变淡。
- **量化水波**：
  `round(sin(row*0.86 + t*speed*1.6)*0.68 + sin(row*0.31 - t*speed*0.9)*0.32
  * amplitude / step) * step`；`row=floor(world.y)`；GDScript 的
  `quantized_shift()` 与 shader 同式，用于 smoke/调试。
- **时间**：GDScript `time_value` 注入所有 shader；暂停或时流 0 时冻结；
  暖灯 flicker 与水面波光和主时钟一致。

## 关键参数

- 世界 320×180；Camera2D zoom=4；1280/1920 分别 4×/6× 美术像素。
- 光角默认 35°（0°=正上，90°=右）；光强 1.18×；预设 冷月/暮蓝/暖烛。
- 暖灯世界坐标 (113,78)/(185,78)；能量 2.0、半径 60px、灯高 22px。
- 波速 1.0×、波幅 2px、量化格 1px；范围 0–2.5 / 0–4 / 1–4。
- 倒影图集 512×128（每侧 6px padding），6 quads / 36 verts / 1 surface。
- 水面 mask 320×180；水线 120；近岸美术脚底 112（压顶石遮住锚点差）。
- 11 个受光物件、11 个 CanvasItem 材质。

## 已知风险 / 限制

- 倒影是 2D 平面 cheat：仅 6 个物件；单 Mesh 透明四边形按固定顺序绘制，
  移动物件后可能需要重新排序；无 SSR、无折射、无菲涅耳。
- 法线为程序化高度场 + 大形 bias，不是手绘/DCC 烘焙；极端光角下会有硬边或近似。
- 水面 mask 为 1-bit 硬边；不模拟浑浊深度吸收/软岸线。
- 1080 截图/probe 使用 macOS borderless 根窗口放到屏幕外；没有额外 Viewport。
- 视频源由 Movie Maker 在 1280×720 录制，再最近邻放大到 1920×1080；截图是原生
  1920×1080。
- UI 依赖系统 CJK 字体回退，未打包字体；无音频。
- 共享的 `docs/task-plans/game-demos.md` 同时有其他 worker 的并行改动；本任务只
  修改 T-20261125-008 记录的状态/产出行。git_publisher 按 commit_paths 提交时
  可能一并带入同文件的其他记录更新，这是现有工作流边界，需要发布侧知悉。
