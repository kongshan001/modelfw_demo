## 2. 规格决定（与视频的偏差）

任务规格要求的是**第三人称低多边形动作** vertical slice（相机轨道/缩放、近战可连击、闪避、HP/击退/死亡、至少 2 种蘑菇 AI、目标/胜负/重开、中文 HUD、调试视图）。因此：

- 保留视频的**类型主题**：低模草地、绿色芽苗系角色、蘑菇敌人、跳跃、成长/清怪目标；
- 改为**第三人称动作**：相机轨道 + 缩放、手动三段剑击、右键闪避 i-frames、Space 跳跃；
- 用**清空 10 只菌怪 → 石拱门开启 → 走入光门**替代视频的限时生存/经验升级；
- 角色、蘑菇、场景、UI、图标、名称均原创，不使用视频资产/角色/品牌。

### 迭代 2 — 世界从“空”到“草甸”

发现的硬 bug：

1. `MultiMesh` 没有设置 `mesh` 且 `custom_aabb` 为 0：草、树、栅栏、石头全部不可见。修复：每个 MultiMesh 绑定 mesh，并按实例变换计算/设置 `custom_aabb`。
2. 地面运行时 `create_trimesh_shape()` 在该 GL 组合下不阻挡玩家/敌人：玩家与菌怪一直下沉。最小日志显示玩家 `floor=false`、敌人 y=-14.8。修复：改为 77×65 的 `HeightMapShape3D`，之后玩家/敌人都能落地。
3. 孢囊菇的“攻击距离环”半径 9.2m，铺满屏幕；改为远程只显示口中充能球，近战/菌卫保留范围环。
4. 调试标签每帧改写 CJK Label3D 导致调试帧率大幅下降（低到 2–10 FPS）；改为 4Hz 更新且仅文本变化时 set。
5. 方向光实时阴影在本机 GL Compatibility + Intel HD 6000 上无可见投影，却带来约 270 个阴影 pass draw；最小方块场景验证后关闭实时阴影，改用双层程序化接触阴影圆盘。README/TECH 如实记录。
6. HUD 的 `draw_string` 居中/右对齐未指定区域宽度导致偏移；统一用 helper 将 center/right 解释为“中心/右边界 + 区域宽度”。

视觉：

- 草甸 76×64m，路径顶点色、踏石、栅栏、树林/灌木/岩石、花、石拱门、薄雾；把草从稀疏白尖调到更密的深绿短叶。
- 标题 / HUD / 目标栏 / 操作提示 / 提示 toast / 伤害数字 / 斩击弧 / 命中环全部自绘；无 UI 素材。
