# 技术说明 · 苔光浮庭 / Mosslight Isle

> 结论先行：这是一个 **Godot 4.6 GL Compatibility** 的程序化治愈系场景 vertical slice。原创低模几何 + 自生成噪声/光照 + 6 组自写 shader + 屏幕空间交互 + 程序化音效。参考视频只提供视觉语言与节奏，**无任何资产、角色、场景、UI 或品牌元素被复制**。

## 1. 参考拆解与差距

`yt-dlp` 从 `https://b23.tv/towtE2d` 下载 1920×1080/30fps 的 70s 片段，`ffmpeg fps=1` 与关键段 0.5s 抽帧只存 `/tmp`。确认：

| 维度 | 观察 | 本作处理 |
| --- | --- | --- |
| 类型 | 3D 低模/手绘风浮岛小品，非像素 | 同类型，但完全重做场景与资产 |
| 镜头 | 高层 3/4 俯视，缓慢环绕/缩放 | 高层 3/4，自动环绕 + 拖拽 + 滚轮 |
| 构图 | 浮岛充满画面；大针叶树、砂径、水塘、岛缘岩 | 月树 + 茶亭 + 砂径 + 锦鲤塘 + 紫灰岩缘，新增苔猫/风铃/茶席 |
| 配色 | 深靛夜空、鲜绿苔草、紫色花与岩、暖橙灯 | 深靛 + 低饱和苔绿 + 紫花 + 暖琥珀灯；更克制 |
| 光照 | 冷月环境光 + 强暖灯反差 + bloom/大颗萤光 | 冷/暖双向光、解析暖池、发光贴片、萤火/浮尘 |
| 微动画 | 草/树摆动、水面、灯光、萤火、编辑器光标 | 草/花/树冠/水面/鱼/灯芯/纸签/风铃/蒸汽/雨/落花/岛屿浮沉 |
| UI | 底部积木式编辑器工具栏 + 参数面板 | 极简 HUD + 药丸按钮；不含参考图编辑器功能与图标 |
| 玩法 | 场景编辑器/造景工具 | 4 个轻交互小物、昼夜/天气/暂停，不要求战斗 |

**明确不同**：没有复刻原视频的松树造型、岛屿轮廓、路径形状、池塘位置、灯笼造型、粉色/紫色花卉搭配、底部图标栏、参数面板与编辑器语义。本作的茶亭、猫、风铃、锦鲤/睡莲、砂径材质、昼夜/雨系统均为原创扩展。

## 2. 架构与数据流

```text
scenes/main.tscn
  └─ scripts/main.gd        # 状态机 / 总推进 / 输入 / 演示 API / FPS
       ├─ atmosphere.gd     # Environment, 冷月/暖日, 雾, 天空球, 低云
       ├─ world.gd          # 浮岛/植被/路径/水/树/亭/小物/粒子/萤光
       │    ├─ geo.gd       # SurfaceTool 程序化几何/径向贴图/云噪声
       │    ├─ moon_lantern.gd
       │    ├─ wind_chime.gd
       │    └─ moss_cat.gd
       ├─ camera_rig.gd     # 三/四轴环绕相机
       ├─ interaction.gd    # 屏幕空间悬停/点击/E
       ├─ post_fx.gd        # CanvasItem 校色/暗角/颗粒
       ├─ hud.gd            # 系统字体 UI + 投影标记 + toast
       └─ procedural_audio.gd # AudioStreamWAV 本地合成
```

- 世界、相机、粒子都设为 `PROCESS_MODE_PAUSABLE`；`main` 与 HUD 为 `PROCESS_MODE_ALWAYS`。暂停时 main 守卫所有动画推进，同时让按钮/键盘仍能继续。
- 所有 shader 使用自定义 `u_time` 而非引擎 `TIME`，暂停时冻结；主控在未暂停时统一推进 `atmosphere.advance()` 与 `world.tick()`。
- `world.tick(delta, nightness, rain_amount, quality)` 是唯一场景动画入口，适合 smoke/截图/视频调用。

## 4. 光照与色彩

- **环境**：`WorldEnvironment`，BG_COLOR + 自写天空球；FILMIC tonemap，exposure 夜间 1.08 / 日间 0.98；glow 夜间强度 0.44、日间 0.10，HDR 阈值 1.02。
- **主光**：DirectionalLight3D，夜间冷色 `(0.62,0.75,1.0)`、能量 1.36，日间暖阳 `(1.0,0.84,0.63)`、能量 1.46；2048 shadow map、单级正交阴影、max distance 42m。日/夜角度从 (-51,-35) 过渡到 (-39,-24)，所有配色按“夜度”正确递增，避免第一版昼夜色温反转。
- **补光**：冷色天空补光 0.38（夜）/0.14（日），无阴影；树冠下暖色 Omni、茶亭纸灯、两盏苔灯、风铃小灯全部无阴影。
- **环境光**：夜 `(0.29,0.37,0.49)` × 1.12；昼 `(0.63,0.69,0.61)` × 0.74。日间降低环境、提高方向光以获得形体与影子；夜间提高环境以保留“月光下仍可读”的草甸。
- **雾**：指数深度雾，夜密度 0.0018、昼 0.0030，雨再 +0.0024；雾色从冷靛过渡到青白。`fog_sky_affect=0`，不污染天空球。
- **暖光池**：苔灯 4.2×3.3m 加法径向贴片 + 真实 OmniLight；茶亭另有一块 4.0×3.2m 地池。水面不接收真实灯光（unshaded），而是把最近水边苔灯位置传入 water shader，解析生成暖倒影/高光。
- **校色**：`post_grade.gdshader` 在 HUD 下方，单次屏幕采样，抬冷阴影/暖高光、1.035 对比、0.26 暗角、极细颗粒；无 TAA/SSAO/SSR 等 Compatibility 不友好后处理。

> Compatibility 下不使用体积雾、SSAO、SSR、TAA。所有“体积感/光辉”由灯光、billboard halo、glow、云片与合成贴图承担。

## 5. 微动画系统

| 系统 | 实现 | 频率/幅度 | 暂停行为 |
| --- | --- | --- | --- |
| 草/花 | `wind_foliage.gdshader`：UV.y 高度权重 + 世界相位；tip flutter | 草 sway 0.055、flutter 0.018；风阵雨 +0.95 | u_time 停止 |
| 树冠 | 5+3 个主树 pivot + 背景树/幼树共 16 个 pivot；每帧旋转组合 | 0.008–0.022 rad，0.33–0.68 Hz | world tick 停止 |
| 叶片 | 叶片卡片 + 低模体积块合成；BACKLIGHT 透光 | 每簇 115 张卡片、6 奶油花簇 | 同上 |
| 水面 | 3 octave fbm 双层法线、正弦亮带、月光碎银、暖灯解析倒影、雨环 | u_time 0.52×；alpha 0.83 | u_time 停止 |
| 锦鲤 | 两条 koi 节点沿旋转椭圆路径 + 尾摆 | 速度 0.30/-0.22；尾巴 4.6–6.6Hz | world tick 停止 |
| 萤火 | GPUParticles3D，盒形发射、turbulence、暖金/苔绿渐变 | 104 个，lifetime 9s | GPU 随 tree 暂停 |
| 浮尘 | GPUParticles3D，86 个，慢漂 | 日间更亮，夜间保留少量 | 同上 |
| 落花 | CPUParticles3D 从树冠落下 + 自转 + 雨时加速 | 34 个，lifetime 9s | tree 暂停 |
| 雨 | CPUParticles3D，盒形 460 滴，竖长条网格 | 晴天关闭，雨时可见 | tree 暂停 |
| 岛浮 | `island_root.position.y = sin(...)*0.055` | 0.37×、极低频 | world tick 停止 |
| 灯芯 | 呼吸 + 点光/自发光/光池 alpha 联动 | 2–5Hz 轻微闪烁 | 对象 tick 停止 |
| 风铃 | 玻璃管 + 纸签 + 铜铃；雨与悬停增大摆幅，点击冲量 | 1.3Hz 待机；点击后衰减振荡 | idle tick 停止 |
| 苔猫 | 呼吸、周期眨眼、尾巴慢摆；点击 joy 抬头/摆尾/星屑 | 呼吸 1.35Hz；眨眼 6.3s 周期 | 同上 |
| 茶汤蒸汽 | CPUParticles3D 极低 alpha 上升雾 | 9 个，lifetime 2.8s | tree 暂停 |
| 纸灯/树荚 | 暖自发光 + 轻微摆动，点光同步 | 0.6–2.1Hz | world tick 停止 |

所有 shader 时间使用自定义 `u_time`，脚本每帧统一下发；因此暂停时不会出现“UI 暂停但草还在摇”的不一致。

## 6. 交互设计

- 不使用物理 RayCast，避免为软场景添加碰撞体；`interaction.gd` 每帧把 4 个交互锚点投影到屏幕空间。
- 小物标记显示为小点；鼠标进入 62 design px 半径后高亮为细环 + `E · 名称` 标签；点击容差 7px，左键释放时触发，避免拖拽相机误触。
- `E` 触发当前悬停目标。点击/键盘事件由 main 的 `_unhandled_input` 与 interaction 分工；HUD 按钮 `MOUSE_FILTER_STOP`，不会穿透触发场景交互。
- 交互反馈：
  - 苔灯：`lit` 切换，灯光/玻璃/地面光池联动，flash 衰减。
  - 风铃：4 根玻璃管的摆动冲量、CPUParticles 星屑、`AudioStreamWAV` 玻璃三连音。
  - 苔猫：`joy` 1.8s 衰减的抬头/尾摆、眨眼、暖色微尘、低频呼噜。
- 状态机很轻：不改变路线/状态间依赖，`reset()` 一次恢复全部默认；工具通过 `main.demo_interact(id)` 走同一交互路径，不做测试专用旁路。

## 7. 性能与预算

设备：**Intel Core i7-5650U / Intel HD Graphics 6000 / macOS / OpenGL 4.1 Compatibility**。vsync off，HUD 与交互标记可见。实测见 [fps.txt](fps.txt)。

| 项目 | 数值/说明 |
| --- | --- |
| 720p 夜/昼/雨/低 | median 42 / 37 / 30 / 46 fps |
| 1080p 窗口 夜 高 | median 30.0，avg 30.4、min 27、best 2s 31.6 |
| draw calls / primitives / nodes | 167 / 133,554 / 182（1080p，HUD 可见） |
| 逻辑视口 | 1280×720 `canvas_items` 拉伸；1080p 窗口受桌面限制实际 1920×762，截图另用 1920×1080 SubViewport |
| 三角形预算 | ~131k primitives（含 HUD/粒子网格等）；草约 2,200×18 tris，树冠 16×~230 tris |
| 粒子预算 | 萤火 104 / 浮尘 86 / 落花 34 / 雨 460；全部 CPU/GPU 粒子节点 |
| 低画质 | 草 56%、花 60%、树冠/卵石阴影关、萤火/浮尘 ratio ↓、落花 18、雨 210、远景 bokeh 4 个 |
| LOD/裁剪 | 所有 MultiMesh 批处理；`custom_aabb` 防误裁剪；树的低层簇/背景树冠不投影；不使用每帧 LOD 切换，避免镜头移动时闪烁 |

**优化路径**（最终 1080p、HUD 可见 median 30.0fps；早期 HUD 隐藏对照曾 29.2fps）：
1. 天空 shader 在夜间/日间/雨天都只计算必要噪声，星野只保留一层；fbm 5→4 octave。
2. 背景树/幼树/低层树冠关闭阴影投射；减少不必要的 shadow pass。
3. 远处 bokeh 收敛为 11 个加法贴片、浮石 3 个、贴地雾 3 片，削减 draw calls。
4. 水体改为 unshaded 风格化 shader，去掉实时光照 fill 成本并消除高光带状伪影；暖倒影由 2 个 uniform 近似。
5. 所有草/花用 MultiMesh 一次 draw；不逐对象脚本更新。

## 8. 声音

- 启动时本地合成三个 16-bit/22.05kHz WAV：苔灯木声（196Hz 主音 + 泛音）、风铃四音玻璃琶音、猫呼噜（92Hz + 23Hz 振幅调制）。不引入任何外部音频文件。
- 交互时由 main 播放；headless 下使用 dummy audio，不报错。视频不包含声音。
- 未做总线混音、响度标准化与空间化；这是场景 vertical slice 的已知限制。

## 9. 与视频的原创/差异清单

- **没有复制**：feralui 的名称/Logo、X 作者/UP 主品牌、原视频的画面、树/石/水/路的具体形状、角色、图标、编辑器 UI、音乐、字体、贴图或模型。
- **参考的视觉语言**：3/4 浮岛、冷/暖双色、苔绿/紫花/奶油池缘、萤火/大颗散景、缓慢环绕、治愈氛围。
- **新增原创**：茶亭、茶具与蒸汽、玻璃风铃、苔猫、锦鲤/睡莲、砂径与土边、昼夜/晴雨、苔灯互动、极简 HUD、程序化音效、8 张 1080p 截图与 10s 视频。
- **风格取舍**：参考是较饱和的夜间手绘森林；本作选择更低饱和、更克制的“苔光+暖灯”方向，以符合任务的低饱和/暖色治愈要求。
- **尺度差异**：参考画面以高密度植被/编辑器工具为中心；本作以“可玩的小场景叙事”和 30fps 性能为中心，模型密度和细节少于参考。

## 11. 已知风险

- 1080p 的窗口高度受当前 macOS 桌面限制，实际窗口 1920×762；1080p 图像是 1920×1080 离屏渲染。更宽的高分屏上可设置全屏 1920×1080。
- 夜间树冠是深绿剪影风格；如果显示器亮度/色彩管理不同，暗部层次可能比截图更弱。可提高 `env.tonemap_exposure` 或调 `key_light.light_energy`。
- 程序化音效未经专业混音；在不同输出设备上音量可能偏小。
- 风铃是场景中的小物，HUD 标记是主要可发现性来源；没有缩放 UI 或移动端手势适配（鼠标/E 为验收路径）。
- 实时 FPS 在截图里隐藏；其余 UI 状态均有截图。
