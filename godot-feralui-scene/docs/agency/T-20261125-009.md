## 参考确认与取舍

- 用 `yt-dlp` 拉取 70s/1920×1080/30fps 参考到 `/tmp`，`ffmpeg` 抽 1s/帧与关键段 0.5s，未入库。
- 画面是 3D 低模/手绘浮岛：高层 3/4、深靛背景、密草、针叶树/阔叶树、砂径、水塘、奶油池缘、紫花/白花、暖橙灯、萤火/浮尘、编辑器底部工具栏。
- 复刻的是**构图密度、冷暖光关系、微光氛围与慢镜头**，不是具体资产。我们把原视频的“编辑器/造景工具”改成“可轻触的完成场景”：茶亭/茶具/风铃/猫/锦鲤为原创新增；没有战斗/建造。
- 明确降低饱和度，避免参考的高饱和“霓虹绿”；保留暖灯对比和深靛夜空。

## 实现摘要

### 场景

- 浮空苔岛：23.6×17m、扰动轮廓、4 层岩带、底锥、悬根；72 段顶面。
- 植被：2,200 草簇、300 白花、189 薰衣草、38 灌丛、72 蕨、34 蘑菇；全部 MultiMesh。
- 月树：主树 8 个冠团、两棵背景树、幼树，共 16 个可摇曳 canopy；6 个发光荚 + 暖色 Omni。
- 水塘：44 边风格化 teal 水面、30 块奶油缘石、5 睡莲、2 条游动锦鲤与解析暖灯倒影。
- 茶亭：曲面瓦檐、木柱、茶桌/凳、茶具、蒸汽、纸灯、风铃；石台/苔痕。
- 苔灯：路径边与水边各一，独立亮/暗状态、暖芯、点光、地面光池。
- 苔猫：程序化橘猫、奶油胸腹、琥珀眼、抬起的尾巴、星屑反馈。
- 天空：自写 shader 星野/星云/弦月/日晕/云带；低云与雾卡。

### 微动画

草/花风摆（顶点 shader + 自定义 u_time）、16 组树冠摇曳、叶卡片轻颤、落花、萤火、浮尘、雨、水面 fbm/雨环/暖倒影、锦鲤尾摆、蒸汽、风铃冲量摆动、灯芯呼吸、岛体轻浮、岛屿轻浮与亮片 bokeh。全部由 `world.tick()` 与 `u_time` 控制，暂停时冻结。

### 交互

4 个屏幕空间交互目标（苔灯/水灯/风铃/苔猫），悬停 62 design px 标记，左键/E 触发。触控反馈：
- 灯：亮/暗 + 闪光 + 暖光池；
- 风铃：摆动 + 星屑 + 玻璃三连音；
- 猫：抬头/摆尾 + 眨眼 + 暖尘 + 呼噜。

### 体验

默认夜/晴/高画质；`N` 昼夜、`T` 晴雨、`Q` 画质、`P` 暂停、`R` 重置、`H` 收 UI、`F1` draw calls/primitives；底部四枚 HUD 药丸按钮等价。FPS 在实时窗口显示，截图中隐藏。

## 关键参数

- 逻辑视口 1280×720；可选 1920×1080；截图 1920×1080。
- 相机 default yaw 22° / pitch 35.5° / 21.5m / focus (0,2.15,0.30) / FOV 43°；自动环绕 0.85°/s。
- 岛顶 y=0；相机约束 14–39m；昼夜/天气指数过渡约 1.5s。
- 高画质粒子：萤火 104 / 浮尘 86 / 落花 34 / 雨 460；蒸汽 9；低画质落花 18 / 雨 210。
- 光照：夜冷月 1.36 能量 + fill 0.38 + 环境 1.12 × 冷蓝；日暖阳 1.46 + 环境 0.74 × 中性；FILMIC exposure 1.08→0.98。
- 交互锚点：灯 1.02m、猫 0.72m、风铃 -0.40m 偏移；点击释放容差 7px。

## 已知风险 / 未覆盖

- 参考为高密度手工视觉，本作是以 30fps 和原创性优先的低模程序化版本；细节密度与画质不属于 1:1 复刻。
- 1080p 实时窗口在本机被桌面限制为 1920×762；1080p 截图是 1920×1080 离屏，不应把其 capture FPS 当性能。
- 1080p HUD 可见 32fps 只比目标高 2fps；雨/多窗口/外部负载下可能压线，Probe 记录了 min 30。
- 视频无声；交互音效为程序化，未做混音/响度校准。
- 风铃在夜景中属于小物，主要靠 HUD 标记发现；没有移动端触控布局优化。
- FPS 在截图中隐藏（离屏 SubViewport 帧率无意义），运行时 HUD 默认显示。
- 未做 3A 后处理（Compatibility 下无体积雾/SSAO/SSR/TAA），所有光辉都是低成本近似。
