### 3. 主要问题与修复

| 问题 | 现象 | 处理 |
| --- | --- | --- |
| 相机相对移动纵向反向 | 在断桥物理行走用例中，按 `W+A` 没有向西走，导致后续遗物交互失败 | `_camera_relative` 改为 `right*x - forward*y`；smoke 增加真实跨桥用例 |
| 程序化武器遮挡 | Knight 的 `2H_Sword` / 盾未隐藏，画面像拿巨剑 | 按节点名隐藏全套武器、披风；只保留程序化雨伞 |
| 雨伞像“光环” | 手骨局部 Y 轴水平，伞横在腰间 | 每帧用全局 Basis 重新定姿；伞挂在 hand slot 但不继承手骨旋转；加高伞杆/加大伞面/偏移身体右侧 |
| 近侧墙体遮挡等轴视野 | 南/东高墙横跨画面，地砖发光边过粗 | 近墙压到 0.5m；墙顶发光条从整面顶盖改为 0.07m 薄带；地面 Shader 细缝变细 |
| HUD 数字越界 | `draw_string` 右对齐以宽度定位，HP/忆能数字飘到屏幕中间 | 数字框改为 `rect.end.x - 120`；HP 数值落在条内 |
| FX 环过亮遮人 | 弹反/开门/闪避时白色圆环像实体甜甜圈 | 环截面变薄、alpha/发光下调、扩散幅度减小；开门镜头前清掉旧 FX |
| 弹反截图只有静态预警 | 截图耗时超过 0.18s 窗，后续 `resolve_enemy_attack` 被当成未弹反 | 截图后把状态重设为 PARRY/parry_elapsed=0.04，再走真实判定；成功后立即轻击反击 |
| 断桥视觉被大圆环和旧敌人干扰 | 开门截图看不出桥，远处巡游者/伤害数字残留 | 移除桥上大 Torus；桥板改成青绿发光材质+扶手；开门镜头改从南侧看桥；清 FX、隐藏巡游者 |
| 1920 截图与实时性能混淆 | 1920 离屏 SubViewport 捕获慢 | 性能改用真实窗口采样；文档明确 1920 截图为离线捕获，不代表实时 FPS |
| 视频逐帧 PNG 太慢 | 10 秒只落了 22 帧 | 帧文件改用 JPEG(0.92)，同样 10 秒落 219 帧，再按 21.9fps 编码为 10.000s |

### 4. 验收证据

- **无头运行**：`godot --headless --path . --quit-after 600` → exit 0，无 ERROR/WARNING。
- **逻辑 smoke**：`DREAM_PARRY_SMOKE_OK checks=140`。
  - 0.18s 窗边界、弹反免伤/敌人硬直/+20 忆能、硬直内 ×2.2 伤害；
  - 0.26s i-frames、气力消耗、不可弹反丧钟；
  - 回梦 35 忆能→35 HP、重击、锁定；
  - 死亡 2.4s 后残梦灯复活、梦魇重置；
  - 幻象墙阻挡 → 遗物扣 25 忆能 → 桥显形 → 真实 WASD 跨桥不坠落 → 第二片；
  - Boss 条/半血二阶段/弹反硬直/胜利/重开/暂停。
- **真 GPU 截图**：7 张，均为 **1920×1080**，位于 `docs/shots/`：
  - `01_awakening_court` 探索
  - `02_parry_window` 弹反窗口（0.18s、预警圈、判定条）
  - `03_riposte` 完美弹反后失衡/反击
  - `04_relic_bridge` 窥梦断桥显形
  - `05_boss_dodge` 丧钟 AoE 与 i-frames 闪避
  - `06_boss_duel` 二阶段 Boss 对决
  - `07_victory` 结算
- **视频**：`docs/dream_parry.mp4` 10.000s / 1280×720 / H.264 / 219 帧；
  `docs/dream_parry.gif` 10s，960px 宽。内容按探索→弹反→闪避→遗物桥→Boss→结算剪辑。
- **性能**（真实窗口，vsync off，Intel HD 6000）：
  - 1280×720：醒梦庭 51.0 FPS，Boss 实战 **45.0 FPS**；
  - 请求 1920×1080 被 1440×900 桌面夹到 1440×762：醒梦庭 68.6 FPS，Boss 实战 **55.9 FPS**。

### 5. 已知限制

- 本机显示器为 1440×900，无法实测原生 1920×1080 窗口的实时帧率；1920 截图走离屏 SubViewport。
- 中文 HUD 使用系统字体；跨平台发行建议嵌入 Noto Sans SC。
- 无音频、无手柄、无磁盘存档、无标题菜单；重开窗口即从醒梦庭开始。
- Boss 以巨大“钟帽”剪影为主，身体可见度低于普通敌人；这是当前美术取舍，不是对比度 bug。
