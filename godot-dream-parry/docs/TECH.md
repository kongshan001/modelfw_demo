# TECH · 梦隙 · 残响

## 1. 目标与边界

- **类型**：原创 3D 等轴类魂动作 vertical slice，Godot 4.6 / GL Compatibility。
- **复刻边界**：只复刻等轴视角、雨伞武器、精准弹反、闪避 i-frames、共享资源、遗物解锁隐藏通路、
  记忆残片、魂系重生等**抽象机制**。所有专有名称、关卡布局、剧情文本、UI 构图、美术与程序化资产均为本项目原创。
- **不依赖**：第三方运行时库；没有复制参考视频的画面、音频或素材。参考视频仅提取类型语言（见 CREDITS）。
- **平台目标**：1280×720 逻辑分辨率；窗口可放大到 1920×1080；Intel HD 6000 上以 30 FPS 为最低设计目标。

## 2. 场景与流程

主场景 `scenes/main.tscn` 只有一个 `DreamWorld` 根节点；运行时构建：

| 区域 | 坐标/尺寸 | 内容 |
| --- | --- | --- |
| 醒梦庭 | 中心 (0,0,0)，16×16 | 出生点、残梦灯、石径、月门、梦树、水池、镜面、漂浮碎片 |
| 无名回廊 | z −8…−14，宽 5.2 | 连接 A/B 的低墙回廊，门洞拱 |
| 齿轮回廊 | 中心 (0,0,−22)，16×16 | 巡游者、第一枚残片、窥梦棱镜祭坛、齿轮墙、西侧幻象断桥 |
| 断桥秘园（隐藏） | 中心 (−17,0,−22)，6×6 | 只有遗物显形后才能跨过；第二枚残片 |
| 无钟之间 | 中心 (28,0,−22)，20×20 | 钟摆守梦人、棋盘地砖、巨钟、钟面；Boss 血条 |

- 出生点 `(0, 0.05, 3.4)`；两台残梦灯：起点 `(−2.7,0,4.2)`、门前 `(16.2,0,−21.3)`。
- 房间高墙根据等轴相机方向做“近墙压低、远墙做剪影”：南/东侧 ≤0.54m，北/西侧 2.5–3.0m。
- 物理层：`world=1`、`player=2`、`enemy=4`。地面/墙/断桥/幻象墙都是 StaticBody3D。
- 离地保护：玩家 y < −2.5 时回到最后残梦灯。

### 流程状态

`DreamWorld.run_state`：

```
PLAYING ── 玩家 HP=0 ──> DEAD ── 2.4s / R ──> PLAYING（最后残梦灯）
PLAYING ── Boss 死亡且记忆残片=2 ──> VICTORY ── R ──> 全新一轮
```

- 梦碎：普通梦魇与仍存活的 Boss 重置；已拾取残片、遗物、已显形断桥保留。
- 休息：最后残梦灯更新、玩家满血、忆能至少 65、普通梦魇与仍存活 Boss 重置。
- Boss 已被击败时，玩家死亡不会让 Boss 复活；胜利判定在复活后的下一帧继续检查。
- `R`：游玩/梦碎时回最后残梦灯（保留拾取进度）；胜利后完整重开（残片/遗物/断桥全部重置）。

## 3. 玩家 FSM 与手感

`DreamPlayer` 状态：`FREE / ATTACK / PARRY / DODGE / HIT / HEAL / DEAD`。
动作由 `_physics_process` 以显式计时器推进，动画只做表现，不决定命中帧。

### 核心参数

| 常量 | 值 |
| --- | --- |
| 最大梦血 / 气力 / 忆能 | 100 / 100 / 100 |
| 初始忆能 | 55 |
| 移动 / 锁定移动 | 4.8 / 3.9 m/s |
| 轻击：气力/伤害/射程/命中帧/总时长 | 14 / 12 / 2.75m / 0.16s / 0.48s |
| 重击：气力/伤害/射程/命中帧/总时长/按住阈值 | 26 / 26 / 3.15m / 0.34s / 0.82s / 0.32s |
| 弹反：有效窗/总时长/气力/冷却/成功回能 | **0.18s** / 0.45s / 8 / 0.16s / +20 |
| 闪避：i-frames/总时长/气力/初速 | **0.26s** / 0.42s / 22 / 9.6 m/s |
| 回梦：忆能/治疗/结算点/总时长 | **35** / 35 HP / 0.38s / 0.80s |
| 挨打无敌 / 受击硬直 | 0.65s / 0.36s |
| 气力回复 | 动作结束 0.55s 后 23/s |
| 忆能自然回复 | 1.35/s；命中 +4/+7；完美弹反 +20 |
| 反击倍率 | 硬直窗口内 ×2.2（由敌人结算） |

- **移动方向**：相机相对。`W` = 屏幕上方/远离相机；`A/D/S` 同理；等轴下 `W+D` 为世界北。
  （曾出现纵向反向 bug，由断桥实际行走 smoke 用例捕获并修复。）
- **攻击**：按下左键蓄力；松开时若 <0.32s 为轻击，否则重击。命中帧到达时做范围+朝向检测，
  可同时命中多个敌人。攻击中不可弹反/闪避（保留“承诺帧”）。
- **弹反**：`is_parry_active() = state==PARRY and parry_elapsed <= 0.18`；面对敌人 ±90° 内有效。
  成功后立即转 FREE、回能、短无敌；镜头轻震并生成金色环/火花。敌人进入长失衡并开放反击窗。
- **闪避**：无方向输入时朝锁定目标的反方向（无锁定则朝后）。前 0.26s 伤害全免；
  与敌人攻击帧重叠时算闪避成功。锁定后朝目标方向做移动，仍保持朝向。
- **回梦**：施法期间不能移动，0.38s 结算；被打断则不回血、忆能已扣。
- **死亡**：禁用碰撞层、播放 Death_A、发出 `died`；由世界负责 2.4s 后复活/覆盖层。
- **锁定**：15m 内最近存活敌人；锁定后朝向目标、移动减速、相机构图向目标偏 16%。
- **UI 提示**：敌人在起手且距离 <9m 时显示右键弹反或空格闪避（不可弹反的 AoE 明确提示闪避）。

### 外观

- KayKit `Knight.glb` CC0，模型缩放 0.96；隐藏 `1H_Sword` / `2H_Sword` / 盾 / 披风。
- 雨伞是程序化几何：木/金属伞杆、奶油色伞面、金色伞骨与伞缘、青绿宝石。
  伞挂在 `handslot_r` 上，但每帧用全局 Basis 重新定姿，因此角色动画不会让伞变成“光环”或横插。
  待机时伞偏向身体右侧；弹反时伞面朝前打开；重击/轻击时随手臂扫击。
- 缺少模型/`DREAM_FORCE_PROCEDURAL=1` 时构建低模骑士 + 雨伞的回退，玩法不变。

## 4. 敌人 FSM / Boss

`DreamEnemy` 状态：`IDLE / CHASE / WINDUP / RECOVER / STAGGER / DEAD`。
起手阶段显示地面预警圈/盘；命中帧一次结算；受击不打断起手，但可破韧/弹反打断。

| 敌人 | HP | 韧性 | 速度 | 攻击 | 起手 | 伤害/射程 | 弹反 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 失忆巡游者 | 60 | 34 | 2.35 | 梦刃横扫 | 0.68s | 14 / 2.7m | 可 |
| 钟摆守梦人 | 160 | 86 | 1.9 | 钟摆重砸 | 0.88s | 22 / 3.35m | 可 |
|  |  |  |  | 丧钟领域（AoE） | 1.18s | 26 / 5.2m | **不可** |
|  |  |  |  | 逆钟回旋 | 0.72s | 17 / 3.55m | 可 |

- **破韧**：每次伤害累积 `最终伤害 × 1.05` 韧性；达到上限进入 0.95s 失衡（0.55s 反击窗）。
- **弹反硬直**：1.65s，反击窗 1.65s；硬直内受到攻击 ×2.2。
- **Boss 二阶段**：HP ≤50% 触发一次“第二声钟”；速度 ×1.18，起手 ×0.84，恢复后冷却降至 0.75s；
  HUD 目标/Boss 条显示阶段变化。
- **攻击令牌**：`DreamWorld.request_attack_token(enemy)` 保证同一时刻最多一个敌人起手；
  `RECOVER / STAGGER / DEAD` 释放。普通与 Boss 均接入。
- **预警可读性**：起手圈随进度放大，颜色橙金（可弹反）或紫（不可弹反）；命中前 HUD 同步给出键位提示。
- **攻击判定**：距离 + 140° 前向锥；玩家绕后可躲开近战。AoE 只查距离（丧钟不可弹反）。
- **Boss 表现**：Mage CC0 模型缩放 1.28、紫黑材质、悬浮钟面/指针/钟摆；手部挂程序化“钟摆权杖”
  （长柄+时钟环+分针刃）。Boss 门前有独立残梦灯，死亡后从门前重试，避免长途跑尸。

## 5. 类魂循环与遗物门

- **残梦灯**：2 个；按 E 休息，恢复梦血/气力/部分忆能并重置梦魇；玩家死亡自动在最后一个灯复活。
- **共享忆能**：回梦 35、断桥 25，共用同一池；没有独立药瓶数量，但忆能上限/回复速度决定资源有限性。
- **窥梦棱镜**：齿轮回廊祭坛交互获得；HUD 显示“已取得/断桥已显形”。
- **隐藏通路**：
  - 初始：`barrier_body.collision_layer=1`（挡住缺口），`bridge_body.collision_layer=0`（不可走），
    `bridge_root.visible=false`。
  - 断桥边按 E（需遗物，忆能 ≥25）：扣除 25 忆能，隐藏石桥显形；切换上述碰撞层，幻象墙视觉消失。
  - 显形是**永久**的（不因死亡/休息撤回，完整重开才重置）；避免玩家被关在桥中间。
  - smoke 既检查碰撞层，也用真实 WASD 行走验证“开门前被挡、开门后能跨桥不坠落”。
- **记忆残片**：固定 2 枚（齿轮回廊祭坛侧、断桥秘园）。E 拾取；HUD 计数 0/2→2/2。
  不需要击杀普通梦魇才能拾取，但巡逻者会守在第一枚旁。
- **胜利**：Boss 死亡 + 2 枚残片；满足后自动进入 VICTORY 覆盖层并停止计时。
- **重开**：胜利后 R 完整重置敌人、残片、遗物、断桥、死亡数和用时。

## 6. HUD / 输入 / 相机

### HUD

- `DreamHud extends Control`，CanvasLayer + 全屏锚点，`PROCESS_MODE_ALWAYS`。
- 以 1280×720 设计坐标绘制；`_draw` 里 `draw_set_transform(scale=viewport_width/1280)`，
  因此在 1920 SubViewport 下中文、血条、Boss 条仍清晰。
- 中文使用 `SystemFont`（PingFang SC / Hiragino / Noto Sans CJK / 微软雅黑回退），不随项目分发字体。
- 元素：梦血/气力/忆能、回梦与遗物成本、记忆残片计数、目标、弹反/闪避/反击提示、弹反判定条、
  Boss 血条与二阶段、交互提示、房间标题、教程、暂停/梦碎/胜利覆盖层。
- 梦碎/胜利时隐藏常规 HUD，只保留覆盖层；暂停保留 HUD + 半透明遮罩。
- HUD 在捕获模式下自动隐藏教程；截图工具关闭 FPS 读数。

### 输入

运行时在 `DreamWorld._setup_input()` 注册 InputMap（避免 project.godot 中手写事件序列化），
重复实例化不会重复添加：

| action | 绑定 |
| --- | --- |
| move_* | W/A/S/D（physical_keycode） |
| attack | 鼠标左键 |
| parry | 鼠标右键 |
| dodge | Space |
| heal / interact | Q / E |
| lock_on | Tab + 鼠标中键 |
| restart / pause | R / Esc + P |

鼠标事件经 `_unhandled_input` 进入；HUD `mouse_filter=IGNORE` 不吞点击。
暂停时 `SceneTree.paused=true`，玩家/敌人/FX 使用 PAUSABLE；World/HUD 使用 ALWAYS 处理 Esc 和重绘。

### 相机

- `Camera3D` 正交投影，默认 `size=14.3`；Boss 交战平滑到 16.2。
- 位置 = 平滑焦点 + `(10.8, 13.8, 10.8)`（约 42° 等轴俯角）。
- 焦点 = 玩家脚中心 + 1.15m 朝向前瞻；锁定/Boss 战场额外向目标偏 16–18%。
- 弹反/受击用 `h_offset/v_offset` 做短促镜头震动，不影响逻辑。
- 截图/视频工具通过 `set_film_camera(pos, look, size)` 覆盖自动跟随，便于固定构图；不进入游戏逻辑。

## 7. 资产 / 渲染 / 性能

### 模型与许可

| 文件 | 用途 | 许可 |
| --- | --- | --- |
| `assets/models/kaykit/Knight.glb` | 玩家基础骨架，挂程序化雨伞 | CC0 1.0（KayKit, Kay Lousberg） |
| `assets/models/kaykit/Rogue_Hooded.glb` | 普通梦魇，紫红材质 + 程序化刃 | CC0 1.0 |
| `assets/models/kaykit/Mage.glb` | 钟摆守梦人，紫黑材质 + 钟摆权杖/钟面 | CC0 1.0 |

所有角色都保留程序化低模回退（`DREAM_FORCE_PROCEDURAL=1` 或资源缺失时自动启用）。
程序化关卡、雨伞、权杖、UI、特效、Boss 钟面等均为原创。细节见根目录 `CREDITS.md`。

### 渲染取舍（Intel HD 6000）

- GL Compatibility；无 MSAA、无阴影贴图、无 SSAO/屏幕空间反射。
- 地面使用单个 ShaderMaterial + PlaneMesh，按世界坐标生成格子/细缝，房间仅 1 个 DrawCall；
  避免 1m tile 大量节点。
- 只有 1 个主方向光 + 1 个冷色补光 + 4 个无阴影 OmniLight；角色/敌人用程序化软阴影贴片。
- 漂浮碎片、齿轮、蜡烛/花/残片等是少量 MeshInstance；3 组 CPUParticles 尘埃；没有实时 GI。
- HUD 在 1920 下按 1.5× 绘制，不重导入大图。
- 环境：Filmic tonemap、低密度雾、无音量/无后处理 Glow。

### 实测（Intel HD 6000, macOS, Godot 4.6, vsync off）

| 运行方式 | 尺寸 | 醒梦庭待机 | 无钟之间 Boss 实战 |
| --- | --- | --- | --- |
| 真实窗口 | 1280×720 | 51.0 FPS | **45.0 FPS** |
| 真实窗口（请求 1920×1080，被 1440×900 屏幕夹取） | 1440×762 | 68.6 FPS | **55.9 FPS** |

p95 帧时间约 39ms（1280） / 23ms（1440）。目标“Intel HD 30 FPS+”在可实测的窗口下满足。
**注意**：本机显示器是 1440×900，无法验证原生 1920×1080 窗口的实时帧率；
`docs/shots/` 的 1920×1080 截图是用 1920 离屏 SubViewport 渲染的（离线捕获，不代表实时 FPS）。
在更大显示器上建议先跑 `tools/perf_dream_parry.gd` 复核；如低于 30 FPS，可降低窗口分辨率或把
`Camera3D`/渲染缩放调低。

## 9. 已知限制 / 风险

1. **1920 原生实时帧率未实测**：本机屏幕限制；截图管线能在 1920 渲染，但离线捕获慢，不能当作实时性能承诺。
2. **中文字体依赖系统**：当前用 macOS 的 PingFang/Hiragino；Linux/Windows 发行版应随包附带
   Noto Sans SC 或改用嵌入字体，否则可能回退为缺字。未引入第三方运行时库。
3. **Boss 外形偏剪影**：Mage 的头部/帽体很大，Boss 主要靠巨帽、钟面、钟摆权杖和血条辨识；
   这是有意的“钟/帽”合成剪影，不是参考作品角色。
4. **无音频/手柄/标题菜单**；项目进入即游玩；没有磁盘存档，重开窗口即全清。
5. **玩家与敌人身体不互相碰撞**：攻击用距离+扇形结算，避免推挤破坏等轴读招；并非漏配碰撞。
6. **1920 截图中的 HUD** 是同一套 1280 逻辑按 1.5× 绘制，非另做 1080 UI。
