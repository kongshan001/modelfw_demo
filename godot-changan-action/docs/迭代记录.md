- 头部无 UI 素材自绘 HUD；中文；键鼠 + 基础手柄映射。

**问题与修复**
1. **角色全部掉出地面**：首版只建了地面视觉 mesh，没有 `StaticBody3D`；调试截图发现玩家 y=-1.10、敌人 y=-3.19。修复：加入 26.5×0.4×92m 地面碰撞体。修复后 AABB 脚底 y≈0。
2. **HUD 对话报错**：HUD 引用不存在的 `main.dialogue_line`；改为 `dialogue_lines[dialogue_index]`，并给结果文本换 `draw_multiline_string`。
3. **C 风格三元表达式**：`warm ? A : B` 在 GDScript 不合法，改为 `A if warm else B`。
4. **`find_child` 类型搜索错误**：`find_child("*","Skeleton3D",...)` 不支持；改为 `find_children(...)[0]`。

**smoke**：首版 73 断言；攻击命中测试因先设置敌位再被竞技场 clamp 而漏检，改为先传送到竞技场再放敌人后通过。

## v0.3 性能：从 327 draw calls 到 ~150–200

**实测问题**
- 首轮 `probe_fps` 1280×720：avg 15.6 / min 3.0；draw calls 327。
- 逐帧卡顿探针显示 0.6–1.1s 卡顿也会发生在无任何特效时，宿主 load average 7–50（Lark/Blender/其他 agent），测量噪声大。

**优化**
1. `scaling_3d/scale` 0.85 → 0.75 → **0.65**。
2. 6 个摊位从 ~60 draw calls 合批为 7 个 MultiMesh；酒坛/竹筐/火盆/广场灯串/街灯杆件合批。
3. 街灯只让最近一盏用实光（远处保持 emissive）；广场灯串在 Boss 熄灯时启用。
4. 灯笼 halo 从 1.15m/alpha .30 缩到 0.42m/alpha .16；街灯 halo 2.8→1.6m；广场 1.6→0.95m。
5. ProceduralSky → `BG_COLOR` 夜空 + 星点，约省 5–7 fps。
6. 相机 SpotLight → 玩家 Omni 补光（range 11），降低屏幕覆盖。
7. VFX：共享 flash/ring mesh+material、`GeometryInstance3D.transparency` 淡出；火花 4 个对象池；伤害数字 6 个 Label3D 对象池；敌人受击闪共享 material；火油改为 1 个 billboard 火舌 + 1 个油迹（原 5 根锥体 + 每根独立材质）。
8. 摊位 `visibility_range_end=44m`。

**结果（1280×720，无 VSync，Intel HD 6000）**

| 场景 | avg | min | draws |
| --- | ---: | ---: | ---: |
| **最终 verify.sh（代表战斗）** | **37.4** | **25.0** | 198 |
| 街道 idle + HUD（load 17.7） | 30.1 | 22.0 | 167 |
| 代表战斗 1（load 20.7） | 33.6 | 7.0 | 181 |
| 代表战斗 2（load 12.5） | 36.5 | 5.0 | 198 |
| 旧连续压力（优化前，load 22.8） | 20.8 | 1.0 | 190 |

- **最终回归通过**：`CHANGAN_FPS avg=37.4 min=25.0` + `CHANGAN_FPS_OK` + `CHANGAN_VERIFY_OK`（Intel HD 6000，1280×720）。
- 负载高时 min 会抖到 3–7；`probe_hitch` 记录 `HITCH dt=662.0ms at=1.82s action=none`、`HITCH dt=1149.9ms ... action=attack`，说明宿主争抢是主要噪声。发布前建议空闲机器复跑。
