# 战斗背景地图与战场地面改造计划

## 对比分析

- 梦幻战斗背景是**整张绘制的自然地形/宫殿地面**：林地、洞窟、石板地，有透视、光影、环境细节；没有明显的方形战术格。
- 当前实现：竹林背景 + 一块矩形石台 + 均匀方格 + 描金边框；石台像“漂浮的战术板”，和竹林没有融合，视觉上更像 demo。
- 独立美术评审：整体平均亮度约 104/255、饱和度 24%，低于梦幻的明亮鲜艳；敌方前排落在竹影暗带。
- 目标：保留现有 2.5D 斜向阵型、单位/ HUD/交互不变，只重做背景地面，使战场成为“竹林里的一块自然空地”。

## 改造方向

1. **去掉矩形战场格**：移除矩形石台、描金边框、均匀方格；改为边缘不规则、带透视的林间空地。
2. **地面分层**：远景草/雾 → 中景泥地/苔藓/石径 → 近景草；远侧降饱和，近侧更暖，和竹林/山雾衔接。
3. **环境细节**：石头、竹根、倒竹、落叶、小花、浅溪/石径、竹影、光斑；不要压住单位脚底和 HUD。
4. **战场锚点**：保留一个很淡的圆形/石环中心纹样（非网格），给阵型一个“场地中心”。
5. **光照/色彩**：提高整体亮度与饱和度（目标平均亮度 ≥135、饱和度 ≥35%）；左上敌侧加暖光；暗角 0.4→≤0.2。
6. **可读性**：单位脚底阴影、HUD/日志对比度、地面不要过于花；敌方后排仍落在受光地面。
7. **不改**：`core/`、`data/`、golden、阵型位置/深度/视图、HUD 布局、交互。
