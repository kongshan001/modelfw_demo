结论先行

先给答案：打击感 = 多层反馈 × 节奏对比

打击感不是“屏幕震动越大越好”，而是接触瞬间的多层反馈叠加，乘上整段攻击的节奏对比。单层拉满一定翻车：只有震动会晕，只有顿帧会卡，只有特效像烟花，只有声音像配音秀，只有伤害数字像表格。真正让玩家觉得“打到了”的，是同一帧里至少三层同时成立，并且在连招里有轻有重、有流有顿。

01
先做“对面”

受击后仰、折身、击退、硬直先成立，再加火花与闪白。视频原话：“你砍他，他得退，得飞出去。”

验收：把特效全关，敌人还像被打到吗？

02
刀要停，但只停一下

接触帧冻结 2–13 帧（按轻重），停完必须有回弹与收招。没有“咬住”的一瞬，就是砍棉花。

验收：关掉顿帧，是否立刻变轻？

03
声音是半条命

破空 → 接触瞬态 → 低频身体 → 材质/环境尾音。四层齐全，瞬态对齐接触帧。

验收：静音后还能“感到”重量吗？

04
每一下不一样

轻/中/重/终结的顿帧、震动、击退、音高、特效规模全部递增；不要所有攻击同一套。

验收：闭眼听，能听出哪一下最重吗？

05
节奏是“浏漓顿挫”

连招是“流—顿—流—重顿—留白”的句子，不是每一下都最大；最后一击加重，前面留白。

验收：一套连招里有弱拍和休止吗？

06
相机是标点

短促、方向性、快速衰减；只给重击/终结/受击。震动是标点，不是主句。

验收：关掉震动，是否仍然成立？

07
可读性 > 华丽

命中反馈不能遮住下一次起手、敌人轮廓与弹幕。最花的特效下也要能读招。

验收：最花的时候还能看清下一招吗？

08
参数化 + 可审计

每一击的顿帧/震动/闪白/击退/音效层写进数据；提供震动/闪烁/音量选项；用 A/B 与逐帧证据验收。

验收：5 分钟内能改一套参数并做 A/B 吗？

02

九层拆解

每层：玩家感知 / 缺了会怎样 / 参考参数

一条实用的记忆链：对面动 → 刀咬住 → 响一声 → 镜头顿一下 → 数字/特效确认 → 收得住。九层不必每层都重，但核心三层（受击反应、hitstop、声音）不能空。

LAYER 00

预备 / 起手 可读性

感知：从姿势、武器轨迹、音效、地面预警读出“要来了”。

缺了：只能背板；第一次见必吃；高难度下像读指令。

起手 0.25–0.6s · 预警 ≥0.35s · 输入缓冲 0.1–0.2s

LAYER 01

接触判定 可信

感知：“这一刀确实碰到了”，而不是穿过敌人后才掉血。

缺了：判定不可信；玩家开始猜而不是看。

hitbox 与视觉误差 ≤1 帧 · 多段间隔 ≥0.08s

LAYER 02

hitstop / 顿帧 重量

感知：刀切进去“卡住”一瞬，时间被压扁。

缺了：砍棉花、砍空气；轻武器像挥塑料。

轻 33–67ms · 中 67–117ms · 重 133–217ms · 终结 200–333ms

LAYER 03

受击反应 传递

感知：后仰、折身、后退、硬直、浮空、倒地；不同材质不同反应。

缺了：敌人像木桩/贴图；数字再大也没有传递感。

硬直 0.15–0.8s · 击退 0.1–1.5m · 方向=命中方向

LAYER 04

命中特效 接触点

感知：接触点在哪里、什么材质、能量多大。

缺了：打击“干”；过量则遮挡起手，变成光污染。

闪白 1–6f · 火花 0.15–0.4s · 8–24 粒子 · 全屏白 ≤2f

LAYER 05

声音 半条命

感知：重量、材质、距离、方向；低频“砸进胸口”。

缺了：视频原话——“就是没声音”；静音测试会暴露视觉层不足。

破空 / 瞬态 / 低频 40–120Hz / 尾音 · 瞬态 ±1 帧

LAYER 06

相机 标点

感知：冲击的方向和规模；画面“被打了一下”，但不抢控制权。

缺了：平；过量则晕、看不清、3D 眩晕。

trauma 0.08–0.6 · 位移 0.2–2.4% 视口 · 衰减 1.5–2.5/s · 推拉 2–10% FOV · 停顿 1–3f

LAYER 07

数值 / UI 确认

感知：伤害大小、暴击、连击、回复、命中确认。

缺了：不确定是否生效；数字太多则变成表格游戏。

数字 0.5–1.2s · 连击 1.5–2.5s · hitmarker 0.05–0.1s

LAYER 08

余韵 / 收招 呼吸

感知：动作完整、力量释放、收得住；最后一击有回响。

缺了：动作断头、飘、连招衔接生硬；玩家不知道还能不能接。

收招 0.15–0.4s · 拖尾 0.1–0.25s · 取消窗 0.1–0.25s

提示：在实验台关掉某一层时，这里对应的卡片会变暗，方便对照“缺了会怎样”。

03

节奏：浏漓顿挫

杜甫写的是剑舞；我们借来谈游戏节奏
大历二年十月十九日，夔府别驾元持宅，见临颍李十二娘舞剑器，壮其蔚跂，问其所师，曰：“余公孙大娘弟子也。”开元三载，余尚童稚，记于郾城观公孙氏舞剑器浑脱，浏漓顿挫，独出冠时。…… —— 杜甫《观公孙大娘弟子舞剑器行（并序）》，《全唐诗》卷 222（公版）。作于大历二年 / 767 年，写公孙大娘剑器舞，不是游戏术语。
浏漓 = 流

连招衔接、取消窗口、移动/追击、武器轨迹的连续。让玩家觉得“顺手、不断线”。

顿挫 = 停

接触帧 hitstop、受击硬直、方向转折。让力量“咬住”，给玩家确认。

两者必须有对比

流让连招成立，停让每一刀成立。全流=飘，全停=卡；只有流+停交替，才有“浏漓顿挫”。

为什么不是每一下都最大

  • 对比原则：重量来自差异。每一下都停 200ms，等于没有轻重。
  • 习惯化：持续大震动/大闪白会被大脑过滤，还会造成视觉疲劳与晕动症。
  • 可读性：长顿帧夺走反应时间；连续攻击中每段都长停，会看不清下一招。
  • 输入响应：顿帧本质是“延迟”。只在命中瞬间可接受；空挥/连段中过长会像掉帧。
  • 音乐性：连招是乐句，需要弱拍、强拍、休止；全是强拍等于没有拍。
