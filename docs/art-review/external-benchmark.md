## Top 5 差距（每条：问题 → 证据 → 根因 → 改法 → 验收）

### G1 · 材质/色阶停在“3 阶平涂”（差两档+，最致命）

**问题**
1× 下角色仍像矢量贴纸：teal 布料只有 base/shade/light 三块，纸/木/布/皮在 1× 不可分；皮肤没有 SSS、金属只有 2 阶高光、头发是 1 块色+1 条高光。参考在同尺寸有连续渐变、布褶、发丝、珠光、边缘反射。

**证据**
- 27 个 L\* 分箱 vs 梦幻 46 / 闪耀 45；teal 三簇占 28.6%，中间无过渡（§3）。
- 暗部色相偏移 **+8°** vs 梦幻绿 **+18°**；我方阴影更接近“同一色变暗”，不是“受环境影响的冷影”。
- 1× 材质签名 <3px（R2 P1-3 未修）；墨色族 7.02% bbox，外轮廓我测扫线中位 2px@720（≈3px@1080），局部 3–4px。
- 近景 `bench_03_material_100pct.png`：我方帽/脸/肩只有 3 阶 + 1 条墨线；参考有发丝 5–7 束、眼/唇/腮红 3 层、金饰 2 阶高光、皮肤 SSS。

**根因**
渲染是“平涂 fill + 硬 shadow + 墨线勾边”，没有 form shadow / AO / rim / 环境反射；细节预算按 local 尺寸给，没有按“最终屏幕 ≥3px”折算；材质签名只在大面积 200% 才出现。

**改法（参数）**
- **色阶**：每材质从 3 阶升到 **6–7 阶**（deep / shade / base / light / highlight / reflected / SSS），大面积布料至少 5 阶可见；色阶之间用 2–3px 软过渡，不要硬边。
- **阴影色相**：暖材质阴影向红紫偏 **−10°~−15°**；绿色布料暗部向青蓝偏 **+15°~+20°**（对齐梦幻 +18°）；阴影明度不低于 base 的 L\*−25，避免“黑块”。
- **光照/材质**：AO 12% multiply；轮廓光 2px、α 0.5、色温 6500K；金属 4 阶 specular + 1 条环境反射；皮肤加 8–10% 红润 SSS；头发 3–5 束高光带。
- **5 个 1× 材质签名**（沿用 R2，但必须 ≥3px）：木 2 条年轮（0.8px `#9a653f` 60%）、布 1 条褶+下摆 2px 阴影、皮 1 排针脚（0.8px `#d1a06a`）、金 2px 高光+2 铆钉、纸 1px 切边+1.5px 层影。
- **线**：外轮廓 2.5–3px @1080（比我方当前局部 4.5–6px 更收），内结构 1.5px 用 shade 不用 ink，细节 1px 仅在屏幕 ≥3px 区域；墨色族 ≤6.5%。

**验收**
3 名未见过项目者在 1× 角色上说出 **≥4/5 材质**；截图中每个大面积材质 **≥5 个可见 L\* 阶**；暗部色相偏移 ≥15°（绿）/≥10°（暖）；墨色族 ≤6.5%；200% 仍能看到纸纤维/切边；95px 卡不糊。

### G2 · 姿态/动画是“对的动作”，不是“好看的表演”（差一档）

**问题**
待机是静态对称 A-pose；walk 支撑脚不滑了，但步幅只有 3.0%H，25% 下脚位移 2.4px，读成原地碎步；最显眼的运动是刀（刀尖 91px=28.6%H），不是腿；攻击只有 3 个关键帧，预备/冲击/跟随不成立。

**证据**
- walk 复评：落点差 9–10px/318px = **3.0%H**；抬脚 22px；8 keys / 0.82s；刀尖 91px；25% 脚位移 2.4px。
- `03_actions.png`：4×3 关键帧能读“动作类别”，但缺预备/过冲；待机、行走、攻击的手臂差别小。
- 参考静态图（mhxy 施法、以闪舞蹈、长安叉腰）都有明确 contrapposto / 重心偏移 / 手部目的性；动画时间轴不可测，不评帧率。

**根因**
共用骨架 + 对称站姿；walk 为守 2px 门把摆动端点做成零位移；剑臂与自由臂同幅；没有 authored breakdown / 次级运动。

**改法（参数）**
- **待机**：肩线 6–8°、髋线 5–7°、头 3–5° 偏移；一只手有目的（扶帽/按剑/垂腕），不要双臂对称；加 2 个次级件（披风/发/飘带），滞后 **2 帧**、幅度 4–6 local。
- **walk**：周期 16–24 帧（0.53–0.80s），8 个 pose + 2 个 breakdown；展示用 **root motion**，步长 **12–16%H**（38–51px @318px），每周期前进 96–128px；镜内若不位移，用“玩具兵踏步”，渲染落点差 **≥16px @100% / ≥4px @25%**，支撑脚仍 0px。
- **持剑臂** ≤±8°，或改 point-down carry；刀身摆角 ≤15°，刀尖 ≤25px @100%（≤6px @25%）。
- **攻击**：6–8 keys / 0.6–0.8s；预备 3–4 帧（反向蓄力 8–12°）、冲击 2 帧、跟随/过冲 8%、恢复 6–8 帧；弧线跟剑尖路径。

**验收**
3/3 盲测看 100% 侧向 2s 说“走路”（不是挥刀）；25% ≥2/3 说“走/踏步”；contact 两靴前后 ≥16px@100% / ≥4px@25%；刀尖 ≤25px@100%；4 动作在 640×360 不读字 3/3 可辨；8 向探针 8/8 ≤2px。

### G3 · UI 信息层级：66 个控件同权，17 槽平铺（差一档）

**问题**
首屏三栏（试衣镜/衣柜/阵容）视觉权重相同；17 个槽位平铺 4 列，无分组标题/色条；16 张阵容卡与主编辑区同权；顶部 3 个随机入口并列；没有唯一主 CTA。玩家第一眼不知道“先看哪、先点哪”。

**证据**
- 66 个可聚焦 Button（QA `buttons=66`）；17 槽 + 5 变体 + 6 色 + 8 向 + 4 动作 + 16 卡 + 3 随机 + 存/读 ≈ 65+。
- 参考：以闪 ≈18 个可见控件（左图标栏 + 底部 10 图标）；梦幻面板 ≈30（页签+图标，但分组清楚）；长安 ≈20（左栏/右任务）。
- 我方对比 5.01–7.0、最小 11px 已达标——**不是可读性失败，是层级失败**。

**根因**
所有控件同一纸卡样式、同一字号、同一间距；产品把“可编辑项多”直接铺到首屏；没有主/次/三次级。

**改法（参数）**
- **分组**：17 槽 → **4 组**（头/身/手/背），组标题 20–22px + 3px 色条；组内 2 列，间距 12–16px。
- **层级**：同屏只保留 **1 个主 CTA**（保存/载入）+ 1 个次 CTA（随机）；其余收进抽屉/页签；首屏可见控件 **≤35**。
- **字号阶梯 @1080**：标题 34–40px / 组标题 22–24px / 正文 16–18px / 微标签 14px；面板内边距 20–24px，面板间距 16px。
- **16 卡**：移入可折叠“阵容”抽屉（4×4 仍可键盘可达）；卡上只留名字 + 1 个状态角标。
- **随机入口**：合并为 1 个“随机”主按钮 + 下拉（整偶/本槽/阵容）。

**验收**
首屏可见交互控件 ≤35；3 名未见过项目者 3 秒内说出“换装/捏纸偶”并找到保存；Tab 可达 16 卡且焦点环可见；小字 ≥16.5px 且 ≥4.5:1；17 槽 4 组全部有标题；无 9px 文本。

### G4 · 构图/主视觉：舞台只占 23%，画面是“工具”不是“舞台”（差一档）

**问题**
1280×720 中试衣镜面板仅 350×608 = **23.1% 屏**；中心衣柜 21%、右侧阵容 37%、顶栏 10%；主视觉被三栏切碎，角色像“面板里的预览图”，不是 hero。参考以闪舞台占 **73%**、长安内置场景 ≈90%，UI 退到边缘图标栏。

**证据**
- 我方 23.1%（§3）；角色高/面板高 52%，而参考以闪 86%。
- `bench_02_screen_25pct.png`：25% 下我方第一眼是“很多白色面板”，参考第一眼是“人和光”。
- 参考的负形：以闪角色周围 40% 以上是暗场/粒子/光；我方角色周围是按钮和色卡。

**根因**
信息架构把“编辑控件”和“展示”放在同一层；没有 hero 区/边缘 UI 的分区；所有面板用同一种纸卡，导致没有视觉焦点。

**改法（参数）**
- **主视觉** ≥ **50% 屏**（≥960×540 @1080）；角色 ≥ **70% 舞台高**（≥378px @540 舞台）；其余 UI 退到左/右图标栏 + 底部条。
- **三栏改两区**：左/下为编辑（可折叠），中间 60% 为舞台；阵容卡抽屉化。
- **负形**：角色周围至少 25% 的留白/暗场，不放色卡与文字；背景 4 层（环境渐变/中景剪影/地面材质/前景粒子或暗角）。
- **焦点**：1 个主 CTA；主标题 34–40px；角色名 24px；其余 ≤18px。
- **不要**缩小主角色去适配 150–200px 目标：该目标若指卡片，当前 95px@720≈142px@1080 略低于下限，建议卡面 +8%（≈154px）；主试衣镜 317px@720≈475px@1080 应保留。

**验收**
舞台占屏 ≥50%；25% 缩略图第一眼能看到角色而非面板；3 人测试 3/3 说出“角色展示/换装舞台”；角色与背景轮廓在 25% 可分离；UI 不遮挡角色 ≥90% 身体。

### G5 · 舞台/光照/VFX：3 层背景 + 1 条弱弧（VFX 差两档+）

**问题**
舞台是平纸面 + 太阳圆 + 接触影，没有环境色反弹、暗角、粒子、前景框架；轮廓光弱；斩击只有一条细弧，金核 #ffd27a 对舞台 1.22:1，640×360 下读不出“打中了”。

**证据**
- 背景 3 层 vs 参考 4–6 层；ΔL\* 32 vs 以闪 ≈55；R2 斩击金核 1.22:1、弧线偏细。
- 参考：以闪暗场 + 金色轮廓光 + 12–24 粒子；梦幻金粉/紫粉环境光 + 面板描边；长安 4 层气泡/远景/前景叶。
- 我方 sparkles 4–6px，攻击帧无冲击 hold；`03_actions.png` 的挥击帧弧线存在但不构成“力量”。

**根因**
灯光只有“主光+接触影”，没有 rim/bounce/vignette；VFX 只有单层弧，颜色对比不足；没有 impact frame / 屏幕反馈。

**改法（参数）**
- **舞台 4 层**：环境渐变（纸色→暖灰）+ 中景剪影（远山/木架/吊旗 2–3 个）+ 地面材质（纸纹/木板）+ 前景（暗角 8–12% / 粒子 12–24）；最多 2 个主光源。
- **光**：主光 45° 左上、5600K；轮廓光 2px、α 0.5、6500K；接触影 2 层（本影+半影）；环境反弹 8–12% 暖色；角色 vs 背景 ΔL\* ≥35，轮廓边缘对比 ≥3:1。
- **斩击 3 层**：核心 2px `#8f5f1f`（对纸面 ≈5.6:1）或 1px `#8f3030` 深边；辉光 8–12px、α 0.6；粒子 12–24、寿命 0.2–0.5s；在 640×360 下核心 ≥4px；寿命 0.22s，impact hold 2 帧，屏幕轻震 2–3px。
- **不要**用降低 AA/超采样换 VFX/帧率。

**验收**
640×360 GIF 不读字 3/3 能指出“命中帧”；斩击 ROI ≥3:1（核心不计装饰高光）；舞台 4 层在 100% 可数；25% 下角色轮廓与背景分离；FPS 不回退（洁净机 ≥30）。

## 风险

1. **参考图是商店宣传图，不是原生玩法截图**：含宣传大字、构图夸张，可能高估参考的 UI 与 VFX。缓解：角色用官网立绘；UI 只取内置面板；报告明确标注。
2. **比例/分辨率不同**：参考为竖屏 1242×2208 / 横屏 1242×699 / iPad 1600×1199，我方 1280×720。同高归一化会掩盖“屏幕密度”差异；因此材质/线宽结论按“最终屏幕像素”给，不按源像素。
3. **动画不可从静态图测**：参考的动画节奏、帧数、打击感 **NOT ASSESSED**；8.0 只代表静态姿态。下一轮若要对标动画，需抓官方视频/GIF 并逐帧。
4. **风格不同**：参考是 3D 写实/半写实，我方是 2D 纸偶；材质对比是“执行密度”对比，不是“像不像”。不要复制参考的深蓝舞台、金粉描边、3D 材质。
5. **8.7 是上限锚点，不是公开门**：我方公开试玩门仍是 7.0；本轮 6.1 说明“差一档”，不是“必须做到 8.7 才能发”。但材质/VFX 两档+ 的项要先补。
6. **UI 目标可能受产品定位影响**：17 槽/66 控件是功能需求；≤35 控件需要产品或策划拍板“哪些进抽屉”。本报告给的是视觉层级建议，不是砍功能。
7. **外部素材许可**：所有参考只做评审，不入库、不随包、不二次分发；若未来要引入外部资产，需单独核对许可/轴心/线宽/色板/过滤/光照。

## 仍不足（即使 P0/P1 全做，也仍存在）

1. **2D 纸偶 vs 3D 换装的上限差**：即使 6–7 阶 ramp 做满，单张 2D 图在 1× 的材质密度仍难追 3D 的连续光照/布料模拟。我们的身份应是“纸艺工坊”，不是“3D 暖暖”；目标是“高级纸偶”，不是“像 3D”。
2. **8 向 2.5D 的解剖限制**：参考是 3D 转台/多角度渲染；我方 8 向靠 yaw 压缩与 17 槽分层，侧向/背向的肢体转折永远不如 3D。需要接受“剪影可辨 + 2–3 个方向精致”，不是“每向都精美”。
3. **动画作者性**：8 个程序关键帧能过门，但“好看”需要动画师的预备/过冲/跟随/次级；本轮只给参数目标，不给“表演设计”。
4. **UI 仍是工具骨架**：即使舞台放大到 50%，17 槽/16 卡/换色/方向/动作仍是重编辑；要变成“玩具”，还需要产品层的首玩路径/角色卡/收藏（T-013 P0），不是美术单独能解。
5. **参考片只是表达标杆**：不复制参考的配色/描边/舞台；我们的纸/墨/珊瑚-青绿身份要保留，否则会变成“低配版梦幻”。
6. **本轮未做真人盲测**：25%/材质/构图结论是我的目检 + 数值，不是 3 人协议；下一轮必须补，否则“可读”仍是单人判断。
7. **未评音频/触感/加载/本地化**：这些不在美术 rubric，但会影响“外放品质”的整体感知。

---

## Verdict：**REJECT（对标；非 build 放行评审）**

- **总差距**：我方加权 **6.1 / 10**，参考均值 **8.7 / 10**，差 **2.6 = 一档**；其中材质（3.5）与 VFX（3.7）**差两档+**。
- **最致命 5 项**：G1 材质/色阶、G2 姿态/动画、G3 UI 层级、G4 构图/主视觉、G5 舞台/光照/VFX。
- **不是“角色看不清”**：25% 下剪影仍可辨；差的是“信息量/表演/舞台感”。
- **scope**：本结论只回答“与外部同类差多少”；不改变 R2 的 build REJECT，不替代 QA；下一轮按 P0 brief 先做 G1/G2/G3/G4，再复评。
- **最短路径**：材质 ramp + 姿态/动作 + 舞台 50% 重构 → 3 人盲测 + 25% 剪影 → 舞台光/VFX → 复评。
