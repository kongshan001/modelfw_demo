结论先行

先看这页，再看细节

这 10 个工具不是一条流水线，而是 1 条 Godot/Blender 主干 + 2 条离线管线（美术/3D、语音）+ 2 个实验（RL、VN）。一个人做 demo，先把主干跑通，再按需接外挂；10 个全上是反模式。

主线 · 已在用
Godot + Blender

Godot（当前 stable 4.7.2，MIT）负责玩法/出包；Blender（当前 stable 5.3.0，GPL-2.0-or-later）负责重拓扑/UV/绑定/GLB。继续现有管线，不上新运行时依赖。

当前可用
增强 · 离线外挂
Whisper + ComfyUI / TripoSR + OpenVoice

产出 SRT / PNG / GLB / WAV 后再导入 Godot。Whisper 本地 CPU 可跑；ComfyUI/TripoSR 需要云端 GPU；OpenVoice 需要本人授权。

值得评估
实验 / 不进主线
SB3 · ML-Agents · RVC · Ren'Py

SB3 只做离线训练/研究；ML-Agents 锁 Unity 6 + Python 3.10.1–3.10.12；RVC 只在有书面声音授权时用；Ren'Py 只适合纯剧情原型。

有条件使用
三句话选型：要可玩 → Godot 灰盒先跑通；要好看 → Blender 手工/云端 TripoSR 底模；要声音 → Whisper 字幕 + OpenVoice（授权）配音。RL/NPC 训练放在垂直切片之后，且只做实验。

视频 claim 核实

视频说法状态官方依据 / 前提
“10 个开源工具全覆盖”已验证10 个都有公开仓库与 LICENSE。但许可是 6 MIT + 1 Apache-2.0 + 2 GPL + 1 MIT+LGPL；“开源”≠“模型权重可商用”。
“TripoSR 在 A100 上 0.5 秒”已验证官方 README：less than 0.5 seconds on an NVIDIA A100 GPU。前提：单图、纯推理；不含贴图烘焙/导出/重拓扑/后处理。
“OpenVoice V2 免费商用”已验证官方 README：V1 and V2 are MIT Licensed. Free for both commercial and research use. 但声音本人的授权另需；官方安装以 Linux 为主。
“RVC 10 分钟语音就能训练”有前提官方 README 是“推荐至少收集 10 分钟低底噪语音数据”。是推荐值，不是质量保证。
“ComfyUI 4GB 显存可跑”厂商口径README 声称借助异步权重流最低 4GB VRAM + 8GB RAM；取决于模型/量化/分辨率。本机 Intel Mac 不适用。
“RVC 170ms 实时变声”厂商口径README 称端到端 170ms、ASIO 可到 90ms；依赖声卡/驱动/模型/硬件。
“ML-Agents 做智能 NPC”有前提它是训练工具包，不是即插即用 NPC；包 4.1.0 要求 Unity 6000.0+，Python 1.1.0 只支持 3.10.1–3.10.12；不支持 Godot。
本报告边界：只做调研与文档，不安装软件、不改项目；性能数字区分“官方文档 / 厂商声称 / 本机推断”；不复制视频画面/素材。所有 URL 访问日期为 2026-11-21。

主干引擎；MIT 无版税；仓库多个 demo。仓库现有 demo 多为 4.6，升级前先回归；继续 GL Compatibility / 1280×720 / 30 FPS 口径。验证：godot --version；跑一个现有 demo

建模/重拓扑/UV/绑骨/GLB；已有 blender-* 项目。本机版本以 blender --version 为准；导出 GLB 到 Godot 验证一次。验证：blender --version；小场景试 EEVEE vs Cycles

Unity ML-Agents

最小工作流

从概念到可玩 demo

一个人做 demo 的最短路径：先证明玩法，再换资产，最后加声音。AI 工具都在“换资产/加声音”阶段离线使用。

主线
概念/约束→ Godot 灰盒→ 可玩循环→ 内容替换→ Godot 出包
美术 / 3D
ComfyUI 概念图→ TripoSR 底模→ Blender 重拓扑/UV/绑骨→ GLB→ Godot
语音
台词表→ Whisper 字幕/校对→ OpenVoice 配音（授权）→ RVC 可选（授权）→ OGG
NPC
SB3 离线训练→ ONNX / 蒸馏→ Godot FSM/BT→ ML-Agents 仅 Unity
剧情
Ren'Py 纯剧情原型（可选）→ 验证文本/分支→ 决定是否迁回 Godot

实线 = 进主线；虚线 = 独立分支；所有 AI 产出都是离线文件，不进入游戏运行时。

最小可行组合

Godot + Blender + Whisper：覆盖“能玩 + 有资产 + 有字幕/台词”，全部本地可跑。

加视觉

云端 ComfyUI 出概念图，TripoSR 出底模；Blender 重拓扑后进 Godot。

加声音

OpenVoice（授权）出配音；RVC 只在有明确授权时加。

不要做

10 个全上；本地硬跑扩散/3D；克隆未授权声音；AI 资产不审查、不标识。

05

本机可行性

macOS · Intel HD 6000 · Godot + Blender

本机没有 CUDA，也没有 Apple Silicon 的 MPS；Intel 版 PyTorch 只能 CPU。所以 扩散/3D 生成/RVC 训练不在本地硬扛，把 GPU 放到云端。

工具本机说明
Godot（4.7.x）✅ 本地GL Compatibility；1280×720；现有 demo 可跑；仓库 demo 多为 4.6，升级前跑回归。
Blender（5.3.x）✅ 本地本机版本以 blender --version 为准；Intel HD 6000 上 EEVEE Next 历史实测不稳；Cycles CPU / 旧版 3.4.1 更稳；建模/GLB 导出不受影响。
Ren'Py 8.6.1✅ 本地极轻量，纯剧情原型首选。
Whisper / faster-whisper✅ 本地 CPUsmall/turbo + int8；large 在 Intel CPU 上会很慢。
SB3✅ 本地 CPU（小实验）CartPole/2D 小环境；图像策略/大网络建议 GPU。
OpenVoice⚠️ CPU 可但慢官方 Linux；建议远程 Linux GPU；需本人授权。
RVC 推理⚠️ CPU 可但慢训练不现实；需 NVIDIA GPU；需本人授权。
ComfyUI❌ 本地不实用无 CUDA/MPS；桌面版 macOS 仅 Apple Silicon；用云端 GPU。
TripoSR❌ 本地不可用无 CUDA；需云端 ≥6GB VRAM。
ML-Agents❌ 本地不推荐需 Unity 6 + Python 3.10.1–3.10.12；不进本仓库主线。
RVC 训练❌ 本地不现实需 NVIDIA GPU；仅有授权声音项目才考虑。
为什么：Intel HD Graphics 6000 没有 CUDA；macOS Intel 版 PyTorch 没有 MPS；ComfyUI/TripoSR/RVC 训练都依赖 NVIDIA GPU 才有实用速度。把 GPU 成本放到云端，本机只做 Godot/Blender/Whisper/SB3 小实验。
06

风险与合规

许可 · 权重 · 版权 · 声音 · 引擎 · 供应链

GPL 传染性

ComfyUI GPL-3.0 / Blender GPL-2.0-or-later：作为独立工具使用，产出资产一般不受传染；但分发修改版/打包进产品要遵守 GPL。不要把 ComfyUI 塞进闭源游戏安装包。

模型权重 ≠ 工具许可

ComfyUI 能跑不代表模型能商用；每个 HF 模型卡单独核对（FLUX.1 dev/schnell、SDXL、SD3.5 条款不同）。TripoSR/OpenVoice/Whisper 的权重是 MIT，RVC 底模 VCTK 声明需自行核对。

AI 内容版权与标识

AI 输出的可版权性因法域而异；保留人类创作痕迹。中国《人工智能生成合成内容标识办法》2025-09-01 施行；Steam Content Survey 要求披露玩家可见的生成式 AI 内容。

声音克隆授权

只使用本人或已签署授权的声音；写清用途/平台/期限/地域/删除机制；禁止明星、配音演员、同事、陌生人。技术能力不等于法律/伦理许可。

引擎绑定

ML-Agents 锁 Unity 6000.0+ 与 Python 3.10.1–3.10.12；迁 Godot 要重做推理/策略。SB3 进 Godot 需 ONNX/蒸馏/桥接，不要把 Python 训练进程作为发行依赖。

供应链与输出质量

ComfyUI 自定义节点是任意 Python 代码；只装可信来源、隔离环境、锁版本。模型优先 .safetensors，不要加载来源不明的 .ckpt。AI 输出必须人工审查拓扑/UV/贴图/语音 artifacts。

合规最小动作：① 建 CREDITS.md 记录工具/模型/素材/声音来源与许可；② 每个 AI 资产保留生成记录与人工修改痕迹；③ 声音授权书面化；④ 发布前按 Steam / 中国标识要求披露；⑤ 不把 GPL 工具打包进闭源产品。
