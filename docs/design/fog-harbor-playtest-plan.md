## 4. 流程（25–35 分钟/人）

| 阶段 | 时间 | 做什么 | 不做什么 |
| --- | --- | --- | --- |
| 开场 | 2 min | 只说“这是原型，不是考试；请边玩边想” | 不教规则/不解释设计意图 |
| A（vanilla） | 3 min | 同一场景/seed/出生点；**背包 22/24（高价值小件）**；附近有 1 个黑匣子和 1 个枪手；不出现手槽 | 不提示“按 E 扛起” |
| B（手槽） | 3 min | 同一场景/seed；**背包 22/24（高价值小件）**；黑匣子 + 枪手；手槽可用 | 不提示“按 E 扛起”（除非 UI 首次提示） |
| 追问 | 5 min | 问“刚才为什么扛/装包/放下？重来会改什么？” | 不问“好不好玩” |
| 收尾 | 3 min | 一句话描述、再来一局、最无聊/最爽 | 不争辩/不推销 |
| 记录 | 2 min | 填 §5 表 | 不补写“应该” |

**顺序平衡**：R1 的 5 人中 2 人先 A 后 B，3 人先 B 后 A；R2 反过来或保持平衡并记录。  
**同一场景**：使用现有 `demo_*` API 布置“背包 22/24（高价值小件）+ 黑匣子 + 枪手 + 撤离点”的固定场景；A/B 只差“手槽是否可用”，不差地图/敌人/掉落。  
**为什么 22/24 且高价值**：如果背包是空的，“装包”永远更优；如果背包里是廉价物，玩家可以丢掉廉价物腾格，手槽也会失去意义。22/24 高价值小件 + 黑匣子（2×2）逼出“丢一件贵的 → 装包” vs “扛手 → 保留全部”的真实选择。

**开场问题**：“你觉得这个游戏要你做什么？”“你第一眼最想点哪里？”  
**过程中**：“刚才为什么选这个，不选那个？”“如果重来一次，你会改变什么？”“有没有哪一刻不知道做什么？”  
**结束**：“用一句话向朋友描述这个游戏。”“你想再来一局吗？为什么？”“哪个时刻最无聊/最爽？”“只能保留一个机制，你保留哪个？”

## 6. 通过线（与 T-033 一致 + H1 特化）

- 首操作 ≤60 秒：≥4/5；
- 说得出核心动词（扛/放）：≥4/5；
- 至少一次有意义取舍（≥4/5 在 ≥2 个独立时刻选择扛/放）；
- 想再来一局：≥3/5；
- 能一句话转述：≥3/5；
- 因“不知道点哪/为什么不能开枪”卡住 >30 秒：0 次；
- 敌人/性能：无 P0 报错；性能回退 ≤10%。

**注意**：L1 灰盒只验证“选择/可读/早期再来一局”，不验证长线留存/美术/商业；5 人计数不是统计证明。
