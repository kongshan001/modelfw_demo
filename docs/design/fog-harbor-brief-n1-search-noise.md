## 0. 结论

- **What if**：What if 搜箱不是“按住 E 等 0.9 秒”，而是**快搜很响、静搜很慢**——敌人在雾里会循声来看？
- **一句话**：玩家反复在“快搜拿时间”与“静搜保安静”之间选择，因为每次搜索都会留下可见的铃声，敌人会来查看。
- **评分**：N3 D4 C4 F4 A4 = **19 / 25** → **L0 → L1（top 2）**；先 1 天 L0/10 秒灰盒，不直接 fast track。
- **状态**：提案；待独立红队/playtest；未实现；未批准。

## 1. 目标玩家 / 场景

| 项 | 内容 |
| --- | --- |
| 主目标玩家 | 搜打撤 / 潜行射击 / 短局 roguelite 玩家；喜欢“声音/信息”带来的紧张，而不是纯枪法 |
| 场景 | PC 1280×720，单局 6 分钟；键盘鼠标；可截图/10 秒 GIF 传播 |
| 非目标 | 依赖音频的硬核潜行、多人 co-op、全黑/听声辨位（可访问性差）；本轮不做 |
| 成功一句话 | “我知道那个箱子很肥，但我得先想清楚：快搜会把人引过来。” |
| 目标玩家证据 | 当前 build 搜索固定 0.9 秒（`loot_chest.gd`）、敌人只有 PATROL/ALERT/CHASE/ATTACK/STAGGER/DEAD（`enemy.gd:11`）、无音频；N1 用视觉铃声替代音频，不依赖声音设备。 |

## 2. 体验支柱与核心循环

**支柱（2–3 条，每条能拒绝方案）**：

1. **信息必须改变路线**：优先让“声音”改变搜哪个箱、什么时候搜、打不打；不做只加滤镜的雾。
2. **搜索不是免费的**：优先让搜索消耗时间或安全；不做“按住 E 就白拿”。
3. **可读优先于拟真**：优先让玩家看到“谁听到了”；不做纯音频/纯黑暗的不可读设计。

**核心循环**：

| 层级 | 循环 |
| --- | --- |
| 30 秒 | 靠近箱 → 选择快搜（0.9 秒、大铃声）或静搜（2.4 秒、小铃声） → 敌人转身/走来 → 躲/打/放弃 |
| 5 分钟 | 规划先搜哪个箱、在哪个巡逻间隙搜、要不要用枪声/冲刺制造诱饵 |
| 30 分钟 | 仓库/升级不变；变化的是每局搜索路线和“什么时候值得冒险搜” |

**删故事测试**：去掉剧情/美术/名字，只留灰盒，循环仍成立——因为“箱子 + 敌人 + 铃声”本身就能逼出“快/静”的选择。  
**但**：如果灰盒里玩家看不出“铃声 = 敌人会来”，循环不成立；所以 10 秒演示是硬门槛。

## 3. 独特动词 / 约束

- **新动词**：**控声 / 静搜**（支持动词：快搜、躲、打、制造噪声）。
- **新约束**：快搜 0.9 秒、铃声 280 px；静搜 2.4 秒、铃声 90 px；敌人进入 INVESTIGATE，前往最后噪声点；无音频依赖，用视觉铃声；墙不阻断声音（或只做简单距离）。
- **玩家因此放弃什么**：时间 vs 安全；不能又快又安静。
- **反馈**：搜索条显示“快搜 0.9s / 静搜 2.4s”；完成后橙色大铃声/青色小铃声；敌人头顶“?”、转身、走向声源；到达后四处看 1.5 秒再回巡逻；HUD 提示“敌人听到了”。
- **为什么是现在**：`FogLootChest` 已有 0.9 秒搜索计时；`FogEnemy` 已有 FSM/巡逻/视线/避障；`FogFX` 已有圆环绘制；只需加 1 个 INVESTIGATE 状态和 3 个噪声源，不需要音频/新敌人/新地图。

## 4. 首 10 分钟

| 时间 | 玩家看到/做什么 | 设计意图 |
| --- | --- | --- |
| 0–1 min | 第一个箱子附近没有敌人；提示“快搜 0.9s / 静搜 2.4s” | 首操作 ≤60 秒；先看到两种节奏 |
| 1–3 min | 玩家快搜；橙色大铃声扩散；320 px 外的枪手转身走来 | 10 秒内看到差异：声音 = 信息 |
| 3–6 min | 玩家躲到箱子后；敌人走到声源四处看；玩家学会“静搜/换箱子” | 第一次有意义取舍（时间 vs 安全） |
| 6–10 min | 精英箱附近有巡逻；玩家决定“快搜拿完就走”还是“静搜等巡逻过去” | 第一次 aha/风险钩子；撤离前再赌一次 |

## 5. 最小原型（范围锁）

- **级别/天数**：**先 L0 1 天**（纸面/灰盒 GIF），通过后 **L1 5–7 天**（5–6 天构建 + 1–2 天 5 人测试；工程需复核）。
- **复用**：搜箱计时、敌人 FSM/巡逻/视线/避障、FX 圆环、HUD、地图、现有截图/视频/性能工具。
- **只做**：
  1. 快搜/静搜两档（0.9s/2.4s；铃声 280/90）；
  2. 敌人 INVESTIGATE 状态（前往最后噪声点，1.5 秒查看，返回巡逻）；
  3. 3 个噪声源：搜索、冲刺、枪声（不新增按键）；
  4. 视觉铃声 + 敌人“?” + HUD 提示；
  5. 1 个用于教学的箱子/巡逻位置（现有地图即可）。
- **明确不做**：音频/配音/新敌人/新地图/新 AI 寻路/多房间听觉遮挡/难度选项；不做“听声辨位”核心（可访问性差）。
- **验收可观察项**：10–15 分钟可玩（2 局）；≥4/5 在敌人在 350 px 内时至少 2 次选择静搜；≥3/5 说得出“我选了时间/安全”；敌人 INVESTIGATE 反应 ≤1.5 秒，卡住 >5 秒 = 0；性能不低于基线 10%。

### 5.1 最小规则表

| 项 | 规则 |
| --- | --- |
| 快搜 | 按住 E 0.9 秒松手；完成；铃声 280 px；获得全部掉落 |
| 静搜 | 按住 E 2.4 秒；完成；铃声 90 px；获得全部掉落 |
| 噪声源 | 搜索（按档位）、冲刺（180 px）、枪声（520 px）；不新增按键 |
| 敌人反应 | 在铃声半径内的敌人进入 INVESTIGATE，前往最后噪声点；看到玩家 → CHASE；到达后看 1.5 秒 → PATROL |
| 墙 | 声音不穿墙/不遮挡（距离判定）；若卡住 >5 秒，返回巡逻（避免无 NavMesh 卡死） |
| 视觉 | 橙色大环/青色小环；敌人“?”；HUD“敌人听到了”；无音频 |
| 调参 | 快搜 0.9s/280；静搜 2.4s/90；若静搜太慢 → 2.0s；若快搜不够痛 → 320；一次只改一个 |

## 6. 可证伪假设（H1–H4）

| # | 假设 | 测量 | 通过线 | 失败信号 |
| --- | --- | --- | --- | --- |
| H1 | 玩家会在敌人附近主动选择静搜 | 至少 2 次“敌人在 350 px 内”的搜索；观察/回放 | **≥4/5** | 4/5 永远快搜；只试一次 |
| H2 | 玩家说得出“我选了时间/安全” | 访谈原话 + 行为 | **≥3/5** | “没感觉”/“不知道铃声干嘛” |
| H3 | 想再来一局 | 结束后不提示，记录是否主动再开 | **≥3/5** | <2/5 |
| H4 | 可读/可教/性能 | 首操作计时、铃声理解、敌人反应、FPS | 首操作 ≤60 秒；0/5 不知道铃声含义；敌人反应 ≤1.5s；卡住 >5s = 0；性能回退 ≤10% | 需要看文档/敌人卡住/掉帧 |

## 7. 成功指标 / Kill 条件

**成功指标**（L1 通过）：

- 10–15 分钟可玩（2 局），无 P0 报错；
- ≥4/5 在至少 2 次“敌人在 350 px 内”的搜索中选择静搜；
- ≥3/5 能说出“我选了时间/安全”；
- ≥3/5 想再来一局；
- 首操作 ≤60 秒；0 次“不知道铃声含义”卡住 >30 秒；
- 敌人 INVESTIGATE 不卡住（>5 秒 = 0）；性能不低于基线 10%。

**Kill 条件（任一命中）**：

- 4/5 永远快搜；或 4/5 说“静搜只是等更久，没意义”。
- 敌人从不查看/查看后不动/卡住 >5 秒；或无 NavMesh 导致 >2/5 的情况卡墙。
- 铃声不可读：≥2/5 两次提示后仍不知道“铃声 = 敌人会来”。
- 最优是“先清光再搜”，且 4/5 都这样做（信息层失效）。
- 7 天内做不出可玩 10 分钟，或需要新增 2 个以上未验证系统（INVESTIGATE 之外）。
- 性能回退 >10%；或 IP/素材风险。

**Iterate 条件**：核心动词成立（≥4/5 说得出“快/静”）+ 至少一次取舍（≥4/5）+ 想再来（≥3/5）；**只改一个变量**（铃声半径/静搜时长/敌人查看速度）再测 5 人。

## 8. IP / 来源 / 风险

- **参考的抽象结构**：“声音吸引敌人”是潜行/搜打撤游戏的通用结构（如 Hunt: Showdown 的噪声陷阱、Thief 的声音信息）；只借“声音 = 敌人可用的信息”这一抽象关系。
- **不复制**：任何作品的角色、UI、素材、商标、音效、具体数值表达；不使用 Hunt/Thief/其他作品的名称、图标、音频、界面。
- **本项目原创**：铃声/“敌人听到了”文案/视觉圆环为本项目原创；无外部音频资产。
- **主要风险**：
  - 敌人卡住（无 NavMesh）；
  - 玩家永远快搜；
  - 静搜像“等待”，不是选择；
  - “先清光再搜”让信息层失效；
  - 继承 B1/B9 的 novelty 虚高（T-035 已标第二波）。
- **降级方案**：
  - 只在同一开阔区域/短距离生效；
  - 静搜缩到 2.0 秒；
  - 只保留搜索噪声，去掉冲刺/枪声；
  - 仍失败 → kill，回到 H1 或 E1。
