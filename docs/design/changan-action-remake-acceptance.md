## 2. 性能探针（Intel HD 6000，1280×720）

```bash
# 3 轮 × 60s：战斗 1 / 战斗 2 / Boss P2
godot --path godot-changan-action --resolution 1280x720 -s tools/probe_fps.gd
```

| 场景 | 采样 | 阈值 | 记录 |
| --- | --- | --- | --- |
| 战斗 1 | 60s | avg ≥30、min ≥20、p95 帧 ≤50ms | avg/min/p95、掉帧位置 |
| 战斗 2（火油+道具） | 60s | 同上 | 粒子/火是否拖垮 |
| Boss P2（熄灯+冲锋） | 60s | 同上 | VFX 爆发是否连续掉帧 |
| 1920×1080 冒烟 | 30s | 可运行、无崩溃 | 仅记录，不作为 30fps 门槛 |

**失败处理**：先降 `scaling_3d/scale`（0.85→0.8）、实光 ≤5→3、粒子池上限；不降 3 战/Boss/3 灯。

## 3. 战斗探针（脚本 + 录屏）

| 探针 | 方法 | 阈值 |
| --- | --- | --- |
| 命中登记 | 10 次刺拳/踢/3 连，记录 hit 事件 | 10/10 只登记一次/挥击 |
| 翻滚 i-frames | 对同一招（打手砸地/ Boss 三连末击）滚 10 次 | 10/10 无伤；逐帧 i-frames 0.08–0.30s |
| 击倒/起身 | 被 Boss 末击击倒 5 次 | 5/5 起身可动、0.5s i-frames、无卡死 |
| 3 连 | 首战内 3 次 J-J-K | 3/3 完整播放、第三击击倒杂兵 |
| 灯数 | 0/1/2/3 灯各进 Boss P2 一次 | 黑暗时长 20/15/10/5s，可读性递增 |
| 重试 | 每场死亡 2 次 | 满血回起点；Boss 跳过演出；无丢失目标 |

## 4. 盲测协议（3–5 人）

- 未见过项目；18–35；动作经验混合；键鼠 1–2 + 手柄 1；1280×720；出声思考；主持人只念任务。
- T0–T9 见主规格 §13.1；通过线 T0–T8 3/3（T8 选择 2/3）、T9 ≥2/3。
- 录屏时间戳：首次移动/首次命中/首次 3 连/首次翻滚/点灯/战斗 1 结束/战斗 2 结束/Boss 开始/Boss 结束/结算。
- 访谈三问：① 用一句话说故事；② 灯对 Boss 有什么用；③ 你记得最后选了什么吗？
