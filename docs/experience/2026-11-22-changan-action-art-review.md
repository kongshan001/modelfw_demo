- 关键发现：
  1. 共享 KayKit 骨架 + 色相 shader 在 25% 会退化为同形团块；必须做剪影破形件（玩家灯杆、敌人武器/肩宽、Boss 角/袍/骨面具），并拆开“阿禾/油贩”“泼皮/闻九”两对同模。
  2. 暗部不能只看“黑得好看”：L*<10 占 74–97%、L*40–100 仅 0.5–7.8%，中间调缺失；给出 L*<10≤65%、L*15–40≥12% 的验收口径与 5 条材质 ramp。
  3. 角色/背景亮度对比用 **WCAG 相对亮度** 计算是 1.09–1.53:1；此前手算把 L* 当亮度会误报为 2.5:1。测量脚本必须用 Y，不要用 L* 直接代 WCAG。
  4. 脚本化演示镜头不能代替“可读战斗”证据：GIF 缺翻滚/起身、4.8s 目标不同步、5.2s 近裁面；展示物料需要单独重录 + 25% 抽检。
- 可复用方法：
  - 2×2/3×3 标注图：25% 缩略 + 色度掩膜纯黑剪影 + 局部 1:1 裁切 + WCAG/L* 数字。
  - UI 文本用 p99 文本/中位背景；暗部用逐像素 L* 直方图；角色 bbox 用屏幕高度百分比。
  - 评审输出先给“失败项/外放门槛”，再给“可保留优点”，避免被氛围分掩盖剪影/相机硬伤。
