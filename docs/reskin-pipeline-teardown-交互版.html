结论先行

视频真正的可复用点不是“某个风格模型”，而是五段式顺序：布局锁定 → 只换题材（先别洗）→ 低强度风格洗 → 4K 修字 → 设定表切零件/同名替换 → 进游戏。换皮是乘法，不是玩法创新。

03

Reskin Kit 规格

输入契约 · 输出契约 · manifest

Kit 的目标：给定原创布局和风格 token，稳定产出可替换资产，并能验证“布局没坏、文字没错、零件没漏、许可清楚”。非目标：不改玩法、不做数值/关卡、不做“一键出完整游戏”。

输入

  • layout_ref：原创截图 1×/2×/4K，同机位；有字版 + 无字/遮罩版；HUD/按钮/文字 bbox。
  • style_token.json：色板 hex、笔触、材质、光照、字体倾向、motifs、negative、参考图许可。
  • text_manifest.csv：id、text、bbox、font、size、color、align、language、mode(live/baked)。
  • parts_manifest.csv：32 件、source/display 尺寸、pivot、九宫格 margin、state、engine_target。
  • target_profile.json：引擎/渲染器/分辨率/sRGB/alpha/filter/max texture/九宫格单位。

输出

  • textures/：成套贴图，文件名与原文件一一对应。
  • manifest.json：原文件 → 新文件 → 尺寸/锚点/九宫格/状态。
  • report.json：布局漂移、OCR 错字、零件数、命名 diff、九宫格、对比度、FPS。
  • contact_sheet.png：全套缩略图；before_after.png：同机位对比。
  • text_manifest.csv：校对状态；parts_manifest.csv：切图记录。

替换映射：
- {旧对象 A} → {新对象 A}
- {旧对象 B} → {新对象 B}
- {旧场景} → {新场景}

- 画幅 {9:16 / 16:9}、分辨率 {W×H}；

风格 token：
- 色板：{hex list}
- 笔触：{线宽/圆角/纹理}
- 材质：{纸/哑光/金属/宝石}
- 光照：{方向/对比/阴影}

逐条文字 · OCR + 人工

输入：{washed_image_4k_source}
逐条文字（必须全部写入，不得遗漏）：
1. 位置 {bbox}：{text_1}；字号 {px}；颜色 {hex}；对齐 {align}。
2. 位置 {bbox}：{text_2}；……
3. ……
要求：
- 中文字形正确、笔画完整、无错字、无乱码、无缺字；
- 不新增文字，不改写文案，不改变字号/对齐/位置；
- 文字与背景的对比度 ≥ 4.5:1（正文）/ ≥ 3:1（大字）；
- 字体使用 {Noto Sans SC / 思源黑体 / 自有无版权字体}。
禁止：把文字做成装饰纹理；用英文/拼音替代中文；添加水印/签名；改变画幅。

- 角色背面 × {3}：{角色列表}；
- 怪物 × {4}：{怪物列表}；
- 技能图标 × {9}：{技能列表}；
- HUD 组件：血条、横幅、按钮、边框、宝石、环、城墙等。
要求：
- 同一风格、同一光照方向、同一描边宽度；
- 正交视角/背面视角；角色脚底对齐；
- 纯色或透明背景；零件之间留 {16–32}px 间距；
- 每个零件完整、不裁切、不重叠；
- 输出 4K 透明 PNG；另存分层 PSD。
禁止：透视变化；零件重叠；文字水印；复制第三方角色/Logo；不同零件风格不一致。

文字变形，错字，乱码，缺笔画，额外文字，移动 UI，缩放按钮，改变画幅，透视变化，新增 HUD，删除按钮，角色裁切，零件重叠，水印，签名，Logo，第三方角色，过度锐化，过曝，低对比，色偏，脏边，锯齿，重复纹理

7.3 换皮 ≠ 玩法创新

维度换皮玩法创新
玩家重复的动作不变出现新动词，或旧动词的代价改变
决策结构不变新的取舍、风险、信息差
30 秒可教靠题材解释一句话 + 一个可试的演示
删掉这个“创新”只是换回原主题核心循环不成立
验证方式截图/宣传语/CPI可证伪的 playtest 假设
典型失败版权/同质化/买量疲劳新颖但不可读、不可行
判断：换皮适合“核心循环已验证、需要低成本获取新用户/新渠道”的场景；不适合用来掩盖“玩法不成立”。先有 D1/D7/付费/留存数据，再决定是否换皮；不要用“换了三套皮”当作创新证据（呼应 T-033）。

7.4 IP / 文字 / 数据边界

素材

不复制《末日小队》或其他游戏的角色、怪物、技能图标、HUD、Logo、UI 布局、文案；参考只用于流程/参数分析。生成/参考素材必须原创/CC0/已授权，记录来源与访问日期。

风格

只用通用词（国风水墨/萌系治愈/欧美卡通）；不点名模仿在世艺术家；不写“像某某画师”。AI 输出要做相似度/商标/角色检查。

文字

中文必须人工校对；AI 修字可能造字/缺笔画；能 live text 就 live text；字体只用 OFL/自有/已购，随包附许可。

数据/平台

上传云端前确认 NDA/留存/跨境/训练；不要把换皮做成“马甲包/欺骗性克隆”；应用商店对重复内容/图标名称混淆有政策风险。
