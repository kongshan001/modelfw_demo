# Mod fixtures

Generated by `tools/make_mod_glb.py`. Do not edit by hand.

- `crystal_lamp/` — valid mod (hash/bounds/pivot/tris all pass)
- `bad_scale/` — same GLB, manifest bounds too small (rejected)
- `bad_hash/` — manifest sha256 wrong (rejected)

Runtime installs these into `user://mods/` and imports the GLB with
`GLTFDocument.append_from_file` after validation.
