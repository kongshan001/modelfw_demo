## 已知问题 / 下一棒

- 分类筛选为右上「全部 ▾」下拉，不是常驻分类栏（为保留 5×5 网格与参考观感）。
- 纸娃娃/装备为展示态；不实现换装/附魔玩法。
- 炼丹/九州谱/图鉴是占位面板；货币「+」为占位提示。
- 触屏双击依赖浏览器/系统的双击映射，稳妥路径是详情卡按钮；已在 README 说明。
- 若 T-015 做 1:1 校正，可优先量化：面板边界、左右分区、页签高度/间距、网格格子尺寸、槽位尺寸与环半径、标题/关闭钮位置、字号与色值；本作因 16:9 适配对参考的 4:3 比例做了重排，见 TECH §8。
- 性能在共享主机上有波动；如需更稳的 60fps，可进一步做图集/Sprite 批处理、减少文字 outline 次数或将 Details/Toast 等按需实例化。
