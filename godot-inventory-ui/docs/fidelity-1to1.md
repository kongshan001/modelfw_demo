## 1. 测量方法

1. 用 Python + PIL/numpy 对参考图做像素级分析：
   - 面板/网格边界：亮度阶跃 + 高斯模糊后的边缘峰值（网格边界 x=270/313/358/403/448/497，y=60/104/150/194/240/284）；
   - 槽位/关闭钮/钱币/按钮：颜色掩膜 + 8 连通域求 bbox；
   - 文字行/页签/导航：行内颜色阈值 + 游程；
   - 主色：区域中位数采样（避开图标/文字）。
2. 归一化映射：
   - `x1280 = x_ref / 529 × 1280`（比例 2.41966）
   - `y720 = y_ref / 356 × 720`（比例 2.02247）
   - 参考图 1.486:1 → 画布 1.778:1，横向相对纵向多拉伸 21.8%；这是 16:9 适配的既定量，所有定位按归一化坐标分别映射。
3. 误差定义（F1 覆盖层同款）：
   - 位置误差 = max(|Δx|/1280, |Δy|/720)
   - 尺寸误差 = max(|Δw|/w_target, |Δh|/h_target)
   - 偏差 = max(位置, 尺寸) × 100%；标题/关闭钮因参考边缘裁切采用中心点比较。
4. 验收口径：面板边界、左右分区、页签高度、网格列数/槽尺寸、装备槽 ≤2–3%；字号/行高按高度比例校准；颜色按区域中位数采样后重新调色。

## 7. 例外与不适用项（有意为之）

1. **16:9 适配**：参考 529×356（1.486:1）→ 1280×720（1.778:1）。归一化后正方形槽会变成 106.5×89.0；实现取 104×90，保持方形观感并把两轴误差压到 ≤2.32%。若未来出 4:3/参考比例版本，用 106×89 即可完全贴合。
2. **参考图无绶带**：T-014 的红色绶带在参考图中不存在，已移除；标题改为场景上的浅色书法「物品」+深蓝描边。`assets/ui/ribbon.png` 保留但不再使用。
3. **容量/筛选为新增控件**：参考图没有容量条与分类筛选。为保留交互与 smoke 验收，把「背包容量 35/216 · 第 1/5 页」和「筛选 全部 ▾」放在网格与钱币行之间的空白带（y=578，高 20），低对比、不挤占 1:1 区域；F1 中以品红标记且不计入最大误差。筛选弹层从按钮上方向上弹出（`(1054,418)`）。
4. **详情卡为新增浮层**：参考图无详情卡。选中物品时在右侧显示 290×440 详情/操作卡（使用/丢弃/出售），默认总览截图不显示；作为交互能力保留。
5. **滚动条**：参考图无可见滚动条；实现保留 10px 低透明度拖拽条嵌在网格背板右缘，用于翻页拖动（滚轮/页签/Tab 亦可）。
6. **关闭钮**：参考图右缘把按钮裁掉一部分；实现完整显示 72×72，中心与参考对齐。
7. **原创素材**：物品图标、立绘、面板纹理、背景、文案均为 T-014 原创，按参考的色板/明度重新调色；未复制参考截图/图标/Logo/UI 切图。品质色按参考“紫 / 橙红”语言重映射。
8. **背景**：保留 T-014 原创夜景；参考的户外白天场景不复制（面板覆盖 95% 画面，仅顶部/边缘露出背景）。
9. **字体**：系统 CJK 回退（PingFang SC / Kaiti）；跨平台发布建议自带 OFL 字体。
10. **装备槽只读**：本 demo 不实现换装/附魔；槽位尺寸/位置/文案与参考一致。
