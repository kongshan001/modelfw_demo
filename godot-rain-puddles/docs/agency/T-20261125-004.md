## 3. 关键实现与参数

- **世界/显示**：世界 640×360，窗口 1280×720，`canvas_items` 拉伸；
  1920×1080 截图通过 1920×1080 SubViewport 渲染（macOS 会裁大窗口）。
- **雨**：默认 360 条（60–600 可调），4 顶点/条，动态 `ArrayMesh` 单 surface；
  尾透明→头亮；风速 -0.6–0.6（×300 px/s）；速度 0.4–2.0×；
  长度 0.5–1.8×；无 `GPUParticles2D`/`CPUParticles2D`。
- **积水**：`PuddleField` 320×180 RGBA（R 高度 / G 遮挡 / B 灯柱标记 /
  A 边缘噪声）；6 个盆地 + FBM；满水 19 百分位（约 17.2% 覆盖）。
  - 默认满雨 22s 满，雨停 75s 干；速度滑杆只缩放时间；
  - 水线 `pow(wet, 0.40)` 缓动，使增长过程全程可读；
  - CPU `mask_from_texel` 与 shader `rp_water_mask` 共用常数。
- **灯柱规则**：16×16 规则格；2 盏灯各 1×1，按“EmitsLight && 1×1 &&
  非边界 → 放行”清除遮挡；大石头/石岸共 28 格遮挡；满水时两灯脚下 mask=1.0。
  F3 叠加：红=遮挡格，绿=灯柱放行格。
- **涟漪**：池 72；目标 = 72 × 雨强；寿命 1.1–2.1s；双环 32×32 贴图；
  12–30px 椭圆；MultiMesh 1 draw call；`SCREEN_UV` 采样同一水 mask。
- **倒影**：启动时烘焙 640×360 镜像图集（红枫/松树/双灯 + 平滑暖光），
  运行时水面 shader 采样 + 像素吸附扰动 + 同一 puddle mask 裁切；不使用
  BackBufferCopy/screen_texture；支持倒影开关。
- **UI**：中文；雨强/密度/风/速度/长度/积水/渗干 7 个滑杆；涟漪/倒影/网格
  3 个开关；暂停/重置；FPS + 总 draw calls + 雨丝数 + 涟漪数 + 水位 + 状态；
  空格暂停、R 重置、H 收起、F3 网格。

## 5. 与参考的差异 / 如实说明

- 参考里的“2 DrawCall”指雨丝+涟漪的合批；本实现雨丝 1 + 涟漪 1 = 2
  个效果层调用，水面合成另占 1。**没有把整个世界说成 2 个 draw call**。
  世界层实测 11（含 blit），HUD 总计 59，调试全开约 121。
- 参考是 Unity C#/HLSL 与 Tilemap；本实现是 GDScript 低洼场 + GLSL
  include + 16px 规则格。规则语义（1×1 细灯柱放行）一致，但不是源码移植。
- 倒影为离线镜像图集，不是实时平面反射；GL Compatibility 下更稳、更便宜。
  动态物体不会自动入水，已在 README/TECH 写明。
- 水色/雨丝/灯笼光晕的观感经过多轮截图调校；最终数值见
  `water_surface.gdshader`、`rain_field.gd`、`pixel_art.gd`。

## 6. 已知风险 / 后续

1. 静态倒影图集：若后续加可移动角色/扫落叶等，需重烘或换镜像视口。
2. 静态水洼 mask：修改地形/摆放需重建 `PuddleField` 与贴图。
3. 灯柱规则简化：不是通用 TileMap 系统；覆盖本 demo 的固定摆位。
4. HUD draw calls 偏高（59 总、世界 11）；如果需要压总调用可自绘面板。
5. 1080 性能数据为离屏测量（见上），比真实全屏略保守。
6. 没有音频；没有外部素材；无第三方运行时依赖。
7. 未修改其他项目；`git_publisher` 按任务的 `commit_paths` 提交本目录即可。
