# 迭代记录 · 雨落青苔

## 2026-11-25 · 参考拆解 → 可交互 demo

### 第一版（骨架 + 首次 GPU 截图）

- 完成：`PuddleField`（320×180 高度/遮挡/边缘噪声）、动态 Mesh 雨丝、
  MultiMesh 涟漪、水面合成 shader、镜像图集、HUD。
- 首次 1280×720 截图暴露的问题：
  1. 水洼近乎黑色，倒影像一团泥/火，水面层次不足；
  2. 雨丝太粗太白，像雪；
  3. 前景暗角全是抖动噪点，屏幕边缘有虚线状杂点；
  4. 灯笼光晕只有约 1.5px：`QuadMesh` 是 1×1 单位，缩放 1.55 被误当成
     “纹理像素尺寸”，实际上应该缩放到 160px；
  5. 灯柱贴图与布局的朝向左/右反了，光晕落在灯笼的反侧；
  6. 松树像一摞整齐的三角，红枫像一圈橙色气泡；踏脚石小径过于抢眼；
  7. 录屏/连续截图时 HUD 显示 FPS 2–7（逐帧存 PNG 拉低实时帧率），
     但专用 probe 实测世界层 217.9 FPS——不是运行时性能问题。
- 第一版启动耗时约 3.9s（有一次 11s 是因为手工逐像素镜像 + 全分辨率底色），
  后续降到约 1–2s。

### 第二版（美术与构图）

- 地面底色改为 320×180 生成后 2× 最近邻放大，草色整体提亮，顶部林缘压暗
  减少到 0.56，底部前景压暗减少到 0.28。
- 灯下光池改成三层平滑 `_soft_blob`，取代碎黄点。
- 删除 8 块踏脚石小径，改为 4 块半埋苔石 + 7 丛中景蕨。
- 重画红枫：更深的酒红/砖红/珊瑚分层、碎叶边缘、暗缝和悬挂枝。
- 重画松树：七层下垂枝、锯齿边缘、冷光侧、缩小枯尖、基部红叶。
- 前景只保留四角蕨叶剪影，去掉左右暗角和逐像素噪点。
- HUD 在 1920 截图中以 1.5× 渲染（与 canvas_items 拉伸一致）。

### 第三版（水、倒影、光晕与曲线）

- 修正灯柱贴图左右交换；灯笼光晕现在与灯笼对齐。
- 光晕从 1.5px 修到 160px，再降低强度/更陡的衰减，避免“月亮圆盘”。
- 倒影：
  - 暖光倒影从散点抖动改成平滑径向渐变，消除“电视雪花”；
  - 红枫/松树倒影乘冷色、按行渐隐；
  - 水面 shader 降低全局去饱和，提升深水倒影权重；
  - 保留 UV 像素吸附 + 正弦扰动，边缘仍由同一 `rp_water_mask` 裁切。
- 雨丝宽度降到 0.8–1.55px，头亮尾透明的顶点色不变，降低整体 alpha，
  看起来更像雨而不是雪。
- 双环涟漪透明度 0.52、尺寸 12–30px，雨强控制目标数量与生成节奏。
- 水线映射从线性改为 `pow(wet, 0.40)`：
  - 线性时 11s（50% 时间）只有约 2.5% 面积有水；
  - 0.40 次幂后约 6.8%，0.25 湿约 3.5%，全程可读；
  - 22s / 75s 的时间口径未变。
- 所有反射图集直接操作 `PackedByteArray` + `Image.blend_rect`，避免逐像素
  混合；启动时 `reflection` 阶段约 30–70ms。

### 最终验收（2026-11-25）

- `RAIN_PUDDLES_SMOKE_OK checks=73`（雨丝数量/无粒子/22s/75s/灯柱规则/72
  双环/涟漪生命周期/雨强频率/倒影开关/统一裁切/暂停/重置/中文 HUD/滑杆接线）。
- headless 600 帧、真实 GPU 600 帧：0 `SCRIPT ERROR` / 0 `ERROR`。
- 9 张 1920×1080 截图：积水、满水倒影、渗干、浅水、 大雨、小雨、灯柱调试、
  面板、倒影关闭对照。
- 10s MP4（1280×720@30）+ GIF（800×450@15）。
- 性能（VSync off，Intel HD 6000）：
  - 720p 世界层 217.9 FPS / 11 draw calls；含 HUD 180.8 FPS / 59 calls；
  - 1080p 离屏世界层 153.8 FPS / 11 calls；含 HUD 141.0 FPS / 59 calls；
  - 600 雨丝时 720p 世界层 207.9 FPS，draw calls 仍为 11。
- 说明：1080p 原生窗口被 macOS 裁到 1440×762，因此用 1920×1080 的
  SubViewport 离屏渲染测量；视频/GIF 内隐藏实时 FPS 统计，避免逐帧抓图
  导致的误导性低值。

### 保留的取舍

- 倒影用离线镜像图集（GL Compatibility 下最稳、最便宜），不追求实时 SSR。
- 水洼场静态生成；地形/摆放变化需重生成，不在本 demo 范围。
- 水色偏深青、雨丝偏细，是为了保留参考里“黄昏草地 + 暖灯 + 冷雨”的对比；
  如果后续希望更亮，可在 `water_surface.gdshader` 调 `u_deep/u_shallow`，
  或降低雨强默认值。
