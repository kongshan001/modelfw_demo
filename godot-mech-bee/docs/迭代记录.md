# 迭代记录 — Mellis HB-7

## 2026-11-18 · 第 1 轮：Godot 版机械拆解模拟器

**参考**：今日头条视频《Ai都强到这个地步了吗？这是AI制作的一套三维机械分解交互系统，
整个机械蜂都一清二楚！》（2026-11-16）。视频背后是开源项目
[elvarofficial/teardown](https://github.com/elvarofficial/teardown)（MIT）的
Mellis HB-7 机械蜂示例。本工程用 **Godot 4.6** 净室复刻其交互结构，没有使用原项目代码/素材。

**实现**：

- **单求解器** `mech_solver.gd`：翼频/翼摆、漂浮/俯仰/滚转、电池/功耗/温度、
  六路舵机负载、姿态/升降、子系统状态全部是 `state + t` 的纯函数；
- **程序化模型** 17 个零件：头、光学镜头、胸、腹两段、尾齿轮、透明舱、4 翼、6 腿；
  球/圆柱/圆环/盒子拼装，翅膀纹理逐像素生成，材质用 unshaded 假棚拍光照；
- **拆解交互**：TEARDOWN / REASSEMBLY / WING OFF / ABDOMEN OPEN / THORAX OPEN；
  每件独立爆炸方向 + 级联延迟；点击选中、`I` 隔离、相机缓动跟随；
- **HUD**：暖纸色面板、翼频波形、姿态仪、电池格、舵机负载、子系统状态、飞行日志；
  3D 锚点投影成左右边栏引线标签；
- **自动巡览**：状态 5.5s 轮换、零件 2.2s 轮换；输入接管，静置 15s 恢复；
- **验收/出片**：无头 smoke、5 张真实 GPU 截图、9s GIF + MP4。

### 本轮问题与修复

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 翅膀全黑/像黑铁片 | 忘了把生成的 `wing_tex` 绑到 shader；透明区域 RGB=0 被过滤平均 | 绑定纹理；透明区 RGB 填奶油；`filter_linear` |
| 2 | 翅膀几乎看不到面，只有线 | 相机在目标下方（pitch=-10°），水平翼面接近侧视 | 相机抬到 +8°；翼加 14° 上反角 |
| 3 | 拆开后零件飞出画面 | 爆炸位移过大（2–4 单位） | 位移缩到约 55%；相机随 `explode_t` 拉远 2.6 |
| 4 | 隔离后画面空 | 选中的镜头处于爆炸位置，相机没跟随 | 隔离时相机目标/距离缓动到零件 |
| 5 | 地面出现灰色方块 | 接触阴影是纯色 Quad | 程序化径向 alpha 阴影贴图 |
| 6 | 白壳发灰 | unshaded 环境项权重低 | 提高环境项；白色材质拉到 `#FFFFFF` |
| 7 | 暂停仍推进时间 | `solver.step()` 在设置 `paused` 之前 | 先设 state/paused，再 step |
| 8 | 标签被左右 HUD 遮住 | 标签按锚点水平摆放 | 固定到 x=272 / 1008 两条边栏 + 纵向防重叠 |

### 验证

- `MECH_SMOKE_OK parts=17 moved=17`：
  - 悬停翼频 > 0 且翼角随时间变化；
  - TEARDOWN 后 `explode_t ≥ 0.8`、至少 12 件移位、翼停；
  - REASSEMBLY 后 `explode_t ≤ 0.05`；
  - 隔离只显示选中件，释放恢复；
  - WING OFF 翼停且翼移位；
  - 暂停不推进时间。
