## 3. 为什么看起来像“程序化调试图”（11 条，逐条证据）

> 每条都可在 `AR02/AR06/AR04` 找到对应裁剪或坐标。

1. **海水是平涂 teal，不是有深度的水。**
   - 证据：01 (30,140)-(340,900) 区域 #2a6c75、L*42.0、S0.64；03 内 700px 横断 p10–p90 40.1–43.5；x630–680 近岸 L*43.2（仅 +1.2）。
   - 根因：`depth.R = 1-exp(-d/3.2)` 在 1–2 格就接近 0.5，`mix(seabed…, deep, smoothstep(0.02,0.76,depth))` 把沙底快速压掉；深/浅共用同一深色。

2. **浅滩没有“透出沙底”，只有一条薄荷色带。**
   - 证据：06 y=500：水 150px → 薄荷 10px → 白沫 24px → 沙；03 y=250：水直接到白沫。4× 图中薄荷带是最亮的浅水信号，但不是沙/鹅卵石。
   - 根因：seabed 混入权重太低；浅水 color 使用 `u_shallow`（#abc? 薄荷）而不是沙底暖色；白沫/岸线覆盖了 1–2 格浅水。

3. **焦散像细划痕，宽视几乎看不见。**
   - 证据：03 (40,550)-(300,850) 高通 p95 1.12 L*、p99 2.32、>2 L* 仅 1.56%；超过 98% 的水面像素没有可读焦散。
   - 根因：Voronoi scale 31 world px + pow1.35 + 加法 0.26，但边缘只有 2–4px 宽；同时 flow crest 的长斜线（`smoothstep(0.84,1.0,sin(...))`）更显眼，被误读为焦散。

4. **白沫是连续白描边，像选区框。**
   - 证据：14 礁石 r80–120 白像素 24–39.5%、p90 L*92.5，环连续无断口；06 白沫 17–26px 单色；`mix(water, #eef7e0, clamp(foam,0,0.92))` 只有 0/1 级。
   - 根因：foam 是单一硬阈值 + 单色；双波前在 0–3.4 格内形成两条平行线；礁石周围是距岸场等值线，天然是同心环。

5. **岸线是硬切，不是水陆过渡。**
   - 证据：16px 栅格在 1920 下是 24px 阶梯；06 水→薄荷 10–30px→白沫→沙；没有湿沙暗带、没有水线阴影、没有不规则泡沫扇。
   - 根因：mask 覆盖率硬切 + 2px dither；`C_WET` 只在沙滩绘制里 0.16 lerp，实际不可见；白色 foam 线吃掉了岸线细节。

6. **陆地是均匀噪点毯，没有光照。**
   - 证据：01 草区 (700,150)-(1200,500) p10–p90 40.1–57.1、uniq16=97，2–4px 等密度斑点；房屋/树/桥无方向光/投影；只有树下一块椭圆假影。
   - 根因：程序化地面用 hash 高频噪声填充，缺少 40–80px 的大色块、AO、日照/阴影层；全部元素平光绘制。

7. **建筑、桥、树是贴片，且投影混用。**
   - 证据：桥 1440–1590×190–570 是最大暗块（L*38.5），无栏杆/无桥影/无湿木；房屋是正立面（俯视地图里的立面），无投影；树冠是三角/红色双圆；船是侧视、芦苇是侧视。
   - 根因：资产按“符号”绘制而非按同一俯视/3/4 投影；没有统一的太阳方向与接触影。

8. **湖心像月亮，湖岸像白色虚线框。**
   - 证据：05 湖心 L*27，但岛周有亮色径向光晕；湖岸是锯齿白点；湖 foam=0.07 仍保留 `edge_line`；无岛影/倒影/芦苇暗部。
   - 根因：浅水 sand_glow + 岛周距离场亮度叠加；湖也执行同一套 edge_line；没有接触影。

9. **雨是“暗水洼”，不是湿地。**
   - 证据：08 积水 `seabed*0.34 + 冷膜 + 圆环`，读成深灰洞；陆地被灰绿 veil 压平；雨丝是均匀竖线，没有溅水/石面反光/水面粗糙化。
   - 根因：积水公式只压暗、不反射；rain 只有全屏 streak + rings，没有 ground wetness/sheen/splash 层。

10. **构图没有 hero，桥抢焦点；UI 压景。**
    - 证据：01 左侧 1/3 是空海，中部是大块空草；桥（L*38.5，最大暗块）第一眼；湖白圈第二眼；海面几乎不参与。02 面板 585×657 = 18.5% 屏；字幕草地 4.1:1；按钮约 22 逻辑 px。
    - 根因：`full` 机位 1.0× 把整张地图摊平，未做视觉层级；HUD 面板默认展开且盖住左岸；字幕在底部压住滩/湖。

11. **动画像雷达脉冲，没有重量。**
    - 证据：2.4/2.9/3.4s 抽帧中礁石环整体缩放、始终连续；海面是长斜细线；没有预备/冲击/跟随；芦苇/睡莲/雨没有次级运动。
    - 根因：波前是 `exp(-((dshore-front)*10)^2)` 的等值带；front 只改半径不改形状；没有噪声断口、没有相位/振幅的岸段变化。

## 5. Top 问题（P0 → P1 → P2）

> 每条：问题 → 目标 → 证据 → 根因 → 改法（参数）→ 验收。最多 8 条；细节参数在第 6 节 brief。

### P0-1 · 水体没有深度渐变，浅滩不透沙（外放第一眼失败）

- **问题**：海面是一块 #2a6c75 平涂；从岸到深海 L* 只变 3.4；1–2 格浅水就被深色吞掉，看不到沙/鹅卵石。
- **目标**：海面 5 档色阶、浅水透沙 ≥60px；水-草中位差 ≥8 L*；25% 岸线有浅水晕而不是白线。
- **证据**：01 海区 #2a6c75/L*42.0/S0.64；03 700px 横断 p10–p90 40.1–43.5，近岸 +1.2 L*；06 横断无“水下沙底”段；4× 图 `AR06`。
- **根因**：`depth=1-exp(-d/3.2)` 在浅水上升过快；`smoothstep(0.02,0.76)` 把 seabed 混掉；浅水色是薄荷 `u_shallow`，不是暖沙。
- **改法**：按“距岸格数”做 5 档色阶（见 6.1），0–2.5 格保留 55–75% 沙底；折射幅度从当前约 4 world px 降到 ≤1.5 world px；浅水暖沙 #C9B57E 混入 15–20%；海深色 L* 33–44、浅水 L* 70–75，水-草中位差 ≥8 L*。
- **验收**：06 y=500 必须出现 ≥60px（逻辑）透沙浅水带；海深 L* 33–44 / 浅水 70–75（Δ≥30）；S 深 ≤0.55 / 浅 ≤0.35；色阶至少 4 档可辨；25% 缩略图岸线有淡色浅水晕而不是白线。

### P0-2 · 岸线硬切 + 白沫连续描边 + 无湿沙（水陆像贴纸拼接）

- **问题**：16px 阶梯硬切；薄荷带 + 连续白线；没有湿沙、没有水线阴影、没有分段泡沫；礁石环像选区框。
- **目标**：岸线 ≥4 段（沙/湿沙/白芯/青沫/水）；湿沙 8–12 逻辑 px；白芯 4–7px 分段；礁石环有断口；25% 河不靠白边。
- **证据**：06 y=300/500 水→薄荷 10–30px→白沫 17–26px→沙；14 礁石 r80–120 白像素 24–39.5%、p90 L*92.5；`AR02 B/C`、`AR06`。
- **根因**：mask 硬切 + 单色 foam 0/1 混合；`C_WET` 只 0.16 lerp；礁石波前是距岸等值线；湖也走 edge_line。
- **改法**：湿沙带 8–12 逻辑 px #A89670（外缘 #82755A 2px）；水线暗线 2px #2B4A45 α0.55；白芯 4–7px #E8F2DE，青沫 4–6px #9CCDBD α0.20–0.30；8–24px 分段、20–40% 断口；礁石改 2–4px 泡沫领 + 4–6px 接触影；湖只保留 1px 水线，无泡沫环。
- **验收**：4× 岸线横断能看到沙/湿沙/白芯/青沫/水 ≥4 段；纯白像素 <2%、白沫面积占比 8–12%；湿沙带 8–12 逻辑 px；礁石环有 ≥20% 断口且不再闭合成整圆；25% 下河岸靠暗水线/阴影识别，不靠白边。

### P0-3 · 没有光照/投影，陆地与道具是平光贴纸（“地图编辑器”感的主因）

- **问题**：草地是均匀噪点；树/屋/桥/礁石没有方向光和投影；房屋正立面、船侧视、芦苇侧视混在俯视地图里。
- **目标**：统一右上光/左下影；所有贴地物体有接触影；草地大色块、道具 3 档色；投影统一 3/4 俯视。
- **证据**：草 p10–p90 40–57、uniq16=97；桥/屋/树无影；`AR02 F/D`、`AR04`。
- **根因**：pixel_art 只做颜色/噪声，没有统一光源；道具按符号绘制，未统一 3/4 俯视。
- **改法**：太阳右上（光向量 (0.55,-0.83)），影向左下；树影 30–40、屋 24–30、桥 8–12、石 6–8 世界 px；影色 #1E3A36 α0.30–0.36；接触影 2–3px α0.45。草地改 40–80px 大色块 + 8–12% 低对比斑点；房屋改 3/4 俯视屋顶（占 70% 足迹），桥加双侧栏杆/桥影/湿木，船改俯视，芦苇改放射状簇。
- **验收**：25% 缩略图能看出统一左下影；灰阶 5 档；房子屋顶占主导、桥端有湿木+影；所有道具底部有接触影，无悬空；草地不再 2–4px 等密度噪点。

### P0-4 · 构图无 hero、桥抢焦点；HUD 默认压景（展示物料不合格）

- **问题**：1.0× 全景摊平，左侧空海、中部空草；桥是最大暗块；面板盖住左岸；字幕压底。
- **目标**：3 个 hero 机位；第一眼落在水/岸线；外放图无 HUD/字幕；面板打开 ≤20% 屏且按钮 ≥32 逻辑 px。
- **证据**：01 桥 L*38.5/最大暗块；面板 585×657 = 18.5% 屏；字幕草地 4.1:1；`AR02 H`、`AR05`。
- **根因**：没有相机/视觉层级设计；HUD 默认展开且没有安全区；字幕直接叠在游戏画面上。
- **改法**：新增 `hero_shore` (520,520,1.45)、`hero_bridge` (1300,300,1.8)、`hero_lake` (1450,720,1.55) 三个机位（带边界夹取）；主图必须 UI/字幕全隐；面板默认收起、宽 ≤360 逻辑 px、屏幕占比 ≤20%；字幕改底部 48px 安全条（#0B1414 α0.55）或顶部小 chip，正文 18 逻辑 px、对比度 ≥4.5:1。

### P1-1 · 焦散/高光/反射都“有代码没画面”

- **问题**：焦散宽视不可见；无倒影；sparkle 只是 1.2% 的 teal 点；水面缺“光”。
- **目标**：浅水焦散可读、桥/湖有风格化倒影、暖色太阳闪；不改全屏管线。
- **证据**：03 高通 p95 +1.1 L*；无反射代码；sparkle `step(0.988,…)`；`AR06 A`。
- **根因**：焦散尺度小、边缘窄；没有屏幕反射/风格化倒影；高光用冷色且密度低。
- **改法**：焦散 2 octave：scale 56 + 23 world px、speed 0.15–0.20、加法 0.10–0.14、smoothstep(0.16,0)、只在 0.75–4.5 格；局部高通 p95 目标 +4–6 L*、覆盖 8–15%；流动亮纹强度降 40–50%，避免与焦散抢。倒影：桥端 0.18–0.25、码头/小船 0.15、礁石 0.12、岸边树/苇 0.10，向下偏移 2–4px、2px dither 打断；加 0.3–0.5% 暖色太阳闪 #FFE9B0。
- **验收**：300×300 浅水裁剪高通 p95 ≥4 L*；25% 浅滩能看出柔和移动光网；桥/湖有可读倒影但不糊；无 screen_texture、draw calls ≤90、1080p ≥90fps。

### P1-2 · 桥/礁石/芦苇/睡莲/树缺“构造”，细节不成组

- **问题**：桥像一块木门；礁石无底座；芦苇是几根侧视细线；睡莲是平圆片；树冠是三角/双圆。
- **目标**：桥有栏杆/湿木/影；礁石有底座/泡沫领；芦苇成簇、睡莲成组；25% 可辨。
- **证据**：04 桥 1440–1590×190–570 大平面；14 礁石白环；05 睡莲 2 个粉点；`AR02 C/D/E`。
- **根因**：道具按最小符号绘制，缺少栏杆/截面/阴影/组群节奏。
- **改法**：桥：双侧栏杆 3px + 每 24px 立柱 4px + 8–10px 板缝 + 8–12px 影；礁石：3 色 + 右上 rim 1–2px + 2–4px 泡沫领 + 接触影；芦苇 8–12 根/簇、3–5 簇贴岸、基部 2px 暗影；睡莲 12–18px、2 色 + 缺口 + 1px 高光、4–6 片；树冠 3 色 + 5 层松针/3–5 枫叶团 + 2px 亮边 + 30–40px 影。
- **验收**：25% 能读出桥栏杆、芦苇簇、睡莲；100% 每种材质有 3 档色 + 1 条特征线；桥不再占据最大暗块；无悬空/穿模。

### P1-3 · 动画节奏像雷达，缺重量与次级运动

- **问题**：泡沫环整体缩放；水面是长斜线；芦苇/睡莲/雨点没有次级运动；雨没有湿地反馈。
- **目标**：两道前缘可读、有重量/次级运动、雨态有湿地反馈；30fps 无闪烁。
- **证据**：2.4/2.9/3.4s 抽帧环连续缩放；无风摆；雨态只有灰 veil。
- **根因**：front 只改半径；没有岸段噪声/断口；没有第二层节奏。
- **改法**：泡沫 front cycle 0.18（约 5.5s），双前相位差 0.5，宽度 0.45 格，±0.3 格岸段噪声，20–40% 断口；宽波 1.5–2.5 world px/8–12s，细波 0.5–1px/2.5–3.5s；芦苇 ±2px/2.4s；雨环 0.4–0.6s + 10% 雨滴 2–3px 溅水；雨态地表 -8% L、-5% S + 0.08 fog，积水加 sheen。
- **验收**：10s/30fps GIF 抽 1s 帧，至少两帧能看到两道前缘；礁石环有断口、无整体脉冲；无闪烁；雨态能看出湿石反光与溅水，而不是一层灰。

### P2-1 · 展示物料、天气变化与收尾打磨

- **目标**：press kit 级 3 hero + 3 GIF；天气过渡；HUD 有收/展动效；可复现。
- **证据**：现有 14 张中 6 张带字幕/调试；无 hero 图；02 是唯一 UI 图。

- 水面 alpha 保持 1.0（不要靠 alpha 透出 ground）；视觉透明用 seabed mix：

### 6.3 岸线湿沙带（资产层，pixel_art.gd）

- 验收：06/14 的 4× 裁剪能看到沙→湿沙→白芯→青沫→水至少 4 段；湿沙 L* 55–65。

### 6.4 焦散（shader）

- 两个 octave：主 scale **56 world px**、次 **23 world px**（次层权重 0.35）；速度 0.15–0.20 world/s；更新 8Hz（不要每帧）。
- 形状：`edge = sqrt(d2)-sqrt(d1)`；`caus = pow(smoothstep(0.16,0.0,edge),1.1)`；加法 **0.10–0.14**，颜色 `#DFF3DC`。
- 覆盖：`dcell` 0.75–4.5 格；湖/积水 0；深水 >6 格 0；在浅水覆盖 8–15%。
- 同时把 flow crest 从 `vec3(0.16,0.27,0.25)*0.32` 降到 0.16 左右，sparkle 阈值从 0.988 提到 0.996（0.4%），颜色改 `#FFE9B0`，避免“细划痕/斜纹”抢焦散。
- 验收：300×300 浅水裁剪高通 p95 ≥4 L*；宽视可见柔光网；湖无焦散。

### 6.5 双波前泡沫（shader）

- 结构：**白芯 4–7px `#E8F2DE`** + **青沫水洗 4–6px `#9CCDBD` α0.20–0.30** + **湿沙 8–12px**；白芯不再 `clamp(foam,0,0.92)` 单色。
- 双前：cycle **0.18**（约 5.5s），相位差 0.5；front 范围 1.2–3.6 格；宽度 0.45 格；振幅权重 0.85 / 0.55。
- 噪声/断口：岸段 hash 8–16px，front ±0.3 格；分段 mask `step(0.28, hash(floor(fs/8)))`，断口 20–40%；礁石周围泡沫领 2–4px，不要 r80–120 的同心白环。
- 湖：无泡沫环，只 1px 水线（`edge_line` 降到 0.15 强度）；河：泡沫 ×0.5；积水：无泡沫，只雨环。
- 验收：14 礁石出现两条断开的弧（或一条主弧+一条弱弧），至少 20% 断口；06 白沫核心 4–7px、纯白 <2%、面积 8–12%；25% 不靠白边识别河。

### 6.6 反射 / 高光

- 验收：10s/30fps GIF 两帧可见两道前缘；无整体脉冲；无闪烁。

### 6.12 Intel HD 6000 预算

- **1920×1080 带 HUD ≥90fps**（当前 131）；1280×720 带 HUD ≥150（当前 158）；draw calls ≤90（当前 67）；水面节点 1；无 screen_texture/全屏 RT；焦散 ≤2 octave；shader 循环 ≤9；启动 ≤4s。
- 新增倒影/阴影用静态 sprite/atlas，不增加全屏采样；若掉到 1080p <90，先把焦散降 8Hz→4Hz、流动亮纹关闭，不要砍岸线分层。

## 9. 仍不足（即便 P0/P1 完成）

1. **16px 岸线阶梯仍在**：湿沙/泡沫能遮一部分，但近看 4× 仍是 16px 块；8px 栅格是另一种预算（数据×4、管线改动），本次不承诺。
2. **没有真实反射/折射**：倒影是静态风格化 sprite；不会随视角/水面法线变化；这是 2D 俯视的限制。
3. **地表密度仍低于参考**：参考是手绘级植被/石墙/灯影；本实现是程序化，P1 后仍是“精致程序化”，不是手绘。
4. **投影仍是假 3/4**：房屋/树只能做 2D 符号化 3/4；没有法线/动态光照；夜景/天气过渡只是颜色与叠加。
5. **玩法/系统未验证**：这是水面 shader demo，不是完整游戏；没有角色、交互、目标、音效；外放叙事需要另行设计。
6. **UI 仍是开发者面板**：无本地化、无手柄/键盘焦点系统、无无障碍；按钮/字号达标也只是 demo 级。
7. **1920 是 1.5× 显示放大**：不是原生 1080 像素资产；大屏近看仍能看出 2× 基础像素。
8. **分类是启发式**：换地图需重调 `RIVER_MAX_WIDTH`；不是视觉问题，但会影响“换场景仍成立”的承诺。
