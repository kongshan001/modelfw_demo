## 4. 关键参数

### 世界 / 数据

- 逻辑世界：1280×720；像素素材在 640×360 绘制后 2× 最近邻放大
- 水面栅格：cell=16px → 80×45
- 每格覆盖率：8×8 子采样（步长 2px）
- 硬水阈值：coverage ≥ 0.5；桥格阈值 ≥ 0.35；低洼阈值 ≥ 0.40
- 水深：`R = 1-exp(-d/3.2)`，`G = d/16`；倒角直向 1 / 斜向 1.41421356
- 分类：不贴边→湖；贴边且 `avg_width<9.5`→河；否则→海
- 结果：海 888 格 / 河 210 格 / 湖 216 格；低洼 88 格；桥面 57 格；水体数 3
- 输出：mask/depth/category/flow/puddle_mask/puddle_depth + meta（SHA-256）

### 水 shader

- 唯一材质挂在一个 1280×720 `ColorRect` 上（`WaterLayer`），无 Mesh/Polygon 水面
- 岸线：`step(0.5, coverage + hash*0.16 - (tide-0.5)*0.24)`，2px 块抖动
- 焦散：`world/31` 的 3×3 Voronoi，`pow(smoothstep(0.20,0,edge),1.35)`，强度 0.26
- 双波前：`c=fract(t*0.22*(0.72+0.55tide)+k*0.5+phase*0.18)`；`front=(1-c)*(1.75+0.45tide)`；`exp(-((dshore-front)*8.5)^2)`；k=0/1
- 预设（wave/flow/foam/caustic）：海 1.0/0.55/1.0/1.0；河 0.32/1.35/0.50/0.60；湖 0.05/0/0.07/0
- 雨积水：同一材质，`puddle_mask/puddle_depth`，`u_rain` 控覆盖/涟漪/雨丝
- 桥：显示足迹 76×152；mask R 挖空、B 标记、A 保留桥下连通；前景桥 z=10
- 调试：0 关闭 / 1 mask / 2 depth / 3 category / 4 shoreline；调试时隐藏前景

## 6. 已知风险 / 限制

1. 分类是启发式（贴边 + 平均宽度），换地图需重新校准阈值；本图结果稳定为 3 个水体。
2. 桥下连通依赖 mask.A；若手绘 mask 未填 A，河会被桥切成两段（水体数 4）。
3. 积水是即时的雨量门控水膜，不模拟体积积累/排干；任务允许的简化。
4. 16px 岸线是有意的阶梯状；依赖覆盖率 + dither + 白沫线弱化边缘。
5. 中文依赖系统 CJK 字体；跨平台可能需调整 `SystemFont.font_names`。
6. 1920×1080 是 1280×720 世界逻辑的显示放大（像素风）；不是重新按 1920 栅格烘焙数据。
7. 场景程序化生成约 2–4s（受机器负载影响），不是首帧零成本。
8. 主沙滩的第二道波前与岸线白沫/浅水高光有叠加，礁石周围更容易看清双波前；如果要求逐帧更强的双线可再调参。
9. 13MB GIF 偏大；MP4 7.5MB 更适合分享。
