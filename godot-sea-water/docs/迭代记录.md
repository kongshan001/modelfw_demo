# 迭代记录 — 星海浅湾

## 2026-11-18 · 第 1 轮：复刻《星之海》式通透像素水体

**参考**：B 站 BV1C44w62Ebp《Godot 复刻〈星之海〉通透像素水体效果｜2D 水面 Shader
原理拆解》（擦玻璃的阿毛）。视频把效果拆成五层：mask、折射底、水色、泡沫、焦散；
再加交互涟漪、落点汇流、角色入水曲面水线、昼夜反光。

**实现**：Godot 4.6，640×360 像素世界 + 1280×720 HUD；全部素材由
`tools/gen_art.py` 程序化生成（场景、角色、瀑布、焦散、泡沫）。没有使用视频的
Quark 工程或《星之海》的任何素材/代码。

### 本轮问题与修复

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| Shader 编译失败 | fragment 里用了 `return` | 改成 if/else 单出口 |
| 角色水线完全没效果 | AtlasTexture 的 shader UV 是整张图集，不是单帧 0..1 | 每帧传 `u_frame_origin/u_frame_size`，用帧局部 `luv` 计算水线 |
| 瀑布/焦散改了不生效 | 游戏运行不重建 PNG 导入缓存 | 改素材后跑 `--editor --quit` 重新导入 |
| 深度图出现一条条竖直色带 | 深度量化成 16 级 + x 偏置过强 | 改回 0..255，距离场/140，柔和偏置 |
| 焦散变成满屏噪点 | Voronoi 线粗、带红边、平铺尺度太小 | 细白/青线、9 站点、40px 尺度、三次方衰减 |
| 地面大片迷彩块 | 用低频噪声阈值分色 | 改 3×3 哈希 dither + 稀疏点缀 |
| HUD 挡住瀑布/池塘 | 左上大面板 | 左上小标题卡 + 底部时间条 |
| 水位/水色偏灰 | 水 alpha 过低、底部被深色 tint 压暗 | 提亮底沙、水色加饱和、alpha 0.30–0.66 |
| 角色像站在水面 | 角色太靠深水区，水线在胸口且不显眼 | 站到中浅水、水线公式改到腰位、加强水下 tint/泡沫边 |

### 验证
