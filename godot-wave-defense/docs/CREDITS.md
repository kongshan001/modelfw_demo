## 运行时依赖

- **Godot Engine 4.6 stable**（GL Compatibility 渲染器）。
- **无第三方 GDScript 插件、无外置资源包、无网络请求。**

## 字体

通过 `SystemFont` 调用系统已安装字体，按以下顺序回退：

- 正文/粗体：`PingFang SC` → `Hiragino Sans GB` → `Noto Sans CJK SC` → `Microsoft YaHei` → `WenQuanYi Micro Hei` → `sans-serif`
- 标题：`Kaiti SC` → `STKaiti` → `KaiTi` → `Songti SC` → `PingFang SC` → `sans-serif`

字体授权遵循各操作系统/发行版自带条款；本项目不打包、不再分发字体文件。
