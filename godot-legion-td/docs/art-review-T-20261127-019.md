## Top 问题（P0 → P1 → P2，共 8 条）

### P0-1 · 单位/英雄剪影同质、阵营色撞色

- **问题**：卫士、弩手、术士、英雄共用同一套方块人躯干/头/四肢，只靠手里的小武器区分；术士/英雄用洋红，和敌方紫同族。1× 单位身高 37–47px，25% 缩略图 9–12px，96m 最大缩放 22–28px。
- **证据**：AR04 单位列队（正面/56m/96m）；01/03 4× 放大；当前色板（术士 #9B6375、英雄 #A05A7C、敌方 #7E5AA0 的 L* 47–49 全撞）。
- **根因**：`build_unit()` 复用一个方块人构造器，颜色参数化而非剪影参数化；没有“先做黑色剪影、再上色”的流程；没有尺寸层级、描边、接触影。
- **改法**（具体参数）：
  - 世界视觉高度：卫士 2.30m（1.85→），弩手 2.25m，术士 2.25m，英雄 2.80m；宽度：卫士含盾 1.50m，弩手含弩 1.70m，术士含杖 1.30m，英雄含披风/肩甲 1.90m。游戏碰撞半径不变（0.50–0.72），只改视觉。
  - 剪影破形件：卫士 = 1.0×1.3m 筝形盾 + 2.2m 短矛（盾面 0.15m 骨白边）；弩手 = 1.4m 横向弩臂 + 背后 0.8m 箭囊；术士 = 2.6m 立杖，杖顶 0.40m 悬浮余烬球，球心高于头顶 0.25m；英雄 = 1.9m 披风 + 双侧翼状肩甲 + 2.8m 长柄斧/旗枪。
  - 阵营色：玩家统一 **青铜绿 #1F8F7C + 骨白 #E6DCC6 + 铁 #8C9499**；英雄金色 #F0B23C 只占英雄的 10%。**玩家禁用洋红/玫红**；术士改为青铜绿袍 + 琥珀色法球（#FFB35C）。敌人统一瘀紫 #5B2F7A + 深渊 #24102F + 酸绿预警 #B9E84A。
  - 每个单位：60% 阵营布/甲、30% 深色皮革/铁、10% 发光/骨白点缀；禁止“同一人换色”。
  - 视觉外轮廓：距离 56m 时最细破形件 ≥10px（0.4m）；96m 时 ≥6px；用 2px 外描边（#0A0F10，α0.55）+ 脚下 1.1m 椭圆接触影（α0.45）。
  - 阵营底环：1.6m 直径，2px 暗外圈 + 2px 队色内圈，α0.55；选中环 2.4m，2px + 四角短刻线，不用纯白。
- **验收**：同一机位（52° / d=56 / d=96）输出单位列队；纯黑剪影下 4 个玩家单位两两 IoU ≤0.60；25% 缩略图 5 人盲测 5/5 说出兵种；敌人 vs 地表 ΔL* ≥18；玩家 vs 地表 ΔL* ≥20；截图/对比图入 `docs/shots/after/`。

### P0-2 · 敌人三型糊成一团、图底分离失败、无攻击预警/出生反馈

- **问题**：三种敌人都是紫色圆/块 + 白点眼；开放地面 L*44.3，敌人 L*42.4（Δ1.3），灰度下消失；没有攻击前摇，传送门出生没有前摇/落地，白色大圆环读成“选中标记”。
- **证据**：AR01 ③、AR02 ①、AR06 灰度；03_hero_skill 敌人 43×50–58×82px；15fps 抽帧无 telegraph。
- **根因**：`build_enemy()` 统一 sphere/box 语言；颜色只在紫系内变化；没有 size/aspect 分层；技能/出生只有 1 帧粒子。
- **改法**：
  - 4 个原创 archetype（3 个现有 + 1 个建议新增，需 designer 签字）：

| 原型 | 体型（高×宽） | 剪影 | 颜色 | 攻击/预警 |
| --- | --- | --- | --- | --- |
| 裂爪兽（近战虫群） | 1.4×1.6m | 低伏四足 + 0.5m 镰刀颚 | 瘀紫 + 酸绿眼 | 0.35s 后坐 → 前扑 0.12s；命中 0.08s 顿帧 |
| 酸刺虫（远程炮） | 1.9×1.4m | 驼背 + 0.9m 尾炮上翘 | 亮紫 + 酸绿囊 | 0.55s 蓄力（囊体发光 + 8m 0.4α 瞄准线）→ 0.1s 吐酸 |
| 裂隙执灯者（支援，新） | 2.2×0.9m | 瘦高 + 2.2m 灯杖（灯在头顶上） | 深紫 + 骨白面具 + 酸绿灯 | 0.6s 举灯 → 0.2s 治疗/护盾光束；被击杀断 buff |
| 熔核巨像（精英） | 3.8×2.4m | 板状躯干 + 单侧巨拳 + 胸口熔炉 | 瘀紫 + 熔橙 #FF6B35 | 0.8s 抬拳（地面 2.8m 红圈 decal）→ 0.15s 砸地 |

  - 体型/亮度层级：小怪 1.2–1.4m→L*48–56；中怪 1.9–2.2m→L*44–52；巨像 3.8m→L*44–50 + 熔炉 L*63 点缀。**任何敌人 vs 地表 ΔL* ≥18**；不满足就改地表（见 P1-1），不要靠加发光掩盖。
  - 阵营色 60/30/10：瘀紫 60、深渊 30、酸绿（仅预警/眼/囊）10。
  - 出生：传送门 1.2s 前摇（3 环收拢 + 门内亮度 0→0.8 + 地面裂纹 0.4s）+ 0.25s 爆发 + 敌人 0.3s 从门内走出（仅视觉淡入，不改选中/伤害判定；出生保护若需要由 designer 另批）。门在屏幕外时，屏幕边缘显示 48×48 的紫色箭头 beacon（1Hz 呼吸）。
  - 死亡：0.15s 命中闪白 + 0.35s 踉跄 + 0.5s 余烬溶解；每个死亡 ≤8 个余烬 quad + 1 个 1.2m 焦痕 decal（2.5s 淡出）。
- **验收**：灰度截图里敌人轮廓可分（执灯者获批则 4 型，否则 3 型）；攻击预警在 15fps GIF 中至少 4 帧可见；传送门生成的前摇/爆发/走出三段在录屏中可数；屏幕外 beacon 可见；ΔL* 记录入验收报告。

### P0-3 · 三塔同读成“白蜡烛”，类型与等级不可辨

- **问题**：棱镜/暮霜都是白色尖晶 + 深色八角底座；熔渣是暗碗 + 小暖光；三塔的第一眼都是白点。Lv1–3 只在底座加发光圆环，玩家会读成射程/目标圈，不是等级。
- **证据**：AR05（3 型 × 3 级专项捕获）；02_battle 4× 塔；25% 缩略图只剩白点；交付截图没有任何 Lv2/Lv3 状态。
- **根因**：三塔共享基座/材质/发光逻辑；等级只加 torus；没有“炮口方向”和“轮廓层级”。
- **改法**：
  - 三种剪影（纯黑可分）：

| 塔 | 世界高度/宽度 | 剪影 | 顶部/炮口 | Lv1 → Lv2 → Lv3 轮廓 |
| --- | --- | --- | --- | --- |
| 棱镜塔（单体高频） | 4.4m / 1.2m | 针 | 顶部三叉晶，光束出口在 3.8m | 单晶 → 双叉 → 三叉冠 + 3 轨道环 |
| 熔渣炮台（范围） | 2.8m / 2.6m | 碗 | 25° 上扬炮口，直径 0.6m，出口在 1.9m | 单管 → 双管侧排 → 大锅 + 3 个烟囱 |
| 暮霜图腾（控场） | 3.4m / 1.6m | 碑 | 碑面 0.3m 冰晶，环在 2.2/2.8m | 1 环 → 2 环 + 4 冰棱 → 3 环 + 地面霜环（9.5m，α0.18） |

## 美术方向与生产 brief

### 1. 方向与 pillars

**方向名：余烬荒原 / 灰烬军团（Ember Wastes, Ash Legion）**。不是写实，不是像素，不是 Warcraft 风；是**大色块、硬边、厚重量感的原创低模**：玄武岩的黑、熔岩的橙、青铜绿的军团、瘀紫的蠕群，配骨白与铁灰。所有造型来自 5–7 边的切面体，边缘 0.02–0.04m 倒角；靠 3 档明暗 ramp 和 1 条特征线表达材质，不靠高模细节。

**四个 pillar（按优先级）：**

1. **Silhouette first**：任何单位/塔/门先过纯黑剪影与 25% 测试，再谈颜色和材质；颜色只是最后 10% 的识别。
2. **Charcoal world, ember edges**：环境 L* 17–30，熔岩是 5–8% 面积的强调，不是背景主色；玩家青铜绿/骨白，敌人瘀紫/酸绿，双方都不靠“更亮”取胜。
3. **Weight & impact**：每个攻击有前摇-命中-跟随；每个命中有一个数字/闪光/方向火花；每个单位有接触影和落地感。
4. **One language**：3D 和 UI 同一套“厚边、2–3 色、实心图标、有限发光”；UI 不要细线科幻，3D 不要写实 PBR。

**参考使用规则**：只参考“读形原则/明度分组/攻击前摇”等抽象方法；不复制任何参考游戏的角色、UI、图标、贴图、关卡、品牌。所有资产原创并登记 `CREDITS.md`。

## 仍不足（即使 P0/P1 全过）

1. **音频仍为空**：无攻击/命中/建造/波次/音乐；本 brief 不覆盖音频，需单开任务。
2. **单地图/单生物群系**：余烬荒原之外没有第二张图；环境复用会显重复。
3. **第 4 敌型与玩法耦合未验证**：执灯者是否加入、是否破坏平衡，需要 designer + playtest。
4. **动画仍是程序化/简单骨骼**：能达到“可读、有重量”，但达不到 3A 级表演；近距离特写仍显硬。
5. **UI 仍只有中文**，无本地化/无障碍（色盲模式、字号调节、屏幕阅读）。
6. **无手柄/存档/设置菜单/重绑定**；相机固定 52° 不旋转。
7. **无发行物料**：没有 key art、商店 capsule、截图分级、平台合规检查；当前只是 vertical slice。
8. **未做真实玩家测试**：所有“可读性”结论来自本机截图与规则；还需要 5–10 人盲测（25% 识别、塔型识别、阵营识别）。
9. **性能只在 Intel HD 6000 测过**：更低端/移动端/不同驱动未知；峰值场景与 3 次中位数仍需补。
10. **美术方向仍是“暗色余烬”单一路线**：如果用户要更明亮/更卡通，需要另做风格选项与成本评估，不在本 brief 内偷偷改。

---

## Verdict

**REJECT（外放）**。内部 vertical slice 的功能与可玩性成立（smoke 80/80、6 波胜利、9/9 截图、真实 GPU 可跑），但美术生产的四个硬门槛——剪影、明度、UI 信息层级、渲染结构/性能——未达标。**当前版本可以继续开发，不能作为对外 demo/商店页/媒体素材。**

复评条件：T-020 完成 P0+P1、T-021 QA 全绿、T-022 对照本 brief 的 fail-closed 矩阵复评；届时如全绿，可给 **APPROVE WITH CONCERNS**（仍保留“仍不足”中的音频/单地图/本地化等），再决定是否外放。
