## Disclosures

- `00/11/11b/12/15` hide the HUD on purpose (world/asset evidence); `01–10/13` show the real HUD.
- `07/08` are real runtime end-screen renders, but their numbers are set through the debug API to
  representative full-run values (131 kills / 129.8s from `probe_legion_run.gd`); the screen itself is
  not a mockup. `05` is a real `debug_force_upgrade` draft.
- The silhouette line-up uses one of each player profession. The normal starting squad contains two
  guards; the second guard is hidden and an adept is spawned for the line-up only. This does not change
  gameplay, waves or economy.
- `11/11b` use `Camera3D` at 52°; the game clamps camera distance to 34–96m, so the close line-up is at 34m.
- `04` shows the default ghost preview on an empty selected pad; hovering a card swaps the ghost type.
- The 720 captures are true 1280×720 SubViewport renders (UI scale 1), not downscaled 1080 images.

## Reproduction

```bash
cd godot-legion-td
godot --path . -s tools/screenshot_legion_td.gd        # 16 shots + 2 thumbnails -> docs/shots/after/
godot --path . -s tools/video_legion_td.gd             # 150 frames -> /tmp/legionfall_frames_after
ffmpeg -y -framerate 15 -i /tmp/legionfall_frames_after/frame_%04d.png \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -movflags +faststart \
  docs/shots/after/legionfall_after_10s.mp4
python3 tools/art_check.py --shots docs/shots/after --ui scripts/legion_ui.gd \
  --out docs/art_check_after.json
```
