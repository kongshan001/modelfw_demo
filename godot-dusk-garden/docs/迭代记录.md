### 2.3 光柱 / 丁达尔

- 新增屏幕空间丁达尔：`post_pixel.gdshader` 朝日月屏幕位置 14 tap 径向采样，阈值 0.60、decay 0.93；深夜只保留月晕。

### 2.4 水池

- 原：`mix(deep, shallow, smoothstep(0.55,0.0,r))` + 92% 天空反射 → 奶白平板；倒影点用的是池外灯的实地点，永远打不到水面。
- 现：
  - 中心深/边缘浅：`shallow_t = smoothstep(0.34, 0.95, r)`；
  - 天空菲涅尔 `0.12 + fres*0.58`，并随 ripple 偏移；
  - 日/月镜面高光（pow 110/150），由 `sun_sky`/`moon_sky` 驱动；
  - 3 个**池内虚拟灯反射点**（0.72R 靠灯侧）+ 0.68 强度暖斑；
  - 双频量化涟漪、稀疏 glint、内圈压深、外圈湿石高光。
- 结果：黄昏是暖灰镜面，蓝调/夜里有蓝紫水面 + 橙色灯倒影 + 月/天光碎闪。
