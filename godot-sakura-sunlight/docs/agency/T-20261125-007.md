## 关键实现 / 修复

1. 固定机位 640×360 世界，所有素材由 `SakuraArt` 固定种子生成；无外部贴图。
2. 三棵樱花树、三块石头均有两段/单段地面影子；树影的树干与树冠在数学上严格接合，
   smoke 对每个时刻检查 `junction`、`tip`、段长和封顶。
3. 所有物体共享 `foliage_light` 材质；太阳方向和颜色只来自 global uniform，
   smoke 检查 `get_shader_parameter("u_sun_dir") == null`。
4. 修复 `ShadowCaster.update_sun()` 在隐藏时提前 return 导致的“关阴影后时间冻结”bug。
5. Godot 4.6 GLES3 的 `global_shader_parameter_get` 是 editor-only；运行时和工具
   不再调用它（否则 console 会报 ERROR）。全局写入路径用镜像/工程注册/shader 声明/
   无本地覆盖验证；真实 GPU 用像素差异探针验证效果。
6. 视觉迭代：树冠从 9 个大椭圆改成 29 个小叶簇 + 白花团；草地低对比化；草丛按簇分布；
   去掉土圈；增强阴影；加入前景草/暗角；最终 1920 截图可读。

## 已知风险 / 取舍

- 屏幕方位角是屏幕平面角，不是地理方位；参考的屏幕投影约定与本项目不同，
  但取反/影长闭环一致（README/TECH 已注明）。
- 阴影是 2D 剪影 + 节点变换近似，不做逐像素遮挡。
- 1.8H 树影上限是美术选择；17:00 有封顶提示。
- UI 在 1920 下 1.5×，像素世界仍 3×；若要 UI 也严格整数需另做 640×360 UI。
- 暂停只冻结时间/日照，花瓣继续飘。
- 无音频、无第三方运行时依赖。
