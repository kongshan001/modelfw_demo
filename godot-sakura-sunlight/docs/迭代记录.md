## 1. 第一版：骨架 + 太阳闭环

- 建 `640×360` SubViewport 世界、1280×720 窗口、最近邻显示。
- `SunModel` 实现：6000 刻/天；`arc=(h-12)/6`；`70*cos(|arc|π/2)`；
  `azimuth=90+60*arc`；`sun=(cos az, -sin az)`；`shadow=-sun`；
  `H/tan(clamp(elev,1,89.5))`。
- 08:00 = 35°，09:45 = 58.20°，12:00 = 70°，16:00 = 35°，17:00 = 18.12°。
- 共享 `foliage_light` / `ground_light` / `cast_shadow` 三个 shader；
  在 `project.godot` 注册 8 个 global uniform。
- 第一轮问题：世界 `TextureRect` 忘记接 `WorldViewport.get_texture()`，
  截图只有 HUD；已修复。

## 2. 第二轮：树冠 / 地面 / 草地的美术返工

第一版截图的问题：

1. 树冠像几块横向粉色松饼，暗部连成条带；
2. 草地大片深浅色块像迷彩，甚至会被误认成阴影；
3. 草丛像均匀撒下的深色“m”字形；
4. 树根下的土圈是巨大的土黄色椭圆；
5. 阴影和地面暗块混在一起，两段投影读不出来。

改动：

- **树冠**：从 9 个大椭圆改为 **29 个小叶簇**（右树 27、小树 13），
  每簇局部上亮下暗，叠加 20 个白花团 + 84 个单像素白花 + 边缘 dither；
  底缘加深，但不再整棵树横向压暗。
- **地面**：去掉土圈；低对比双层噪声 + 6200 根短草叶 + 落瓣 + 野花；
  不再用大块深浅阈值。
- **草丛**：14×12 的多刀草叶，按 45 个“草簇锚点”周围成组撒 180 丛；
  近处草更高；新增 38 丛前景草（z=28）和轻微暗角（z=45）。
- **树篱**：改成三层灌木团，改用 ground 材质 + 更低饱和度，退到背景。
- **色板**：提亮樱花粉/白，树篱变浅，阴影色改为冷青绿并提高可见度。

结果：在 1920 截图中，树冠可读为樱花树；地面不再有大便土圈和迷彩块；
阴影能独立读出；草和花有前中后景。

## 3. 第三轮：全局参数 / 两段投影 / 冻结 bug

- 两段影：
  - `total = min(H/tan(elev), 1.8H)`；
  - `trunk = min(T/tan(elev), total)`；
  - `crown = total - trunk`；
  - 树冠剪影的底边中心放在 `base + dir*trunk`，沿影向拉伸 `crown`；
  - 石头 `trunk=0`，整块剪影拉伸，上限 1.6H；
  - 所有影子共享 `cast_shadow` 材质和全局阴影色。
- 发现并修复：`ShadowCaster.update_sun()` 在阴影隐藏时直接 `return`，
  导致“关阴影 → 拖时间 → 开阴影”时影子和 HUD 的影长冻结在旧时刻。
  现在即使隐藏也更新数学姿态，只把 `visible` 设为 false。
- 全局光测试的现实限制：
  - `RenderingServer.global_shader_parameter_get()` 在 Godot 4.6 GLES3 是
    editor-only；在真实 GPU 上调用会打印 ERROR。
  - 因此运行时和工具都不调用它；headless smoke 检查镜像值、工程注册、
    shader `global uniform` 声明、无本地覆盖；真实 GPU 探针用帧像素差异
    （08→12、12→16.6、阴影开/关）证明全局光和开关确实改变了渲染。
- 2026-11-25 实测像素差异：0.333 / 0.458 / 0.035；通过。
