# 樱庭日照 · Sakura Sunlight

一个 Godot 4.6 / GL Compatibility / 2D 的**纯三角函数像素日照**技术 demo。
它复刻 B 站视频《不靠3D灯光！用初中三角函数在Unity里手搓2D像素樱花树动态日照》
里的*数学与视觉语言*，不是复制原作：

- 固定机位，**640×360 像素世界**，2×/3× 最近邻放大到 1280×720 / 1920×1080。
- 连续 **08:00–17:00** 时间；**6000 刻/天**，250 刻/时，2000 刻 = 08:00。
- 方位角 + sin/cos → 平面太阳向量；高度角 = `70° × cos(|arc| × π/2)`。
- 地面影向 = 太阳向量**取反**；影长 = `树高 / tan(clamp(高度角, 1°, 89.5°))`，
  树上限 **1.8 H**（石头 1.6 H）。
- **树干 + 树冠两段投影**：树冠剪影底边严格接在树干剪影末端，避免悬空/断脚。
- 3 棵樱花树、3 块石头、草、花、66 片 MultiMesh 飘落花瓣。
- 树/草/石头/花瓣走同一套 **global shader uniform**；没有 Light2D、没有 3D 灯光、
  没有逐物光照参数。
- 所有像素素材由 `scripts/sakura_art.gd` 用固定种子程序化绘制；无外部贴图/模型/字体文件。

参考视频（只做技术拆解，未复制任何素材/代码）：
<https://www.bilibili.com/video/BV16Fsq6NEhg>（UP：小武同学贼下饭，1:31）

## 运行

```bash
godot --path godot-sakura-sunlight
```

- 默认 1280×720，窗口可拉伸到 1920×1080；世界始终是 640×360 最近邻。
- 期望环境：Godot 4.6，GL Compatibility，Intel HD 6000 级别核显。
- 1920×1080 截图是离屏 SubViewport 渲染，避免 macOS 裁切大窗口。

## 操作

| 操作 | 说明 |
| --- | --- |
| 时间滑杆 | 拖动 08:00–17:00；拖动时自动暂停时间 |
| 播放 / 暂停 | 继续/冻结时间（花瓣仍继续飘落） |
| 速度 0.5× / 1× / 2× / 4× | 实时流逝速度；1× 时 90s 走完 08:00→17:00 |
| 重置 | 回到 08:00、1×、阴影开、花瓣开、调试关 |
| 阴影 S | 开关全部地面投影（树干+树冠+石头+接触影） |
| 调试 F3 | 世界网格、太阳向量、影向、两段影子的接点/长度/H |
| 花瓣 P | 开关飘落花瓣（MultiMesh 数量仍是 66） |
| 1 / 2 / 3 | 跳到 08:00 / 12:00 / 16:00 并暂停 |
| H | 收起/显示中文 UI |
| Space | 暂停/继续 |
| R | 重置 |

面板同时显示：时间、刻数、时段、高度角、方位角、影长（H 倍数与像素）、
光照向量、影向、FPS、draw calls。右下角太阳罗盘显示当前太阳在屏幕平面上的方位和高度。

## 关键参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 世界分辨率 | 640×360 | 1280/1920 下分别为 2×/3× 最近邻 |
| 时间范围 | 08:00–17:00 | UI/自动播放范围 |
| 一天刻数 | 6000 | 2000 = 08:00；4250 = 17:00 |
| 交互一周 | 90s | 1× 下 9 小时；媒体 10s 快速预览 |
| 正午高度角 | 70° | `70 × cos(|arc| × π/2)` |
| 日弧 | `(hour-12)/6` | 06:00 = -1，18:00 = +1 |
| 方位角 | 90° + arc×60° | 08:00=50°，正午=90°，17:00=140° |
| 平面太阳向量 | `(cos az, -sin az)` | 屏幕坐标；0°=右，90°=上 |
| 影向 | `-太阳向量` | 08:00 左下，16:00 右下 |
| 影长公式 | `H / tan(elev)` | `elev` clamp 到 1°–89.5° |
| 影长上限 | 树 1.8 H，石头 1.6 H | 17:00 起封顶 |
| 樱花树 | 3 | 主树 / 右侧树 / 前景小树；均两段影 |
| 石头 | 3 | 均有单段剪影影 + 接触影 |
| 花瓣 | 66 | 一个 MultiMesh / 一次 draw call |
| 主角树高度 | ≈131 px | 08:00 影长 ≈187 px；正午 ≈48 px；17:00 封顶 ≈236 px |
| 1920 UI 缩放 | 1.5× | 世界仍为严格 3×；UI 为可读性缩放 |

godot --path godot-sakura-sunlight --resolution 1280x720 -s tools/probe_sakura_sunlight.gd

# 一条龙（导入 + smoke + 600 帧 headless/GPU + 截图 + 两个探针）
godot-sakura-sunlight/tools/verify.sh

- headless 600 帧、真实 GPU 600 帧：日志 0 个 `SCRIPT ERROR` / `ERROR`

- 1920×1080 隔离离屏探针：平均 **129.8 FPS**，最低 **128.6 FPS**，draw calls **79**
- 完整 verify 与另一个 Godot worker 并发时：1280 平均 **91.7** / 最低 **71.0**；

## 已知限制 / 说明

- **方位角是屏幕平面角**（0°=右，90°=上），不是地理方位角；参考视频的屏幕投影约定
  可能与本项目不同，但“方位角 → 平面向量 → 取反求影向”的闭环一致。
- 参考视频 09:45 的高度角是 58.2°，12:03 的影长≈0.36 倍树高；本项目公式在同样时刻
  复现这两个数（见 `docs/TECH.md`）。
- 阴影是**精灵剪影 + 节点变换**的 2D 近似，不是逐像素遮挡；两段影的接点有单元测试。
- 暂停只冻结时间和日照，花瓣仍继续飘落；这是刻意的交互选择。
- 1920×1080 的 UI 用 1.5× 缩放保证可读性；像素世界仍是严格 3× 最近邻。
- 媒体视频是 10s 快速预览；交互版仍是 90s 一轮。
- 无音频、无外部素材、无第三方运行时依赖。
