# 迭代记录 — Blender 极意资产

## 0. 方向切换

首版 `blender-wukong/` 是金色 chibi 拼装；用户接受原创方向但要求“更精美、游戏可用、可外放”。
本版从零构建英雄比例角色，保留可编辑 IK .blend + 烘焙 GLB 的工程方式，但不复用其网格。

## 1. 造型迭代

| 轮次 | 做法 / 问题 | 修复 |
| --- | --- | --- |
| 1 | 肌肉体块 + Voxel Remesh 得到连续皮肤；初版预览全身发黑 | 3.4.1 先设 colorspace 会清空 pixels；改为先写 pixels 再存 PNG/pack |
| 2 | 银发像“海胆”、大量细长针状发片 | 发片变宽/变少/后掠，加中央脊线与弧度；保留银白尖发轮廓 |
| 3 | 裤子渲染成短裙 | 发现基元未 apply location，join 后体重/裤腿权重错位 1.36 m；apply location + world-space 权重，裤腿正常 |
| 4 | 胸口中缝像洞、腹肌像球 | 增加胸骨填充、缩小腹肌块、Smooth 2→3 次；去掉蓝脸彩绘（像眼泪） |
| 5 | 视觉太 chibi / 配色太近 | 拉长腿/颈、肌肉肩背、裤子延长到小腿上缘、橙布更饱和、蓝布提亮 |
| 6 | 蓄力姿势偏“龟派气功”且手在右胯 | 改为双手胸前聚气；胜利改为举拳；减少 DBZ 相似度 |
| 7 | GLB clip 多 1 帧 | bake 后关键帧整体 −1，clip 从 0 s 开始；导出时长精确 |

## 2. 绑定 / 导出

- 29 导出骨 + 12 控制骨（手/脚 IK、pole、腕/踝 Copy Rotation）。
- 逐 action bake（visual keying），删约束/控制骨，清理 ctrl fcurve；NLA 每 clip 一条 track。
- 校验：skins 1、joints 29、animations 6、56,072 tris、15 materials、5 images。
- .blend 41 骨保留 IK，供后续编辑；GLB 纯 FK。

## 3. 渲染

- `render_stills.py` 在 .blend 上重建 1080p 布景（石台/断柱/拱门/星月/浮石/aura/orb/beam/石傀）。
- Blender 3.4.1 EEVEE Legacy，40 samples，Filmic High Contrast；3 张 1920×1080。
- 与首版对比：`before_after.png`，960×540 ×2 并排。

## 4. 交付状态与边界

- 资产已完成、可导入 Godot、可动画/蒙皮/材质分区。
- 仍为风格化程序化角色：局部块面感、简化手指、无面部表情骨、发片刚性、布料无模拟。
- 若继续打磨：手工重拓扑肩/手/脸、加 blendshape、加毛发卡片、用 HDRI/摄影棚继续压测关键帧。
