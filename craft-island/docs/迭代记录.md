# 迭代记录 — Craft Island

## 2026-11-17 · 第 1 轮：用 Craft Anything 做净室复刻

**目标**：用 Craft Anything（`storytold/craft-anything`）复刻 B 站 Three.js
案例合集 207 期封面 / Top 2 的 Water Pro 海岛效果（BV1x4nY6xEHo）。

**方法**

1. 下载 Craft Anything v0.6.1 macOS CLI，`doctor` 通过。
2. 最小 cube 测试：确认它确实会启动独立的 Claude Code builder（Opus 5.5），
   写代码并用 Chrome 截图检查。
3. 以视频封面 + 2 张关键帧作为净室输入，写 `inputs/REQUEST.md` 与
   `inputs/ANALYSIS.md`，用 `rebuild --clean-room --unattended --rounds 1`
   生成 `app/`。
4. 工具自检 2/2 通过。它的 app-screenshot 检查只支持桌面/游戏栈，builder
   在 app 里加了零依赖 Rust 启动器来满足检查；真实 GPU 验证由 Playwright
   + Chrome（`--use-angle=metal`）完成。

**第一版 GPU 实拍的问题**

- 船的周围是一大片白色锯齿：不是泡沫纹理，而是 128² 高度场的三角面。
- 原因 1：三个 half-float RT 从未初始化，NaN/garbage 一直留在波方程里。
- 原因 2：wake splat 每帧叠加，把高度顶到 ±1.2 clamp；GPU 60fps 比工具
  的软件 WebGL 快，累积更严重。
- 原因 3：`vCrest` 用 Gerstner 波峰曲率，阈值 0.07–0.10 与最大幅值 0.099
  重合，全海都算白浪；岸线 `depth` 被 clamp 到 0.3，泡沫也偏多。
- 天空看不到云：低模云球是受光材质，镜头主要看到暗底面。
- 船体白色与泡沫混在一起；红顶被 ACES 洗成土色。

**修复**

| 项 | 做法 |
| --- | --- |
| 高度场初始化 | 三个 RT 首次使用前用 zero shader 清零 |
| wake 注入 | `uAmpScale` 按 dt 缩放并大幅降低；高度 clamp ±0.35 |
| foam | 提高 `vCrest` 阈值并乘 0.22；`depth = max(-shoreH, 0)`；拉普拉斯泡沫阈值 0.50–0.90、乘 0.12；泡沫混合 0.45 |
| 云 | sky shader 增加 fbm cumulus 投影层；低模云改亮、下移、放大 |
| 船 | 船体按水线分白/红/暗三色；红顶 `#a3211a` |
| 岛 | 棕榈 17→30，scale 1.15–1.60 |
| 相机 | 距离 22→24，仰角 0.22→0.24 |

**验证**

- `mod`? 不适用；本项目的检查是：Craft Anything 2/2 + Playwright GPU 截图。
- 最终截图：`app/docs/screenshot.png`（1280×720）。
- 视频：`app/docs/demo.mp4`（17.6s，真实 Chrome GPU）。
- 控制台无 JS 错误；只有 Chrome 的 `GPU stall due to ReadPixels` 截图警告。

**结论**：Craft Anything 能完成“从可见证据到可运行重建”的闭环；它的自检对
纯静态 Web 项目不友好，需要自己补 GPU 截图验证。第一版的方向正确，但程序化
水面的运行时稳定性必须用真实 GPU 长跑验证，软件 WebGL 的低帧率会掩盖问题。
