## 2. 实现方案

### 2.1 2D 还是 3D

参考在 450/480 s 明确是 3D 池底透视，中心圆石有可见的体积和遮阴。因此选择 **3D 场景 + 世界空间 shader**：

- 池底：40×31 PlaneMesh，程序化河床。
- 圆石：3 个程序化 UV 球变体，22 个实例。
- 焦散：`caustics.gdshaderinc` 同时被池底和圆石 shader include；输入世界 XZ，圆石再加法线偏移。
- 这样同一帧里光网连续跨过地面与石头，直接满足“shader 应用到池底/石头”。

### 2.2 原创场景

没有复制参考的石块布局、相机角度或材质。最终为一个原创的“苔泉石盆”：

- 一大块中央偏左的圆石 + 5 块错落圆石。
- 14 块岸边石 + 2 块前景剪影，围出封闭感。
- 河床是冷青淤泥、苔斑和卵石，不是参考里的单一青绿平面。
- 低多边形、手绘式受光，UI 为中文编辑器风格。

### 2.3 核心实现顺序

1. 先做 `hash22` + 3×3 F1/F2/F3 搜索，输出单独的 F1/F2/gap 调试图，验证边界归零。
2. 加入 `exp(-gap/width)` 亮纹、宽柔光、动态线宽，在平面 shader 上成立后，再上池底。
3. 加 domain warp、低频 gather、F3 交点鼓结和鼠标聚焦。
4. 构建程序化河床/圆石；同一 include 投到圆石。
5. 增加熔岩配色/阈值变体、单格教学对照、中文 HUD。
6. 最后补截图、视频和自动化验收。

## 3. 迭代与修复

### 3.1 圆石翻面（已修复）

第一版自建 UV 球使用 `(a,b,c)` / `(b,d,c)` 索引，渲染时被背面剔除，圆石像裂开的碗。将绕序改为 `(a,c,b)` / `(b,c,d)` 后，外表面完整，法线方向也正确。截图中的圆石现在是闭合实体。

### 3.2 光网密度

初版 `u_scale` 2.35，1280 宽的池底约有 50 个格宽，看起来像细密爬虫纹。逐轮调到 1.18 → 1.02 → **0.72**，约 17–20 个主格宽，接近参考中“大尺度光网 + 少量粗线”的观感。线宽、柔光、亮度也同步重调，避免越放大越糊。

### 3.3 颜色与石头可读性

- 初版偏黄绿，且圆石被光网完全覆盖，像同一张贴图。改为蓝青水色，降低岩石上的焦散增益（0.34 / 0.22），提高上表面苔藓与湿高光，使岩石保留体积。
- 河床贴图从偏亮改为深青；水面微光最高 alpha 0.30，避免抢焦散主体。
- 最终圆石仍能看出光网投影，但不会变成高亮线框球。

### 3.4 UI 与截图问题

| 问题 | 处理 |
| --- | --- |
| 搜索按钮 active 索引写反（3×3 显示成单格） | 改为 `1 if search_3x3 else 0` |
| 单格分析后切 F1/F2 未恢复 3×3，导致 F2 全黑 | 截图序列在 F1 前恢复 3×3 |
| 1920 连续截图写盘后 FPS 显示 2 | 面板截图前空转 3 s 让引擎 FPS 恢复；最终显示 59 |
| 自动环视状态在面板上过期 | 截图前调用 `sync_ui()` |
| 亮背景上标题难读 | 增加顶部/底部程序化渐变 + 文字阴影 |
| 右上 FPS/DC 在批量截图时失真 | 分析视图隐藏统计，面板图保留真实值；正式性能以 probe 输出为准 |
| 单格最终图被误标成 F2−F1 | 模式文案改为“F1 等距环 / 格缝断裂”，并给黄色警告 |

### 3.5 相机边界

移除初始的无限 yaw 拖拽和过大俯仰/距离；最终约束为 yaw ±12°、pitch 48–60°、距离 12.8–17.2，避免用户看到 40×31 河床之外的黑色空洞。

### 3.6 媒体

- 首次 GIF 29 MB，改为 800 px / 12 fps / 160 色调色板，降到约 16 MB；MP4 1920×1080 / 30 fps 约 5.1 MB。
- 逐帧捕获时把主循环置为暂停，由帧号显式写 `u_time` 与相机位姿，保证离线渲染速度不会改变 10 s 视频节奏。

## 6. 已知差异 / 风险

- 参考只有 480p，细线宽度、软光扩散和最终色调的还原精度受限。
- 光网比参考更规整、更像“网”；可通过提高扭曲强度、调整 scale/gather 来改变，但当前默认值在性能与清晰度之间取了平衡。
- 圆石上的光纹仍偏线框感；进一步可做法线相关宽度/多次模糊采样，但会增加成本。
- 单格模式是教学近似，不提供有效 F2；HUD 已明确标注。
- 水面的视觉暗示是可加性微光，不是折射。
- GIF 16 MB，较适合作为文档资产；即时分享优先 MP4（5.1 MB）。
- 截图 1920 面板中的 FPS 来自当次离屏运行的稳态值（59），正式性能请用 probe 数值（最近一轮 105.9 / 58.2 fps，多次 94.6–105.9 / 53.5–58.2 fps）。
