# 素材与参考

## 原创声明

- 场景中的全部几何、材质、灯光、相机、动画均由 `scripts/build_scene.py` 程序化生成；
  仓库不含任何外部模型、贴图、HDRI 或音频文件。
- 造型参考了开源项目 [elvarofficial/teardown](https://github.com/elvarofficial/teardown)
  里的 Mellis HB-7 机械蜂，以及 B 站视频《这居然是 Fable5.2 用代码做出来的视频？怎么实现的？》
  所展示的 Blender + MCP 工作流。
- 本工程是独立实现：没有复制原项目的代码或素材；Blender 场景文件由本仓库脚本生成。

## 工具

- Blender 3.4.1（渲染）/ Blender 4.2.9 LTS（建模、MCP）
- [mcp-for-blender](https://github.com/ahujasid/blender-mcp)（MIT）
- ffmpeg（视频封装）
