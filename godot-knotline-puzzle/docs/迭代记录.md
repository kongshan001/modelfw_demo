### 从视频得出的需求（与本任务 brief 合并）

1. 3D 一笔画：一条从锚点出发、不能断的线；鼠标/指针在 3D 表面和空间中操作。
2. 轨道相机：可绕、可缩放；画线时也需要转镜头看背面。
3. “打结”不能只是数圈：需要至少一种可玩的结条件；本实现选择**绕柱 ≥1 圈 + 自交分出上下**（近似）。
4. 友好的 undo：视频右侧的 Quick undo 是核心体验；本实现做成 Z 逐点撤销 + 0.2 s 收绳动画。
5. 视频里引导偏弱；本实现特别强化中文 HUD、目标进度和情境提示。

### 明确没有照搬的部分

- 原游戏的生物角色、拖尾式“角色画线”控制、橙/粉色世界、黑色圆环目标、编号垫、极简角落 UI、关卡布局、品牌/名称/音频。
- 本项目按任务要求采用**鼠标射线画线**，不是角色拖尾；用粉绿/奶油色漂浮 diorama、糖果条纹绳、中文卡片式 HUD，这些均为原创。

## 3. 实现迭代（按提交顺序的思考过程）

### 迭代 1 · 核心闭环

- `KnotRope`：锚点 + 用户/自动控制点；加入 `min_step`、边界/高度夹取、柱体圆弧避让。
- `KnotTube`：Catmull-Rom + 平行传输 Tube + UV；先验证网格规模、法线、索引。
- 关卡 1：一根必须青柱 + 一个可选铃柱 + 结台；路径用无头工具验证能绕满、能到达。
- 关卡 2：两根必须柱 + 1 次自交；用“低股 0.55 m / 高股 0.90 m”的 X 形自交。
- `tools/probe_paths.gd` 打印 winding、resolved/flat 交点和目标检查；确保演示可解。

**发现**：最初的 winding 把整条路径的带内角变化全部相加；玩家绕满一圈后把线尾甩出柱子，尾部反向角变化会抵消圈数，出现“看着已经绕满但不判定”。这是从演示路径的 430° 只得到 335–365° 发现的。

**修复**：winding 改为**按连续柱周区间取绝对值最大的 run**；判定改为 `abs(turns)`（顺时针也可）。同时把演示路径的绕圈加到 400° 并让出口沿切向离开，给鼠标密度采样留余量。

### 迭代 2 · 引导与 Undo

- HUD：左侧关卡片 + 目标行（✓/○/·，必须/可选、角度/圈数、自交、结台距离）；右侧模式徽章；底部深色提示条 + 控制行。
- 情境提示优先级：没开始 → 续笔 → 最近缺失的必须绕柱 → 自交上下 → 结台 → 可以收笔；`H` 轮换关卡内置提示。
- 解决视频“引导不明显”：玩家始终知道“下一步差什么、差多少”。
- Undo：最后用户点 + 它产生的弧点一起回退；用临时的“回收尾”polyline 做 0.2 s 平滑动画；探针验证 9→8 步。
- `Esc` 收回整笔，`R` 重建本关。

### 迭代 3 · 视觉与可读性

- 第一版绳偏细、被环境光洗成粉白；把半径从 0.045 提到 **0.068 m**，shader 改为奶油/珊瑚对角条纹，加暗色 Fresnel 描边和微弱自发光。
- 第一版柱子完成的提示只是淡蓝环；改为完成后**金色环 + 收珠**，未完成时小珠绕柱环旋转；目标更醒目。
- 结台加悬浮金色环/光珠；起点保留金色浮环；可选铃柱有铃铛。
- 接触阴影（MultiMesh）、踏脚石引导带、花/蘑菇/石/灌木、两座远景浮岛、云朵、尘埃；解决“飘在空中没有落地感”的问题。
- 由于方向光投影在本机 Intel GL 驱动上偏淡，追加了压扁的绳影（同一 TubeMesh 的 y 压扁副本）与接触阴影；截图里绳子明显有落地/高低感。
- 相机重新取景：加大 distance、抬高 focus，解决第一版岛体被提示条切掉、第二关起点在屏幕外的问题。

### 迭代 4 · 性能

- 第一版在 1280×720 live 窗口约 50 FPS（带绳），1920 截图只有个位数；绘制量/draw call 偏高。
- 优化：
  1. 游戏内关闭 MSAA（截图 SubViewport 单独 2×）；
  2. 方向光阴影贴图 2048、max distance 14；
  3. 接触阴影、踏脚石、石子、云合并为 MultiMesh；
  4. 自交度量抽稀到 420 个样本、按 0.18 s 节流；
  5. HUD 0.12 s 刷新；去掉面板阴影；
  6. 去掉 5 瓣花，改单花头；
  7. 截图/视频模式隐藏实时性能卡，避免把回读帧率当成游戏性能。
- 结果：1280×720 live 窗口最终探针 `LIVE_ROPE fps=113.7 draws=173`、`LIVE_IDLE fps=56.0`、`LIVE_DEBUG fps=108.7`；HUD 截图显示 109 FPS / 182 draw（带调试）。全部高于 30 FPS 验收线。
- 多次运行因 macOS 窗口遮挡/省电策略出现 55–152 FPS 波动（早前一次带绳 126.6）；以最终 live 探针与截图为准，并在 TECH 说明。

### 迭代 5 · 截图与视频

- 1920×1080 截图：SubViewport 1920×1080 + `size_2d_override=1280×720` 拉伸 + MSAA 2X；UI 按 1280 布局后 1.5×，3D 原生 1920；7 张覆盖全景/画线中/绕柱/双桩成结/过关/调试/第二关全景，另加一张 1280 live 性能图。
- 视频：固定 `--fixed-fps 30`，300 帧、10.00 s；脚本按时间顺序喂控制点（不是每帧截屏的 wall-clock），画完后停 1 秒展示成结，再过关；`ffmpeg` 编码 MP4 与 GIF。
- 第一次视频用 wall-clock 录帧只得到 12.8 fps（回读+JPG 落盘拖慢），且在 7.5 s 卡在珊瑚柱 325°（densify 后 winding 掉到阈值以下）；修复 winding/路径后改为 fixed-fps 300 帧，最终视频在 7.5 s 全部目标 ✓，9.2 s 显示“全部结成！”。

### 迭代 6 · 验收

- `KNOTLINE_SMOKE_OK checks=98 levels=2`（headless，无 ERROR/SCRIPT ERROR）。
- 真实 GPU 600 帧（10 s）运行无 ERROR。
- `probe_live`：屏幕射线点击起点 → 17 raw points / 9 steps；`game.drawing=false` 后 Z 撤销 9→8；shadow enabled。
- 1920 截图 7 张 + 08 live 1280；MP4 300 帧/10 s，GIF 120 帧/10 s。

## 5. 遗留问题 / 下一步

- 自交的 XZ 平面启发式在近顶点/竖直交叉会漏检；可加顶点 epsilon 扰动或 3D 最近 Distance 补充。
- winding 只按单柱、水平带；如果以后做多柱联合/三叶结，需要真正的局部 crossing 序列与符号。
- 方向光阴影在 Intel GL 上仍偏淡；可考虑烘焙 blob shadow 或更高影子贴图（有性能代价）。
- 视频无声；若要展示音效，需要 A/V 同步录制。
- 触摸仅为鼠标模拟；无手柄。
- 字体子集需随新文案重生成。
