## 2. 做了什么

- **循环**：基地 → 部署 → 6 分钟雾港 → 搜箱/战斗 → 撤离/阵亡/超时 → 结算 → 仓库/升级。
- **地图**：程序化 2400×1500 雾港（仓库、11 集装箱、7 木箱、栈桥、围栏、水洼、灯光锚点、9 箱、8 敌、撤离栈桥）；矩形碰撞层 1；玩家层 2；敌人层 4。
- **玩家**：WASD、鼠标瞄准、左键 hitscan、R 换弹、Shift 冲刺、HP/弹药、受击无敌/击退、冲刺残影。
- **敌人**：潜伏者（近战）/ 枪手（远程）/ 港区看守（精英三连发+近战）；PATROL→ALERT→CHASE→ATTACK→STAGGER→DEAD；墙体视线、0.85 雾视野系数、丢失视线 3.4s。
- **战利品**：8 类，稀有度 0–3、价值、占格（1×1/2×1/2×2）、堆叠；普通/精英箱权重与精英保底；搜索 0.9s、剩余留在箱内。
- **背包**：6×4，首格扫描、堆叠、使用/丢弃、容量限制；打开暂停世界；界面支持鼠标/方向键/U/X。
- **撤离**：2:00 或搜箱 2 次激活；站入 3 秒；离开清零；HUD 剩余时间/状态/进度。
- **基地/升级**：仓库容量（24→42）、初始医疗包（1→4）、武器伤害（18→27）；信用点；回收仓库；`user://fogfall_save.json`。
- **结算**：成功——旧港币换钱、物资入库、溢出折现；失败——清空当局背包，仓库/信用点/升级不变。
- **渲染**：全部程序化绘制；单次全屏夜间/雾/手电/光池 shader；静态地图预渲染；UI 网格批处理；离屏裁剪。

## 6. 与线程的关系 / 复用了什么

本任务是该线程的第 3 个 Godot 可玩 demo。沿用既有**工程约定**（不复制代码/素材）：

- `godot-inventory-ui/`：6×4/九宫格、数据驱动物品与稀有度/堆叠的 schema 思路；
- `godot-wukong-ultimate/`：Godot 4.6 GL Compatibility、程序化原创美术、1920×1080 SubViewport 截图/媒体管线；
- `godot-flowfield/`：headless smoke 末行 OK 的验收格式、共享主机性能采样与 caveat 写法。

相对父线程新增：**搜打撤完整循环、撤离转移与死亡丢包、仓库/3 升级持久化、3 敌型 AI、雾中视野、6×4 占格背包、单次全屏夜间/雾 shader、地图预渲染与 UI 批处理**。

## 7. 已知风险 / 后续

- 共享主机 GPU 争用导致 FPS 波动；验收应以低负载整轮或 best 2s 记录，并附 `uptime`。
- 伪光照无墙体遮挡/真实阴影；AI 无 NavMesh；单地图、无音频、无触控。
- 系统 CJK 字体未打包；存档非原子写；弹药无补给、敌人无掉落。
- 预渲染地图为 2400×1500 RGBA（约 14MB），极低显存设备需改用回退/缩图。
- 下一步可选：真实 navigation、灯光遮挡、音频、更多武器/护甲、随机地图、移动端触控。
