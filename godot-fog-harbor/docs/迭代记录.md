## v0.4 · 性能与最终自测

### 问题

初版使用 `CanvasModulate + 8 × PointLight2D + 22 个网格格线`：
- Headless 逻辑很快（process ≈0.1ms），但真实 Intel HD 6000 上战斗场景只有 10–15 fps；
- draw calls 333；
- 2D Light2D 的多 pass 与大量逐格绘制在旧 Intel GL 驱动上代价高。

### 处理

1. **移除所有 2D Light2D / CanvasModulate**，改为单次全屏 `fog_overlay.gdshader`：
   - 夜色遮罩、3 个灯池、玩家径向光、手电锥、雾纹理、暗角一次画完。
2. **地图预渲染**：静态地图渲染到 2400×1500 SubViewport，烘焙为 `ImageTexture` 后释放 viewport，用 1 个 Sprite2D 显示；失败回退直接绘制。
3. **UI 批处理**：仓库/背包格线用 `draw_multiline`；面板去掉装饰角线（每面板 4→2 条 draw）。
4. **离屏裁剪**：敌人/箱子按相机距离隐藏视觉，AI/物理继续。
5. **HUD 重绘降到 12.5Hz**。

结果：战斗场景 draw calls 333 → **123–133**；空场景 169–209 fps；全屏夜间 shader 112–169 fps。
