## 关键实现

- **雾**：WorldEnvironment 指数深度雾 + 高度雾（Compatibility 支持）；20 片 billboard 雾片 + 2 层水平 patch 雾 + 248 CPU 粒子；4 组交叉面片伪光束；8 taps 屏幕空间 god rays；色调/暗角/颗粒。
- **明确不是真体积雾**：Compatibility 不支持 Volumetric Fog；custom shader 的 `FOG` 输出在 Compatibility 不可用，故未做 depth/raymarch 体积雾。TECH 与 README 均如实说明。
- **原创场景**：程序化地形/树/石/石柱拱门/踏石/浅潭/睡莲/芦苇/石灯笼/雾精灵/草，全部原创低模；无 Zelda/任天堂素材。
- **交互**：拖拽环绕/滚轮/WASD/自动环绕；F 雾浓度、G 雾层高度、C 雾色、B 风、N 昼夜、1/2 质量、R 重置、Tab HUD；FPS 显示。
- **质量档**：高=雾片20/粒子248/光束4/草1200/阴影2048/Glow/god rays；低=9/104/2/540/无阴影/无rays/保留Glow。

## 已知风险

- 雾片是 2D billboard，极近/极侧视可见片状；god rays 无深度遮挡；无运动模糊/景深。
- 1080p 高质余量有限（~35fps）；窗口高度在本机被系统夹到 762（内部始终 720p 渲染）。
- 共享主机负载尖峰会造成 720p 高质 33–48fps 波动；以 median/best2s 与 docs/fps.txt 为准。
- 水面/灯笼/精灵为解析风格化光效，无真实反射/光追/点光阴影。
