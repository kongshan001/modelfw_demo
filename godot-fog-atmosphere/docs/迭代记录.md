## 0. 参考确认（先抽帧）

- `yt-dlp` 拉取 720p 短链 → 实际为 360×640 竖屏、30fps、12.7s。
- `ffmpeg -vf fps=2` 抽 25 帧 + 5×5 contact sheet，再查看关键帧。
- 观察结论：
  - 贴地白色雾团（高频丝状翻涌），不是全屏均匀雾；
  - 大量金色/黄绿浮尘、流萤、近距离柔光团；
  - 苔藓林地、草、树根、石块；无水面/遗迹/光柱；
  - 高角度倾斜的缓慢环绕镜头，角色跑动带运动模糊；白天柔光。
- 复刻策略：保留“低空雾团 + 浮尘 + 柔光 + 高角度环绕”视觉语言；场景、水面、遗迹、灯笼、夜景/光束均为原创扩展。

## 1. 技术验证（spike）

在 /tmp 独立 spike 工程验证 Godot 4.6 / GL Compatibility：

| 验证 | 结果 |
| --- | --- |
| WorldEnvironment 指数深度雾 | 可用（有画面差异） |
| `fog_height` / `fog_height_density` 高度雾 | **可用**（低处更浓，柱底被淹没） |
| Volumetric fog | Compatibility 不支持（官方渲染器特性表） |
| Glow | 可用；unshaded 高亮球会泛光 |
| 自定义 Sky shader | 可用（太阳/月亮/星星） |
| `hint_screen_texture` 全屏后处理 | 可用（径向采样/调色/暗角） |
| custom spatial shader 写 `FOG` | **不可用**（Unknown identifier 'FOG'）；放弃屏幕深度重建雾 |
| StandardMaterial3D / Unshaded / 自定义 spatial | 都被环境雾覆盖（远球体整体雾化） |

结论：以**引擎深度+高度雾**为底，雾片/粒子/伪光束/屏幕 rays 补体积感；不伪装真体积雾。

## 2. 迭代过程

### v1 — 骨架 + 初版场景（当天 18:23）

- 程序化地形 110m/72×72、29 棵树（MultiMesh 树干+树冠）、34 石、石柱/拱门、踏石、圆形浅潭、3 灯笼、雾精灵、900 草。
- 雾系统初版：18 雾片 + 2 水平雾层 + 190/34/24 粒子 + 4 光束；环境雾首次参数。
- 问题：解析错误（`INV_VIEW_MATRIX`/`FOG` 不可用、`uv1_scale` 是 Vector3、Variant 类型推断）；已修复。画面：环境高度雾过浓、整体发白；水面是亮灰大矩形；草是白色小锥；夜光柱过实。
- 截图：/tmp/fog_dev_*.png（未入库）。

### v2 — 降低环境雾、水面改圆盘、草换几何叶片前的调整

- `fog_density` 档降至 0.0010–0.0095，`fog_height_density` 昼 0.030、夜 0.085；雾片 alpha 0.30。
- 水面从 PlaneMesh 矩形改 CylinderMesh 圆盘，降低反射/高光；草先改为交叉 alpha 叶片（仍像梳齿）。
- 结果：地面细节显出来，夜晚光束/灯笼成立；白昼偏冷、水平雾层像均匀白纱。截图对照记录在 /tmp。

### v3 — 草地改真几何、潭盆重塑、补丁雾纹理、暖色

- 草：每 tuft 7 个真实三角叶片（1200 实例），取消 alpha 裁剪；实例颜色更绿；彻底消除“白色锥/黑梳齿”。
- 地形：潭区先压平到 0.35m 岸台，再挖 2.1m 碗；水面圆盘半径 6.35m，水面 -0.35m，岸坡埋住水盘边缘；加 9 片睡莲、岸边芦苇。
- 雾层：新增 256² 可平铺 patch 噪声（四角混合 FBM），水平雾层不再均匀；雾片尺寸/alpha 提高。
- 色调：昼太阳 (1.0,0.90,0.72)/能量 1.18，环境 0.74，雾色晨白 (0.86,0.83,0.73)，post 高光偏暖；夜雾压暗、环境 0.26、月光 0.30。
- 夜景：`moon_dir` 降至仰角约 21°，使截图能拍到月盘/星空；月光束强度 0.04→0.42。
- God rays：锚点优先月/日，其次精灵/灯笼；8 taps；从月盘拉出可见放射光。

### v4 — 最终视觉定稿

- 雾浓度档扩到 [0.0004, 0.0020, 0.0044, 0.0085]，高度 [0.4,1.2,2.4,3.6]m；雾片 alpha 因子 [0.25,0.65,1.0,1.30]；浓/淡对比明确。
- 低质量保留 Glow（观感优先），关阴影/god rays，减少雾片/粒子/光束/草。
- 性能优化：方向光单级阴影 2048/48m（原 2 splits）、后处理 rays 10→8 taps；1080p 窗口高质量从 ~29 提到 **35fps**。
- UI：截图工具隐藏 FPS 数字，避免把 1920×1080 SubViewport 采集帧率误当运行帧率；交互时 FPS 正常显示。

## 5. 决策与未做

- **不做真体积雾**：Compatibility 不支持，且自定义 FOG 不可用；用引擎深度+高度雾 + 雾片/粒子/伪光束，TECH 明确声明。
- **v1–v4 不做角色**：把资源集中在雾/大气；T-20261124-005 按要求加入 **CC0 KayKit Rogue** 与动态雾交互（见第 6 节），未复制参考视频角色。
- **不做运动模糊/景深**：参考的跑动模糊依赖角色动画；本 demo 以静态环视+缓慢环绕展示雾的流动。
- **水面是风格化**：解析波光/菲涅耳/太阳高光，无反射/折射；换来低端 GPU 可跑。
- **未做移动端触控/音频**：任务未要求，保持范围。
- **已知瑕疵**：极近观察雾片可见片状；夜间光束从侧面较薄；god rays 无遮挡；灯光是伪光（无点光阴影）。

## 6. T-20261124-005 — 角色 + 动态雾驱散

目标：在父任务雾景上追加**可操控第三人称角色**与**动态雾驱散**，保留原自由相机/质量档/昼夜；不改变原全局雾观感。

### 6.1 角色与相机

- 资产：KayKit Character Pack — `Rogue.glb`（CC0，内嵌贴图），从 `godot-changan-action/assets/models/kaykit/` 复制到本工程；记录于 CREDITS。
- 原始高 2.33m → 缩放 0.74 ≈ 1.73m；脚底 y=0；模型 +Z → `ModelRoot` 旋转 PI。隐藏武器/披风 7 个网格。
- 动画：`Idle` / `Walking_A` / `Running_A`；状态切换 0.20s blend，`speed_scale` 跟实际速度（0.6–1.45）。
- 移动：WASD/方向键/左摇杆，Shift/A 奔跑；相对相机 yaw；2.0 / 4.6m/s；指数加速 11、转向 12。
- 贴地/碰撞：terrain_height 每帧贴地；世界半径 33m；池岸水外 0.55m；树干/石柱/灯笼圆推离（+0.38m）。无物理刚体。
- 相机：默认第三人称 26°/20°/7.2m；V 切自由相机（保留 26°/36°/15.5m、WASD 平移）；鼠标左键/右摇杆环绕，滚轮 3.5–12m。相机对树干/高石柱做 2D 圆+视线步进拉近，并抬高避免钻地。
- 回退：程序化胶囊人形（`FOG_FORCE_PROCEDURAL=1` 可验证），有摆动动画、阴影、柔雾薄纱。

### 6.2 动态雾驱散迭代

- v5.1：先做雾片逐实例 alpha + 水平雾层 shader 遮罩 + 玩家处 15% 系数。**问题**：浓雾下全局环境雾很白，只清这些还不够可读；近处雾片数量随机，可能没有刚好在角色旁。
- v5.2：加入**跟随角色的 8 片近身雾团**（2.2–5.0m，低 alpha），平时提供局部雾量；移动时推到 +0.52×半径外并保留约 45% alpha，形成“雾被推开”的可见雾墙。该层是半径/强度变化最直观的视觉反馈。
- v5.3：加入近身雾粒子（44，移动 alpha 0.20→0.05）、雾浪（16 片，0.14s 间隔、1.25s 寿命）与足迹雾 burst（7）。停下后 0.35s 延迟 + 1.6s 线性恢复；F1 双环 + HUD 调试行。
- v5.4：解决角色可读性——近身雾片保留 35% `BODY_SOFTNESS`，角色加 `MistVeil` billboard 与夜间隔雾补光（0.10→0.48）。
- v5.5：出生点/机位迭代：最初出生点脚底有石块/踏石、跟随相机撞树；加入相机圆避障，选定 (1.5,18.5) 的开阔草地出生点（无石块/踏石、相机无遮挡）。相机避障是 2D 圆近似，仍可能被树冠/灌木局部遮挡。

### 6.5 限制 / 后续

- **局部清雾不是局部体积雾**：只清可见雾片/雾层/近身雾/粒子；全局深度/高度雾无法逐像素修改，远处保持。
- 相机避障是 2D 圆近似；树冠/灌木不处理；极端角度可能仍有遮挡。
- 角色无 IK/坡面贴合；无跳跃/战斗/音频。
- 1080p 高质 33fps 余量不大；近身雾墙在极近距离仍有 billboard 片状。
- 后续可选：脚部 IK、深度遮挡清雾（Forward+ 体积雾）、角色武器/披风动画、移动端触控。
