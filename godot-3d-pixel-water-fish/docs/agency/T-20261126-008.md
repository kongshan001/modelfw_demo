## 关键实现

- **像素管线**：WorldViewport 640×360（MSAA/AA/TAA 全关）→ CompositeViewport
  640×360 canvas_item 后期（描边/调色/Bayer+哈希抖动/12 色阶）→ 最近邻整数倍显示；
  UI 在 root CanvasLayer 全分辨率。
- **两段式原因**：SubViewport 的 `hint_depth_texture` 恒 0；3D 后期与水面同时读屏幕
  纹理时，后期拿到早于水面的 backbuffer 拷贝，水会从最终画面消失。拆成 World →
  Composite 后水面/折射完整进入后期。深度/法线调试改为材质覆盖。
- **像素稳定**：所有 3D shader 在 clip space 吸附虚拟像素网格；`g_pixel_snap` 可关。
- **水面**：384×288 解析场（R 水深、G 离岸距、B 陆地、A 水），冷青绿浅/深色阶；
  屏幕 UV 折射；岸线 G 场泡沫 + 岩石 + 鱼/雨涟漪；假岛影；稀疏碎光；程序化焦散；
  水下亮顶棚 + 3D 光柱 + 后期光带；鱼附近风格化通透水窗。
- **鱼**：3 种原创程序化低模（锦鲤 0.76m / 青鳞 0.46m / 银灯 0.34m）；instance
  uniform 尾摆；boids 分离/聚合/对齐/锚点/边界/深度；近水面涟漪；无外扩壳（早期
  外扩壳在 Godot cull 方向下导致整鱼变黑，已移除，改 rim + 屏幕描边）。
- **光照/氛围**：半 Lambert 3 段量化 `light()`；5 个时段关键帧（光色/能量/天空/雾/
  曝光）；雨夜；水下雾/FOV 58°；无实时阴影（岛影为解析假投影）。
- **相机/UI**：轨道相机、自动环绕、水上/水下平滑切换与相机夹取；中文 HUD
  11 个滑条、分辨率/调色板/吸附/暂停/天气/预设/视角/调试；FPS/draw calls/RT/鱼数。

## 已知风险 / 限制

- GL Compatibility SubViewport 无屏幕深度纹理 → 无深度/法线屏幕描边；用亮度/色度
  Sobel + 鱼体 rim；深度/法线只做材质覆盖调试。
- 无实时阴影/SSR/SSAO；水面为解析风格化模型；鱼附近水窗是艺术处理。
- 开发屏 1440×900，1920 截图用 CaptureViewport；视频由 1280 放大，而非原生 1920 窗口。
- HUD 固定 px，1920 下相对较小；FPS 采样受系统窗口/调度影响，min 有毛刺。
- 参考视频只用于分析，没有复用任何素材/代码；如版权或平台要求，可移除参考链接。
