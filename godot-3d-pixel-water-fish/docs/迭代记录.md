## 2. 实现迭代

### 迭代 1：像素管线 + 场景/水面/鱼群骨架

- 建立 `WorldViewport 640×360` + 最近邻放大 + 整数缩放；1280→2×、1920→3×。
- 程序化池塘场（384×288 RGBA）、地形/草岛/岩石/草簇/水草、水面/光柱/气泡。
- 3 种原创低模鱼 + instance uniform 摆尾 + boids。
- 首个全屏后期四边形 + Bayer 抖动 + 描边。
- **问题**：GL Compatibility + SubViewport 下深度纹理采样恒 0；水体厚度=0 导致全池
  接触泡沫；后期读屏幕纹理时复用早于水面的 backbuffer 拷贝，水面从最终画面消失。
- 证据：深度调试整屏纯色；水面“泡沫铺满”；隐藏后期四边形才看得到水。

### 迭代 2：两段式 viewport + 解析水面

- 改为 `WorldViewport`（3D + 水）→ `CompositeViewport`（canvas_item 后期采样世界纹理）。
- 去掉屏幕深度依赖：
  - 水深/浅水用解析场 R 通道；
  - 泡沫用场 G 通道 + 岩石列表 + 涟漪事件；
  - 深度/法线调试改为材质覆盖；
  - 描边改为亮度/色度 Sobel。
- **问题**：初版水深场被岛距压得过浅（池心仅 0.16），整池仍被当岸边浅水；重排
  岛屿并把深度拆成“离岸深度 × 近岛浅滩因子”。
- **问题**：鱼的外扩描边壳在 Godot cull 方向下把整条鱼变黑；移除壳，改鱼体 rim +
  屏幕描边。
- 水面屏幕折射恢复：鱼在水下可见且轻微扭曲。
- 证据：`docs/shots/03_underwater.png`、`05_debug_lowres_rt.png`、`06/07/08_debug_*`。

### 迭代 3：颜色/构图/清晰度

- 场景调亮：太阳能量 1.24–1.45，环境光 0.6–0.78，曝光关键帧；草岛顶颜色提亮、
  土壁保留深色对比。
- 水面从“沼泽绿”改成乳浊青绿：浅水/深水冷色、减少屏幕地面权重、加低频噪声与
  焦散光网；岸线泡沫收窄，碎光改成稀疏短划线。
- 抖动从 0.45/8 级调到 0.20/12 级，Bayer+哈希混合，减少“雪花”。
- 鱼：加橙红饱和度、轻微自发光、鱼附近“通透水窗”；加大锦鲤尺寸、降低群聚强度。
- 水下：FOV 58°、相机地底/水面夹取、8 组光柱 + 后期光带、顶棚渐变。
- 1920 截图：开发屏 1440×900，改用 1920 CaptureViewport（640 3× + 1920 HUD）。
- 证据：`docs/shots/01_surface_wide.png`、`02_fish_school.png`、
  `04_caustics_foam.png`、`09_golden_hour.png`、`10_night_rain.png`、
  `11_hud_panel.png`；`docs/water_fish.mp4`。

## 3. 与参考的对照

### 做到的部分

- 高角度俯视浅水池塘 + 4 个草岛 + 深色土壁 + 白色虚线岸线。
- 乳浊青绿水面、水底沙/藻、白色碎光与涟漪、岛影。
- 3 种原创鱼（橙锦鲤/深青/银蓝）在浅水下游动，可见且受水面轻微折射。
- 像素化：640×360 → 整数倍最近邻；12 色阶 + 抖动；亮度/色度描边；像素吸附。
- 水下光柱 + 亮顶棚；雨夜雨丝；黄昏暖光。
- 中文全分辨率 UI、轨道相机、暂停、内部分辨率、水面参数、鱼数量、调试视图。

### 与参考的差异

- 参考水面更“水彩/手绘”，有更丰富的蓝绿层次与柔和光斑；本项目的解析水色更平，
  更依赖抖动与噪点，整体偏“清爽像素池”。
- 参考疑似有真实深度/法线屏幕描边；GL Compatibility 下不可用，本项目用颜色边缘 +
  鱼体 rim，轮廓强度与稳定性略逊。
- 没有实时阴影/SSR；岛影是解析假投影。
- 鱼模型是低模管状 + 鳍，近看比参考简单；没有骨骼/软体变形。
- 参考岛更大、草更密；本项目为了可读性与性能，岛略小、草簇更块状。
- 参考色板可能经过逐帧调色板/K-means；本项目是程序化亮度/色度 36 色（可选）+ 12 级通道量化。

## 4. 交付参数快照

- 内部 640×360；1280×720 → 2×；1920×1080 → 3×。
- 色阶 12、抖动 0.20、描边 1.0、调色板关、像素吸附开。
- 水：清澈度 45%、深水 30%、折射 0.40、泡沫 0.45、焦散 1.0、波纹 0.60。
- 鱼 20 条（6–36），3 种，深度 -0.30/-0.60/-0.80 m。
- 相机：水上 FOV 48°、默认 yaw 26°/pitch 62°/dist 16；水下 FOV 58°、
  target (0,-0.2,-2)、yaw 5°/pitch -3°/dist 7。
- 时段关键帧 5 个；预设 晨光/正午/黄昏/雨夜；雨夜含雨与雾增强。

## 5. 已知问题 / 下一步

1. 深度/法线屏幕描边需换 Forward+/Mobile 或用额外深度 prepass；当前已记录限制。
2. 水面可再加一层真实菲涅尔反射/天空球或手绘调色板，更接近参考的水彩感。
3. 草岛顶面/土壁可增加程序化细节（土纹、草叶层次），减少“大平块”感。
4. 鱼群近景可加眼睛/鳍骨/轻微软体弯曲。
5. HUD 可增加 1.5×/2× DPI 缩放，1920 下更易读。
6. 视频为 1280 录制后放大；若屏幕允许，可直接 Movie Maker 1920 或自建 1920 帧序列录制。
