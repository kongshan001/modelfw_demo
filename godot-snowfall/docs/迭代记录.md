# 迭代记录 — 雪夜墓园

## 2026-11-19 · 第 1 轮：2D 雪天效果

**参考**：B 站 BV18DYt6mE24《2D游戏中的雪天效果 DEV LOG.05》（Mushreb，
Godot 4.7 + C#）：8×3 雪花图集 + GPUParticles2D；噪声蒙版做地面积雪。

**实现**：Godot 4.6 / GDScript，640×360 像素世界 + 1280×720 HUD；
全部像素素材由 `tools/gen_art.py` 程序化生成。没有使用原游戏素材。

### 本轮问题与修复

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 整个场景加载失败 | 场景把 `wall.png` 写成 `assets/world/`，实际在 `assets/props/` | 改正 ext_resource 路径 |
| 雪粒子层数组为空、后续全挂 | Godot 4.6 的 `CanvasItemMaterial` 没有 `particles_anim_speed`；赋值报错导致 `_make_layer` 提前返回空字典 | 删除该属性，动画走默认速度 |
| 地面是“迷彩块”不是雪 | 低频噪声 + 阈值对比过强 | 双频 fBm（0.05 + 0.16）+ 偏白分布；路径雪量 ×0.92 |
| HUD 显示 68% 但画面雪很厚 | HUD 默认值在 setup 时覆盖了 world 的 0.74 | `set_value_no_signal(world.*)` 后再回调 |
| 截图看不到脚印 | 角色只走到画面底部，脚印被 HUD 底栏挡住 | 演示/截图中让角色走到中上段；脚印放大 1.35×、alpha 0.82 |
| 雪帽不像“逐渐盖上去” | 所有道具统一阈值 | 每个道具独立 threshold，alpha = clamp((coverage-th)/0.32) |
| 路灯照不亮雪地 | 地面是 unshaded 自定义 shader，PointLight2D 不作用 | 路灯加加色 glow 光池；树/角色仍由 PointLight2D 照亮 |
