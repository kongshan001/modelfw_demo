## 3. 原生路径调试（21:50–22:00）

现象：`M` 切原生后，墙面光池正常，但三个角色近乎全黑；去掉角色法线或提高
PointLight2D 能量可局部变亮。

定位过程：

- 确认 `CanvasTexture.diffuse/normal` 都绑定；灯 enabled/能量/rang_z/cull mask 正常。
- 单独把点光放大到角色头部、energy=8：头部亮、身体仍暗 → 不是“完全不亮”，
  而是原生光照的覆盖/参数不匹配。
- 测试 texture_scale 2/4/6/12、height 0/24/64：scale 12 + height 0 + 无
  CanvasModulate 时整屋被照亮；说明原生路径可用，暗的主因是 **CanvasModulate
  把最终光照一起乘色**。
- 最终方案：原生模式用 `CanvasModulate = 深色底 + ambient*系数` +
  冷色 `DirectionalLight2D` 补光 + 暖色 PointLight2D（texture_scale=6，
  energy=强度×2.2，height 跟 UI 光高）。角色/砖块可读，同时保留夜景对比。
  这是与教程不同的工程取舍，已在 TECH 中明示。

## 4. 平面对比的黑色 bug（22:00–22:05）

现象：按 `V` 关闭法线后，场景只剩环境色/微光，角色像黑剪影；此前归因于
“法线关掉当然平”，但亮度和点光位置不符。

根因：法线关闭时 `nd=(0,0,1)`，随后 `normalize(v_nmat * nd.xy)` 对零向量
归一化；部分 GL 驱动返回 NaN，整条颜色变 NaN/黑。

修复：

```glsl
vec2 n_world = v_nmat * nd.xy;
float n_len = length(n_world);
n_world = n_len > 0.0001 ? n_world / n_len : vec2(0.0);
```

修复后平面模式亮度正常，法线 ON/OFF 成为有效对比（`02_normal_on` /
`03_normal_off` 使用同一光位 0°）。

## 5. 导入与法线方向（22:05）

  用 0→2 滑杆验证不会翻面。

## 7. 视觉取舍与已知问题

- 法线图为 1 art px/texel + nearest，4×/6× 下光照是块状的，属于像素风选择；
  若要更平滑需要单独提高法线分辨率或线性采样（会破坏 albedo 像素锐度）。
- 原生路径观感比 shader 平：没有逐像素粗糙度/rim/法线强度；高光靠
  CanvasTexture 的全局 specular，金属箍在原生路径下不如 shader 抢眼。
- 只有一盏点光，没有实时投影；接触阴影是烘焙的，苔灵 2× 时阴影不跟着变大。
- 视频源是 1280×720，MP4 最近邻放大到 1920；截图是真 1920 根窗口。
- 环境里同时运行其他 worker 的 Godot 进程，性能数字按保守值记录。
