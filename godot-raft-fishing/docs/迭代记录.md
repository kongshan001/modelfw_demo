# 迭代记录 · 浮木湾

## 0. 目标与边界

- 目标：3–5 分钟可玩的原创像素木筏钓鱼 vertical slice，复刻“自瞄 + 追踪 + 资源入包 + 扩筏/设施/生存”的循环与反馈，不复制原作名称/UI/角色/素材/文案。
- 技术边界：Godot 4.6、GL Compatibility；无第三方运行库；贴图与音效全程序化；只改 `godot-raft-fishing/`。
- 验收：smoke、真实输入、9 张 1280×720 截图、6–10s GIF/MP4、Intel 30fps+、`tools/verify.sh`。

## 1. 迭代：可跑骨架（第 1 天）

**做了什么**

- 新建 `godot-raft-fishing/`：`Main(Control) → SubViewportContainer(stretch_shrink=2) → SubViewport(640×360) → World(Node3D)`，HUD 独立 1280×720。
- 程序化像素贴图：甲板、木桶、木箱、银鱼、角色 4 朝向 × 2 帧、HUD 图标、旗帜、阴影。
- 3/4 正交相机、Q/E 环绕、滚轮缩放；WASD 相机相对移动；初始 2×2 木筏、灯柱光晕、浪纹旗。
- 水面 shader 第一版：分块浪纹 + 木筏泡沫圈 + 涟漪槽 + 昼夜染色。

**验证**

- 真实 GPU 能出图；中文 HUD 正常；无解析错误。
- 第一轮截图发现：相机 13.5 略远、灯柱被外框挡住、水面白沫/涟漪过亮、toast 盖住建造菜单/物资面板。已在后续迭代修正。

## 2. 迭代：核心手感（第 2 天）

**做了什么**

- 钩子 FSM：`idle → charging → flying → returning`；按住自动锁定 20m 内最近漂浮物；松手追踪；命中后入包、飘字、水花、音效、震屏；回收冷却 0.5s。
- 漂浮物表：桶 50%、箱 30%、鱼 20%；桶/箱木材 2–4（均值 3）；箱额外 1–2 木板；每 2.7s 刷新，上限 8。
- 程序化 9 个音效（正弦+噪声+包络，AudioStreamWAV）。
- 物资飞向玩家的 0.34s tween；钩头金色球 + 绳 + 每 0.13s 水面涟漪。

**发现并修正**

- 中文 HUD 与 toast 打架：toast 改到顶部中央、宽 490，最多 3 条。
- 钩子视觉比逻辑慢一帧：`_update_visual_tools` 原本在钩子更新之前调用，改为在状态机之后；绳索/钩头/锁定标记改为当帧同步。
- 低帧率下钩子单帧穿越目标：飞行/回收步长 clamp 到 50ms。
- Space 输入被键盘分支提前 return 吞掉：把 `is_action_pressed("cast")` 放进键盘分支内处理，空格与左键都可用。

## 3. 迭代：建造、箱子、净水、烤鱼、生存（第 3 天）

**做了什么**

- 建造：扩建 2 木板；木箱 3 木板；净水器 2 木板+2 木材；烤鱼架 3 木板+2 木材。
- 建造模式：B 菜单 → 按钮进入放置 → 鼠标移动显示绿色/红色 ghost → 左键放置，右键/ESC 取消。建造扣料不足时成本红字、toast 提示。
- 木箱自动存取：溢出阈值木材 22、木板 12；建造缺料自动从箱子扣；F 可手动整理/取木材。
- 净水器 18s/杯（上限 3），35% 批次免木；烤鱼架 12s/条（上限 3）；靠近 3m 自动收取，F 手动。
- 生存：水 62（-0.28/s）、食物 66（-0.18/s）、体力 100；`1/2/3` 喝水/吃烤鱼/生吃；低值变红。
- 目标：12 格或第 4 天；结算面板 + R 重开。HUD 目标/天数双进度条、资源行、木箱存量、提示条与蓄力条。

**发现并修正**

- 放置 ghost 不明显：单独生成 32×32 格纹贴图 + 2px 亮边，提高 alpha。
- ghost 被 Main 每帧用鼠标位置覆盖：改为只在鼠标移动事件里更新 ghost；截图/调试可单独设置预览格。
- 设施图标与灯笼/桅杆挤在一起：设施图标默认隐藏，只在有产出时显示，并缩小位置。
- 建造菜单第 4 行被面板裁切：面板高度改为 360，footer 下移；toast 移到上方避免遮挡。
- 瞄准/相机面板遮挡：打开建造菜单时隐藏底部提示条。

## 4. 迭代：验收与画面（第 4 天）

  - 建造扣木板、非法位置拒绝、放置模式 ghost/try_place；
  - 木箱自动存入/取出、缺料失败；
  - 净水器 18s/杯与 35% 免木统计、烤鱼架 12s/条、靠近自动收取；

## 5. 参数与手感记录

- 锁定 20m、蓄力 1.1s、冷却 0.5s：开始时 5–6m 的目标在 0.3s 左右被钩到，节奏不拖。
- 追踪速度 17–28m/s + 9/s 转向系数，移动目标也能命中；50ms 步长 clamp 避免低帧穿越。
- 自动收取半径 3m：站在对角的格子（约 2.8m）也能收到，但不会跨半个木筏。
- 箱子阈值（22 木材/12 木板）保证背包里始终够造 1–2 次，不用频繁开箱。
- 80s 一天、240s 生存胜利；水 62 起始、0.28/s，鼓励尽早净水器；食物更宽松，烤鱼是加分项。
- 12 格目标约需 8 次扩建（16 木板），木箱是主要木板来源，单局 3–4 分钟。

## 6. 与参考视频的差距

- 参考循环中的“钓鱼”在这里简化为钩子直接收集；没有鱼咬钩/拉杆节奏、鱼种和鱼竿升级。
- 角色没有抛竿/收线/进食动作，只有 4 朝向 2 帧。
- 木筏不做真实浮沉；水面是像素分块着色，不是网格波。
- 木箱只有木材/木板；没有完整背包页、配方树、更多设施。
- 无音乐、存档、设置、手柄/触屏；音效为程序化占位。
- 视频里的原创名称/UI/角色/文案均未使用；只保留了“按住自动锁定最近资源、松手追踪、自动存取、省木净水”等交互目标。
