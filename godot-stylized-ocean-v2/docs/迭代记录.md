## 2. 实施时间线（2026-11-26）

1. 参考下载 720p + 1fps 抽帧，确认镜头为**俯视环绕**，不是低机位海平线；确立“俯视广角 + 低机位海平线预置”的双镜头。
2. 建立 Godot 4.6 项目；海岛高度场与水深贴图共用同一函数；环形 LOD 海面 + 6 层 Gerstner。
3. 修复水面不可见：确认 Godot 正面绕序为 CW，翻转海面/地形索引；显示水和岛。
4. 色阶/泡沫迭代：海水过白 → 加深深海色、降低浅滩 sandwater 混合、收窄泡沫带；泡沫从“棉花圈”改为细白线 + 断续离岸弧 + 浪尖泡沫。
5. 光照问题：GL Compatibility 下方向光表现异常（测试 cube 正常、场景内不稳定），改为 **unshaded 手绘方向光** + 软椭圆接触阴影；确认沙地明度从 ~#9b8f78 提升到 ~#e8dfc8，接近参考的 `#efe9db`。
6. 场景资产迭代：棕榈从 9 → 12 片叶；礁石加棱角/青苔并启用双面；木屋加侧墙/梯子、塔加红顶/灯晕；海鸥从纸片状大鸟缩到参考的远景小白点。
7. 交互：12 路涟漪源；左键拖拽尾迹/单击落石（弹道 + 水花 + 白环）；船尾自动尾迹；雨点自动涟漪；相机自动环绕/手动轨道。
8. 性能：真实 GPU 探针 1280×720 **96 fps**、雨 86.9、UI 73.1；1920×1080 **53.1 fps**（Intel HD 6000）。无 SSR/实时阴影/GPU 粒子。
9. 证据：smoke 53 项通过；真实 GPU 1920×1080 截图 13 张；10s MP4/GIF。
