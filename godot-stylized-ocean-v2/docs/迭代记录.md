## 7. 岸线整改（T-20261126-021，2026-11-26）

用户反馈：**“海岛和水的交接处效果太差”**。结合参考视频 BV1AE4u6KEAR 的 0/5/10/15/20/25/30 s 抽帧重看岸线（参考仅在 `/tmp/ocean_v2_ref/`，未复制任何素材），针对交接带做专项整改；波浪/涟漪/相机/UI/交互未改。

### 7.1 参考帧里实际看到的岸线结构

- 干沙 `#ece5d3`；向水线过渡为宽而灰的湿沙带（`#ddd5c2 → #c9c1aa`），不是一条窄线；水线处还有更暗的接触带。
- 水线泡沫：**厚薄不均、带蕾丝孔洞的白色泡沫团**；主带外侧 1.5–3 m 还有 1–2 条断续细白线；泡沫随浪进退。
- 浅水不是平涂青色：沙底颜色真实透出，近岸灰绿 → 青绿 → 深蓝；沙底有细线焦散光网、沙纹与少量暗色斑。
- 离岸礁石：没有青色方形/圆形光晕；礁石有湿岩基座，水线一圈局部泡沫，水下的岩体被水色染青。
- 参考的湿沙带横向宽度在俯视尺度约 3–6 m（按岛径 ~52 m、7 px/m 估算），主泡沫带约 0.3–1.5 m 厚，第二道线约 1.5–2.8 m 外。

### 7.2 问题 → 改法

| 旧问题（T-010） | 根因 | 本次改法 |
| --- | --- | --- |
| 沙/水硬切多边形 | 水面不透明 + 无水线过渡 + 深度图 0.35 m/px | 浅水改真透明（alpha 随水深）；地形湿沙带 + 水线暗带；地形近岸加密；SDF 1024² 0.176 m/px |
| 浅水平涂亮青、像贴花 | 只用 512² 深度色阶，无沙底/透明度 | 地形延伸水下 72 m，水下沙底 + 冷色衰减 + 沙纹/海草；焦散细线光网；水体色阶改为水膜/潟湖/礁盘/中水/深海 |
| 无湿沙/水线暗带/接触阴影 | 地形只有一条很窄的 wet 判定 | SDF 驱动湿沙（3.6–6.0 m）+ 0.30–0.80 m 暗水线 + 噪声扰动 + 拍岸涨落 + 视角微高光 |
| 泡沫是均匀白线或缺失 | 泡沫按深度阈值生成，且与地形不一致 | 主带/第二道/第三道/离岸团四层；clump 成团 + 1.3 m 孔洞；SDF 宽度/相位驱动；泡沫环 |
| 礁石方形/圆形青色光晕 | 515² 深度图上的礁石隆起 + 平涂青色 + 无道具泡沫 | 礁石基座缩到 size×0.8+0.1、只高出 0.05 m；G 通道泡沫环（噪声打斑）；rock shader 湿岩基座 + 水线泡沫；水下岩体偏青 |
| 水与岛没有 run-up/退潮 | 水线静态、泡沫按均匀深度 | A 通道沿岸相位 + swash 正弦（±0.25 m）+ 泡沫团宽度变化 + 地形湿边同步涨落 |

### 7.3 关键参数（最终）

- 岸距场：1024² / 180 m；R 有符号岸距 ±8 m（0.5=水线）；G 道具环（礁石 core=size×0.82+0.08, width=size×0.25+0.15；近岸棕榈 core 0.55/width 0.75）；B 泡沫宽度 0.55–1.45；A 拍岸相位 0–1；水线半径表 2048 角度 × 26 次二分 + 法向修正。
- 湿沙：干沙 `#ece5d3` / 潮湿 `#d3cbbc` / 湿沙 `#b4ab98` / 水线暗带 `#8e948e`；湿沙宽 3.6–6.0 m（雨 +60%），暗线 0.30–0.80 m，噪声 ±0.45 m，拍岸 ±0.22 m。
- 浅水：`alpha = 0.14 + 0.86 · smoothstep(0.06, 3.9, depth)`，岸边再取 `max(alpha, 0.18)`；泡沫 alpha `smoothstep(0.10,0.55,foam)·0.98`；深海 alpha=1。
- 泡沫：主带中心 0.32+0.45·wfac+run m，半宽 0.26+0.28·wfac+0.16·lace；run 拍岸 ±0.25 m；第二道 1.55+1.20·wfac m（宽 0.08–0.22 m）；第三道 3.1+1.8·wfac m；离岸泡沫团 0.9–3.6 m；clump 8–10 m / 2.7 m，孔洞 1.3 m；礁石环随深度 0.04–0.20 m 淡入、2.8–4.4 m 淡出。
- 焦散：256² 干涉驻波细线网；地形 uv 0.07（≈14.3 m 周期），细线阈值 0.22–0.78，mask 0.25–4.0 m，12 m 噪声打散，45–95 m 相机距离淡出，强度 0.07–0.10。
- 地形网格：0–38 m 128 环 + 38–72 m 28 环（几何增长）× 288 段 = 157×288 ≈ 45.2k 顶点（旧 112×200≈22.4k）。
- 礁石：离岸基座 bump 0.05 m / radius size×0.8+0.1；近岸水中巨石 bump 0.22–0.48 / radius size×1.05+0.35；rock shader 湿岩 `y<0.62 m` ×0.58、水线泡沫环 ×0.62。

> 与任务 brief 的差异说明：brief 写“湿沙宽约 0.3–0.8 m”。本岛沙滩坡度约 9°（0.16 m/m），横向 0.3–0.8 m 只对应 2–5 cm 高差，视觉上不可见；参考帧的湿沙带实际约 3–6 m。因此把 **0.3–0.8 m 用于水线暗带**，湿沙/潮湿带扩展到 3.6–6.0 m，并在 README/TECH 明示。
