# TECH · 风格化海洋第二版

Godot 4.6 / GL Compatibility / 1280×720 逻辑（可 1920×1080）。视觉主导，全部网格、材质、贴图程序化原创。

## 2. 海面几何与 Gerstner 波

- 单张环形渐变 LOD 网格：半径 **420 m**，140 环 × 160 段；`r = 0.5 + (R−0.5)·(i/N)^2.2`，近岛密、远海疏；约 22.5k 顶点、45k 三角形。
- 6 层波（方向 / 振幅 / 波长）：

| # | 方向 xz | 振幅 | 波长 | 作用 |
| --- | --- | --- | --- | --- |
| 1 | (1.0, 0.28) | 0.30 | 22 m | 主涌浪 |
| 2 | (0.62, 0.85) | 0.18 | 12 m | 交叉涌 |
| 3 | (−0.35, 1.0) | 0.105 | 7 m | 中频细节 |
| 4 | (0.92, −0.40) | 0.055 | 4 m | 碎浪 |
| 5 | (−0.75, −0.65) | 0.034 | 2.6 m | 细纹 |
| 6 | (0.15, −1.0) | 0.022 | 1.7 m | 高光扰动 |

- `wave_dir` 滑条整体旋转方向；振幅乘以 `wave_height`（默认 **0.72**，总振幅约 0.5 m）。
- 相速度 `c = sqrt(9.8/k) · 0.42 · wave_speed`；相位 `f = k(D·p − c·t) + i·1.7`。
- 水平位移 `xz += D · A · 0.34 · cos(f)`，垂直 `y += A · sin(f)`；近岸阻尼 `smoothstep(0, 2.2, depth)`，避免岸边几何穿沙。
- 解析法线：`n = normalize(vec3(−Σ A·k·Dx·cos f, 1, −Σ A·k·Dz·cos f))`；fragment 再叠加两层细节法线（uv ×0.9 / ×2.7，幅度 0.055）。
- 俯视波面明暗：`col *= 0.9 + 0.16·pow(dot(n,sun)/2+0.5, 1.4)` + `v_crest·0.045`，让俯视也能看到浪的推进。
- CPU 浮力采样 `ocean.get_wave_height_at(x,z)` 使用同一组 6 波（船/筏/鱼）。

## 3. 水深与色阶

- 水深贴图 **512×512**、覆盖 **180×180 m**（−90..90）；单通道 `R = sqrt(depth/12)`（浅水精度更高）；线性过滤。
- 深度来自同一高度场：先铺海床，再对礁石做局部隆起盖章（避免逐像素遍历）。
- 色阶（参考帧采样，shader uniform；白天）：

| 深度 | 颜色 | 说明 |
| --- | --- | --- |
| 0 m | `#85c7ae` 浅滩沙水混合 | 叠加 `sand_glow` 0.2 |
| 0.2–2.4 m | `#2eb8bf` → `#1c8fb0` | 潟湖 / 礁盘 |
| 2.4–5 m | `#176fa5` | 中水 |
| 5–8.6 m | `#0d5991` | 深海主色 |
| 泡沫 | `#fbffff` | 岸线、沙脊、涟漪 |
| 焦散 | `#b8fff4` | 浅水（深度 0.08–2.8 m） |

- 菲涅尔：`fres = pow(1−dot(n,V),4)`，混入天空色（系数 0.45，上限 0.35）；俯视时很弱，低机位明显。
- 焦散：程序化可平铺纹理（256²，正弦干涉 → 尖锐光网），两次采样（uv ×0.085，不同滚动/缩放），mask ×0.12。
- 次表面：浪尖/高波面混入少量青绿色（`caustic_color × 0.16`）。

## 4. 泡沫

- 可平铺 fBm 泡沫纹理 256²；世界缩放 0.055（大块）+ 0.37（细纹）。
- **岸线细白线**：`depth ≈ 0.05 + fnoise·0.07`，宽度 `0.045 + 0.03·fn2`（世界约 **0.2–0.5 m**），强度 0.5×foam_amount。
- **湿沙上方模糊泡沫带**：`depth < 0.065 + fnoise·0.05`，强度 0.2–0.42；与地形湿沙线联动。
- **离岸泡沫弧**：两条以 sin(depth) 推进的窄带（深度约 0.5–1.5 m 与 1.2–4.2 m），强度 0.15–0.18，乘噪声阈值 → 参考帧里的断续白弧。
- **浪尖泡沫**：`smoothstep(0.22,0.78,v_crest) · smoothstep(0.85,1.5,wave_height) · 0.7 · foam_amount`；默认浪高 0.72 时几乎不出现，拉高浪高才出现。
- **涟漪泡沫环**：见 §6。
- 泡沫像素级抖动由 fBm 阈值完成；不使用全屏后处理。

## 5. 高光 / 闪点

- 卡通高光：半程向量 `H = normalize(sun+V)`，`pow(dot(n,H),900)·0.4`；宽 sheen `pow(...,36)·0.06`。
- 阳光闪点与视角无关，保证俯视可见：
  - 细点：`smoothstep(0.90,0.985, foamTex(p·9))·0.9` + `smoothstep(0.93,0.995, foamTex(p·14))·0.6`；
  - 大范围微光：`smoothstep(0.72,0.92, fbm)·0.04`；
  - 乘 `sun_facing` 与 `sun_glint`（滑条 0–2，默认 0.5）。
- 天空反射色 `#c2e9f2`；夜晚天空色 `#17345c`，太阳颜色切到月光 `#b9d2ff`。

## 6. 涟漪模型（交互核心）

- 固定 uniform 数组 12 路 `vec4 ripples[12] = (x, z, startTime, strength)`；`ripple_count`。
- 每路生命周期 `ripple_life ∈ [1.6, 5.0] s`（“涟漪持续”滑条反比映射）；半径 `r = age · 2.8 m/s`。
- 顶点位移：`sin((d−r)·6) · exp(−((d−r)/0.62)²) · 0.045 · strength · fade`，并给法线加同相位梯度（近岸阻尼）。
- 片元环：主环宽 `0.16 + 0.13·age`、次环（0.55r）宽 `0.26 + 0.16·age`，乘 `(1−age/life)²`、strength、泡沫噪声；叠加到白色泡沫。
- 生成策略：
  - 单击：strength 0.95；
  - 拖拽：每 0.09 s / ≥0.28 m 一个，strength 0.62；
  - 雨：每 0.19 s，strength 0.25–0.45（水深 >0.4 的随机点）；
  - 船尾自动尾迹：每 0.42 s，strength 0.38；
  - 落石：strength 1.8 + 粒子水花 + 扩张白环。
- 满 12 路时淘汰最老源；`debug_view=4` 显示暗底青色环与源。

## 7. 光照 / 阴影 / 昼夜

- **实现取舍**：GL Compatibility + Intel HD 6000 上，DirectionalLight3D 的直接光在场景中表现不稳定（方向光位置/兼容路径异常），无法作为可靠视觉基线。为保证可复现的卡通明度，场景采用 **unshaded 手绘方向光**：所有沙地/岩石/植被/水面由 shader 内的 `sun_dir / sun_tint / shade_tint` 调制，UI 调色板负责昼夜。
- 地形/岩石/植被手绘光：`ndl = dot(N, sun)/2+0.5`，`lit = mix(shade, sunTint, pow(ndl,1.2~1.7))`。
- 真实阴影关闭；使用**软椭圆接触阴影** MultiMesh（1 次 draw call）：棕榈 6.6×3.6 m、礁石、木屋、塔，按太阳反方向偏移 24% 长度；夜间灯晕为加法 billboard。
- 三套调色板 DAY / DUSK / NIGHT，按太阳高度权重混合（`night = smoothstep(0.02,−0.38,elev)`，`dusk = (1−night)·(1−smoothstep(0.10,0.55,elev))`，`day = 1−night−dusk`）。
- 白天：环境光 `#e2f0f5`、能量 0.76（用于 props 的环境光），sunTint `#fffdf6`、shadeTint `#c3d1dd`；夜晚：`#5f7fa8` / 0.34，水体深蓝 `#0a2a4e`，木屋/塔暖色灯池 + billboard 光晕。
- 夜间灯池在 terrain shader 里用 hut/tower 到片元的世界距离叠加暖色（不依赖引擎点光）。

## 8. 场景资产

- 海岸线：`r(θ)=26.5 + 2.5sin(3θ+0.8) + 1.9sin(5θ+2.2) + 1.2sin(8θ+4.9) + 0.8sin(11θ+1.3) − 4.4·Gaussian(θ−2.85) + 2.8·Gaussian(θ+0.62)`；沙丘噪声、海床深度（0→12 m 截至 90 m）。
- 地形网格：112 环 × 200 段，法线由高度场中心差分。
- 道具数量（程序化）：棕榈 ~27（MultiMesh 树干 + 树冠 2 draw calls）、礁石 25 处（3 variants）、灌木 20、草丛 110、云 5、海鸥 10、鱼影 16、木屋、瞭望塔、帆船、小筏。
- 木屋、塔、船为低模盒/柱组合；岩石为细分二十面体位移 + 平直法线 + 顶点色青苔；棕榈冠为 12 片折叶（UV2.x 色调），风摆 shader。
- 云为合并椭球（18×9 段）+ 法线方向的暖白/冷灰渐变；海鸥为单 MultiMesh（翼展扑动 shader）；鱼影为半透明深青薄片（避免不透明水体的透明排序问题）。
- 雨：CPUParticles3D 650 滴（兼容路径稳定，不用 GPUParticles3D）。

## 9. 相机 / 交互 / UI

- 相机 fov 36、默认 dist 116、pitch 58°、yaw 90°、目标 (0,1.6,0)；自动环绕 0.9°/s。
- 屏幕射线解析求交 `y=0` 平面，要求水深 ≥0.1 m；范围内有效。
- 左键拖拽尾迹 / 单击落石（<240 ms 且位移 <9 px 视为 click）；右键拖拽轨道；滚轮缩放；H/Space/R/C；F1–F7。
- 落石：11 m 高、重力 26 m/s²、到水面生成水花粒子 + 白环 + 1.8 强度涟漪，石块短暂漂浮后下沉。
- HUD：深青玻璃、奶白字、青绿滑条；15 个参数控件、3 时间预设、水色/调试 OptionButton、重置、折叠、1.0/1.5 缩放。
- 调试视图：0 关 / 1 浪高灰度 / 2 世界法线 / 3 泡沫 / 4 涟漪源 / 5 水深热力 / 6 岸线梯度；统计 FPS、draw calls、涟漪数、浪高、时间。

| 场景 | 视口 | 平均 FPS | DC |
| --- | --- | --- | --- |
| 默认 | 1280×720 | 96.0 | 66 |
| 雨 | 1280×720 | 86.9 | 67 |

| 默认 | 1920×1080 | 53.1 | 65 |

（`tools/probe_stylized_ocean.gd`，110/90/80/60 帧平均。）

关键优化：单水面网格、无 CPU 流体；无 SSR/SSAO/实时阴影；云/鸟/鱼/植被合并 MultiMesh；阴影为 1 个透明 MultiMesh；焦散/泡沫用 256² 程序化纹理；HUD 独立 CanvasLayer。

## 11. 已知限制

- 无平面反射 / 屏幕空间反射；水面为不透明绘制，鱼群为水面剪影。
- 低机位海平线能看到半径 420 m 的水面边缘（经雾化/天空色柔化）。
- 岩石/木屋/云为简化低模，细节低于参考视频的资产；后续美术可替换。
- 太阳闪点在 1080p 为 1–2 px 细点，截图缩放后较不明显；运行时更明显。
- 无真实阴影，依赖软椭圆接触阴影；被遮挡关系（如屋顶对沙地）为艺术近似。
