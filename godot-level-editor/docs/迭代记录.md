### 参考与拆解

参考 B 站视频《免费开源！3 分钟认识 2D 关卡编辑器 LDtk》（UP：像素炼金师皮克森游戏，3:04，`b23.tv/SpeXw3f`）。只抽帧确认工作流，参考文件放在 `/tmp`，未复制任何素材/源码/Logo/品牌元素。

从视频确认到的核心环节：

1. 网格画布上先画地形结构（层可见/可锁、画笔/橡皮/矩形等工具）。
2. 规则自动铺砖：修改平台或挖掉一块墙，边缘/转角自动更新。
3. 实体（出生点、敌人、宝箱、传送门等）可放置并编辑属性。
4. 数据输出为 JSON，再进入 Godot/Unity 等引擎；用一个小关卡验证图层、实体、碰撞。

据此确定原创 demo 的 MVP：三层（地形/碰撞/实体）、六工具、四类瓦片、四邻自动铺砖、三类实体、撤销/保存/导出/可走预览。

### 版本迭代

#### v0.1 数据与规则（纯逻辑）

- 建立 `LevelData`：二维地形（type/variant/mask）、碰撞位图、实体数组、图层状态。
- 定义四邻掩码 N=1/E=2/S=4/W=8；草/土共享 ground 组，石墙/水各自成组。
- 实现 `paint_terrain/erase_terrain` 的 3×3 邻域重算、全图重算、手动变体保留/清除、自动关闭冻结。
- 实现矩形/直线格子生成（Bresenham）、实体默认属性与规范化。
- 建立 v1 JSON schema：编辑器格式 + 运行时格式，载入采用“先校验、后替换”。
- 用 headless 脚本验证掩码预期（中心 15、左上角 6、墙中段 10、转角 12、水岸 2/8 等）。

#### v0.2 画布与程序化美术

- `editor_canvas.gd`：整数倍缩放 ×1–×4、以鼠标为中心缩放、中键/空格平移、可见区裁剪、坐标/网格/悬停/选中/范围预览。
- 工具输入：画笔拖拽补间、橡皮、矩形、直线、取色；实体层放置/选择/拖动。
- `tile_art.gd`：16×16 原创草地/泥土/石墙/水面，基于掩码生成边缘；手动变体 3 种；实体三图标 + 16×20 四向园丁精灵。
- 修复了初版墙体顶部高光呈“金色散点”的观感问题，改为连续顶沿。

#### v0.3 编辑器 UI 与闭环

- 深青 + 苔绿 + 暖金的原创编辑器主题；中文 SystemFont。
- 顶部工具栏、左侧工具/调色板/实体、中央画布、右侧图层/地图设置/属性、底部状态栏。
- 属性面板动态字段：出生点朝向；敌人种类/HP/伤害/朝向/巡逻；宝箱掉落/数量；格子掩码/外露边/恢复自动；碰撞切换。
- 撤销/重做（整图快照，一次拖拽一步，最多 80 步），保存/加载/导出/清空/重置示例。
- 运行预览：运行时 JSON→重新解析，静态地图合成单张纹理，AABB 四角碰撞，出生点/宝箱/敌人/HUD。
- 修复实体朝向 OptionButton 用中文标签匹配英文值导致默认“朝右”的问题；现在按值索引正确显示“朝左/朝上”等。
- 修复预览 `try_move` 在单轴移动时把 0 位移的 Y 轴也算作成功移动的问题；碰撞阻挡判定现正确。
- 预览隐藏编辑器主 UI，减少无谓绘制；预览平均 FPS 从 ~44 提升到 >100（探针口径）。

#### v0.4 验收、性能与交付

- `tools/smoke_level_editor.gd`：134 项检查，含真实画布输入事件路径；最终 `checks=134 failures=0 / LEVEL_EDITOR_SMOKE_OK`。
- 用 SubViewport 解决本机窗口无法开到 1920×1080 的问题：`size=1920×1080`，`size_2d_override=1280×720`，输出 6 张真实 GPU 截图。
- 演示序列 20fps×200 帧：脚本驱动真实画布事件画墙、擦除/撤销、放敌人、改 HP/种类/朝向、保存/导出、预览行走拾取，编码 10s MP4 + GIF。
- 性能探针最终：editor avg=89.8 p5=62.5 min=50.0；preview avg=105.6 p5=66.7 min=43.5；`LEVEL_EDITOR_FPS avg=97.7 ... OK`（Intel HD 6000，vsync off）。
- 真实 GPU 主场景 300 帧 + headless 600 帧：日志无 ERROR/WARNING。
- 干净工作区（移除 `.godot/`）重跑 smoke 仍通过，说明本地 preload 常量方案不依赖全局类缓存。

### 已知问题（记录，不冒充修复）

- 大地图上整图快照撤销会变慢，但当前上限（96×96）可用。
- 编辑器 UI 使用系统 CJK 字体；换到无中文字体的机器需内置字体子集。
- 截图分辨率由逻辑 1280 拉伸到 1920，文字有轻微缩放插值；画布内仍保持整数倍。
- 预览是校验场景：敌人不移动、不战斗；水面/墙/碰撞都阻挡但不做坡度/斜坡。
- 图层显隐/锁定和关卡名不进撤销栈；这是有意的编辑会话状态设计。
