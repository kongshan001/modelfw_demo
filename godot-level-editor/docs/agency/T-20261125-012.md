## 关键实现选择

1. 数据层 `LevelData` 与 UI 解耦，纯 RefCounted，可在 headless 验证。
2. 自动铺砖使用四邻掩码（N=1/E=2/S=4/W=8）+ 分组规则（grass/dirt 共享地面组），实时 3×3 重算；手动变体优先，重算保留。
3. 画布使用自定义 `_draw` + 程序化 16px 瓦片；缩放 ×1–×4、格子 16/32/48 都是整数倍，配合 NEAREST 保持像素清晰。
4. 撤销使用整图 JSON 快照；一次拖拽/一次形状/一次属性修改各记录一步。
5. 预览使用导出的运行时 JSON 重新解析；“静态地图一次性合成 ImageTexture”，避免每帧绘制数百 tile。
6. 截图使用 1920×1080 SubViewport + 1280×720 2D 覆盖，绕开本机窗口尺寸限制。
