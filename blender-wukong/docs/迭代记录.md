# 迭代记录 — 齐天大圣 · 斗战形态

## 2026-11-19 · 第 1 轮：程序化角色 + 骨骼 + 蒙皮 + 气功波

**目标**：验证从建模到动画的完整 Blender 程序化链路，交付 `.blend`、`.glb` 和一段 8 秒演示。

**设计**：原创「金发猴王」——参考《西游记》齐天大圣与金色爆气类动漫的视觉语言，
但不复刻任何具体版权角色的服装、发型、标识或剧情。角色为 chibi 比例，便于程序化建模和动画。

**实现**：

- 程序化建模：头/脸/耳/金发尖刺/金箍/胸甲/肩甲/护腕/膝甲/靴/尾巴/金箍棒；
- 25 根骨骼，手臂/腿 2 骨 IK + pole，脚本化蒙皮（距离权重 + 关节混合 + 刚性护甲），
  全部 join 成单一 `Wukong_Body` + Armature 修改器；
- 8 秒动画：蓄力 → 双手前推 → 金色双层光束 → 回收；
- 特效：能量球 + 点光、斗气壳、光束、火花、地面圆台、相机抖动、Bloom；
- Blender 3.4.1 EEVEE，960×540 / 24fps / 192 帧 / 8 samples；GLB 烘焙导出。

### 本轮问题与修复

| # | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 能量球只有一个小白点 | `sphere()` 先把初始 scale 应用到网格，动画再乘一次 | 基础网格半径设为 1，只用动画 scale |
| 2 | 手够不到前方目标 | IK 目标超出臂长 0.51 | 目标收到臂长内（胸前 x≈0.3，推出 x≈0.42） |
| 3 | 蓄力看不清 | 球被手/身体遮挡且无照明 | 球前移放大 + 橙色点光 |
| 4 | 相机看到背面 | orbit 起始角度在 -X 侧 | 从 +55° 起，到 +10° |
| 5 | 放波时像背对镜头 | 躯干 twist + 头旋转叠加 | 释放段去掉 twist，头归零 |
| 6 | 斗气包住角色 | 大 alpha 球 + 强 emission | 降 alpha/emission，只留薄壳 |
| 7 | IK 动画无法进 GLB | glTF 不导出约束 | 导出前 bake（visual keying + clear constraints） |
| 8 | 4.2 渲染崩溃 | Intel HD 6000 EEVEE Next | 渲染改用 3.4.1 EEVEE Legacy |

### 验证

- 192 帧齐全；960×540 / 24fps / 8.0s；
- `GLB_OK ... skins 1 animations 1`；
