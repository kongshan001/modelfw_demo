# 素材与参考

- 全部几何、材质、灯光、动画、特效均由 `scripts/build_wukong.py` 程序化生成；
  仓库不含外部模型、贴图、HDRI、音频或字体文件。
- 角色是原创的「金发猴王」设计，灵感来自公共领域的《西游记》齐天大圣，
  以及金色爆气类动漫的通用视觉语言；**没有复制任何具体版权角色的模型、服装、标志或素材**。
- 工具：Blender 3.4.1（渲染）/ Blender 4.2.9（建模、MCP）、ffmpeg。
- 参考工作流：B 站视频《这居然是 Fable5.2 用代码做出来的视频？怎么实现的？》
  （Blender + MCP）与 [elvarofficial/teardown](https://github.com/elvarofficial/teardown) 的程序化思路。
