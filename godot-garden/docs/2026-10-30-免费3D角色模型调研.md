# 免费 3D 角色模型调研（2026-10-30）

> 目的：给《废墟花园》的巡逻 NPC（提灯守夜人 / 扫园人 / 小狐侍）找一套**可商用、可直接下载、风格匹配**的替代模型。
> 结论先行：**KayKit《Adventurers》** 做人形 NPC，**Khronos glTF Fox** 做小狐；两者都是低多边形、带骨骼和动画，Godot 原生导入。
> 本文的下载链接都实测可达（2026-10-30）；许可证以官方页面/仓库 LICENSE 为准。

---

## 1. 筛选标准

1. **许可**：可商用 + 可修改 + 可再分发；CC0 最省事，CC-BY 可接受（必须署名）；排除 NC / ND / “仅个人使用”。
2. **格式**：glTF / GLB 优先（Godot 4 原生）；FBX 在 Godot 4.3+ 走内置 ufbx 导入，也能用，但多一层转换。
3. **绑定和动画**：必须有 Idle / Walk（最好同厂骨架可复用），否则还要自己做动画。
4. **风格**：低多边形、色块/卡通，和现在 640×360 像素化场景匹配；写实风会“架空”。
5. **体量**：单角色几 MB 以内、移动端可用。

## 3. 许可证要点（必须看）

- **CC0 1.0**：商用、修改、再分发都允许，**无需署名**。仍建议在 `assets/art/CREDITS.md` 记录来源与版本号。
- **CC-BY 4.0**：允许商用/修改/再分发，但**必须署名**。例如 Fox：模型作者 PixelMannen（CC0），绑定/动画 tomkranis（CC-BY 4.0），glTF 转换 AsoboStudio + scurest（CC-BY 4.0）。游戏内 credits 和仓库文档都要写。
- **Mixamo / Adobe**：可以在项目中使用，但不能把角色或动画作为独立资产再分发/转售；需要 Adobe 账号。
- **Sketchfab / Poly Pizza**：每个模型单独许可，必须逐项看；避开 NC（禁商用）、ND（禁修改）、“Editorial only”。
- 不要从“免费下载站/网盘转载”拿模型——无法确认版权链条，风险高。

## 4. 和本项目风格的匹配

当前花园是 **640×360 内部分辨率 + 程序化低多边形 + 纯色材质**。换成外部模型时，风格取舍：

| 方案 | 匹配度 | 说明 |
|---|---|---|
| KayKit | ★★★★☆ | 玩具感低模、色块清楚，低分辨率下辨识度高；需要把贴图过滤设成 **nearest**，否则放大后会糊 |
| Quaternius | ★★★★ | 更“素”的低模，比例偏写实，和现在的程序化角色最接近；细节少一些 |
| Kenney | ★★★☆ | 块状风最接近现有风格，但精致度提升有限 |
| Mixamo | ★☆ | 写实人形，和花园的卡通低模明显冲突 |

另外：外部模型自带贴图，和当前“纯色块”背景的融合度需要在 640×360 下实测；建议先接 1 个角色做 A/B（同机位截图）再决定整套替换。

## 5. 落地方案（如果决定替换）

1. **下载**
   - KayKit：GitHub 仓库的 `addons/kaykit_character_pack_adventures/Characters/gltf/*.glb`，或整个仓库 ZIP；也可在 Godot AssetLib 搜 KayKit。
   - Fox：上面的 GLB 直链（159KB）。
   - Quaternius：官网 Download 按钮（zip）。
2. **目录 / 许可**
   - 放 `godot-garden/assets/models/kaykit/`、`godot-garden/assets/models/fox/`；
   - 随包保留 `LICENSE.txt`；在 `assets/art/CREDITS.md` 登记版本、作者、许可。
3. **Godot 导入**
   - glTF/GLB 拖进项目即可，自动生成 `Skeleton3D + AnimationPlayer`；
   - 贴图过滤改 **Nearest**，关闭 mipmap（像素风）；
   - 如需脚底对齐：导入后量 `AABB`，把模型原点放在脚底。
4. **替换巡逻 NPC**
   - 保留 `GardenPatrol` 的 FSM/路线/相机，只把 `_build()` 换成实例化 glTF 场景；
   - 动画：`Idle` ↔ `Walking` 用 `AnimationPlayer` 淡入淡出（或 AnimationTree），按速度切换；
   - 缩放：以当前 NPC 身高 1.66m 为基准（`scale = 1.66 / 模型高度`），脚底 y=0；
   - 道具：灯笼/扫帚可用 `BoneAttachment3D` 挂到手骨，或做成独立 Node3D 跟随（简单）。
5. **性能**
   - KayKit 单角色 3–5k 三角面 + 1 张 1024 图集；3 个 NPC 对当前 60 FPS 影响很小；
   - 若掉帧，先关 NPC 的 `cast_shadow`（当前巡逻 NPC 已用软阴影贴片）。
6. **验证**
   - 同机位三张：黄昏全景 / 提灯人近景 / 夜间提灯；
   - 探针：`tools/probe_patrol.gd` 复测走位、间距、FPS。

## 6. 风险与注意

- **风格统一**：不要一半 KayKit、一半 Quaternius；同一场景用同一套。
- **贴图过滤**：线性过滤在 3× 放大后发糊，和场景的像素边界冲突；统一 nearest。
- **动画重定向**：KayKit 同厂包通用；跨厂（比如 Quaternius 角色用 KayKit 动画）需要 Godot 4 的 retarget，成本高，优先同厂配套。
- **CC-BY 署名**：Fox 必须署名；忘记写会构成许可违约。
- **AI 生成模型**（Meshy/Tripo 等）：免费额度通常 CC-BY 或平台许可，且需要自己绑定/动画，风格也难统一；本期不建议。

## 6.5 本机实测记录（2026-10-30）

- **下载**：KayKit 的 GitHub 仓库可直连；单个 `Mage.glb`（3.59MB）走 raw 链接在本机约 6 分钟（代理限速），整包 ZIP 更慢。Fox 的 GLB（159KB）秒下。**结论：先单文件下载试点，不要一上来拉整包。**
- **导入**：Godot 4.6 直接导入 `Mage.glb`，自动得到 `Node3D → Rig → Skeleton3D` + `AnimationPlayer`；动画 **76 条**，含 `Idle`、`Walking_A/B/C`、`Running_A/B`、`Unarmed_Idle` 等；帽子/披风/法杖/书通过 `BoneAttachment3D`（head/chest/handslot_l/r）挂骨，**灯笼可以直接挂 `handslot_l`**。
- **比例**：模型身体（不含帽子）约 2.2 个单位高，帽子宽约 2.09 个单位；缩放到 `0.58` 时整体高度和现有 NPC 接近，但 **KayKit 是 Q 版大头身**，和现在细长的程序化角色不是同一种比例。
- **机位**：沿用巡逻近景（俯角 16°）时，宽帽檐会挡住脸；正式接入需要把俯角降到约 8–10°，或改用 **Rogue / Knight** 这类没有宽檐的角色。
- **材质**：把贴图过滤改成 **Nearest** 后，和 640×360 的场景更协调；默认线性过滤会显得糊。
- **文件**：预演资产在 `assets/models/kaykit/Mage.glb`、`assets/models/fox/Fox.glb`；脚本 `tools/preview_kaykit.gd`（同机位 A/B 截图）；许可登记 `assets/models/CREDITS.md`。

### 6.6 A/B 结果（2026-10-31）

- 同机位对比图：`docs/media/patrol_model_ab.jpg`（左：程序化提灯守夜人；右：KayKit Rogue）。
- 机位：相机 `(5.7, 1.55, 6.2)` 看向 `(2, 1.0, 3.0)`，俯角约 **7°**；Rogue 缩放 **0.58**、朝向额外 +180°（模型正面是 +Z）。
- 结果：Rogue 的脸、头发、腰带、靴子、明暗层次都能看清，**同机位下明显比程序化 NPC 精致**；灯笼挂到 `handslot_l` 后按其世界坐标偏移 0.16m，暖光照脸。
- 结论：**法师（Mage）不是好选择**——宽帽檐在 16°/7° 都会压住脸；**Rogue / Rogue_Hooded / Barbarian** 这类角色更适合花园的近景机位。
- 仍需注意：KayKit 是 Q 版大头身（头/身比例约 1:1.5），和现有细长程序化 NPC 不是同一比例；整套替换后建议同时复核狐狸、儿童（hero）和其它单位的身高关系。
