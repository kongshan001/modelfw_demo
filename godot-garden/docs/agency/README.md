# 多职能质量协作协议（策划 / 美术 / QA / 程序）

> 目标：把“达到竞品质量”拆成可执行、可验收的循环，而不是一次性大改。
> 每个循环 = 一次完整交接：**策划定标准 → 美术/QA 找差距 → 程序落地 → QA 验收 → 策划签字 → 红队对抗审查**。

## 1. 四个职能 agent

| 职能 | agent 定义 | 核心产出 | 不做什么 |
|---|---|---|---|
| 策划 | `.claude/agents/game-designer.md` | 竞品拆解、质量门槛、P0/P1/P2、验收口径 | 不写代码、不改美术资产 |
| 美术 | `.claude/agents/game-art-director.md` | 维度打分、整改参数、A/B 图、风格统一意见 | 不改游戏逻辑 |
| QA | `.claude/agents/game-qa-lead.md` | 基线、测试计划、bug、放行结论 | 不改玩法逻辑 |
| 程序 | `.claude/agents/game-engineer.md` | 代码改动、自测输出、风险 | 不做产品决策、不擅自扩需求 |
| 红队 | `.claude/agents/game-red-team.md` | 对抗审查：证据/性能/逻辑/许可/文档的可复现问题 | 不做建设性美化、不改代码 |

## 2. 一个循环的 6 个步骤

1. **策划（Brief）**：更新竞品与质量门槛；本轮只挑 **≤3 个 P0**，写清“玩家会看到什么变化”和验收口径。
2. **美术 + QA（Review / Baseline）**：同一版本上并行——美术给画面差距与参数，QA 跑基线（探针、无头、截图）。
3. **程序（Implement）**：按 Brief + 美术参数实现；保留程序化回退；自测通过后交 QA。
4. **QA（Verify）**：跑用例与回归，给“放行/阻塞”；阻塞项回到第 3 步。
5. **策划（Sign-off）+ 记录**：确认玩家可感知变化，写入 `docs/迭代记录.md` 的轮次记录，更新质量分。
6. **红队（Adversarial Review）**：独立复现，专找“报告说做到了、实际没做到”的问题；P0 未清则回退到第 3 步。

## 4. 质量门槛（0–10，竞品对标口径）

| 维度 | 权重 | 当前 | 目标 | 验收方式 |
|---|---|---|---|---|
| 角色与动画 | 15% | 待评 | 8 | 同机位截图 + 动画目检 |
| 视觉统一性（程序化 + 外部资产） | 15% | 待评 | 8 | 同场景截图对比 |
| 光照与氛围 | 15% | 待评 | 8 | 黄昏/夜间截图 |
| 构图与镜头 | 10% | 待评 | 8 | 主镜头 / 近景截图 |
| 材质与细节密度 | 10% | 待评 | 8 | 近景截图 |
| 性能 | 10% | 待评 | 8（≥60 FPS） | `probe_patrol.gd` A/B |
| 稳定性 | 10% | 待评 | 9 | 无头 600 帧 + 探针 |
| 玩法与反馈 | 10% | 待评 | 7 | 任务链/交互实测 |
| 音画完整性 | 5% | 待评 | 5 | 现有范围（暂无音频） |

**放行规则**：本轮相关维度必须 ≥ 目标 - 0.5，且稳定性 ≥ 8、性能不回退 > 2 FPS；否则阻塞。
**阶段门槛（非像素垂直切片，2026-10-31 起）**：视觉 5 维归一化 ≥ 7.0、单项 ≥ 6.5、角色 ≥ 7.0、同框 ≥ 7.0；完整游戏 8 分是后续内容阶段的终态。

**B 方案验收口径（2026-10-31；美术建议、在用户未指定 A/B 时的推荐默认）**
- 近景：垂灯成立（手套压顶板、杆/提梁可见、玻璃可读、脸 R p95<240）。
- 广角：暖点可辨——距提灯人最近处至少 1 个独立暖色连通域（长边 ≥10px、与街灯分离），不盖人、不浮空；**允许灯笼本体或地面光池计入**（在 960 native 口径测量）。
- 不适用 70px/2m 图标：27.5m 下真实手持灯在结构上无法既真实又 ≥70px。

**“亮芯/脸光”统一度量（2026-10-31 红队后定义，已被 B 口径取代）**
- 广角手持灯：默认 48°/27.5m、00:00、1920×1080、UI 隐藏；关街灯隔离，另在街灯开启的 canonical 图目检。以灯笼屏幕坐标为中心 ±120px，亮芯 = `R>200 && R−B>25 && R−G>8`；门槛 **长边 ≥70px 且面积 ≥1200px²**。宽度不作为单独否决项（会逼出手持灯 3–5 倍放大）。
- 近景脸光：16°/5.8m 近景、脸 ROI（排除灯笼/头发），R 通道 p95 <240。

## 5. 循环节奏

- 每个循环只做 **1–3 个 P0**；跨循环累积，不追求一次到位。
- 每个循环必须留下：同机位前后图、实测数值、`docs/迭代记录.md` 一条记录。
- 风格决策（程序化 vs 外部模型）由策划 + 美术共同签字；程序不单独定。
