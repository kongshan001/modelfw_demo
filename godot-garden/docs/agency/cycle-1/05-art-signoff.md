## 3. 仍不足（5 条）与 Cycle 2 必须做的 3 件事

### 3.1 仍不足（按玩家感知/放行风险排序）

1. **P0-3 夜间脸光未过，且 16° 黄昏也过白。**
   - 证据：`patrol_lantern_night.png` 脸部 p95 **255**、max **255**、>240 **7.76%**；`signoff_lantern_night_16deg.png` 为 **255/255/10.37%**；`signoff_lantern_dusk_16deg.png` p95 **248**（阈值 <245）。脸颊单区 >240 达 25.7%/33.1%，与 04 §7 自报的 24% 一致。
   - 结论：这是唯一硬指标未过项。眼睛/鼻子/嘴可读，但“脸颊三段明暗”在持灯侧被洗成一片暖白；不是“没有过曝”，是“过曝集中在脸颊”。

2. **动画/步态证据缺失，PAUSE 没有“意图”。**
   - 证据：04 §7 自述“专用 PAUSE 举灯动作”留 Cycle 2、640 未抓；现有只有静帧。没有 `cycle1_walk_pause.gif`/90 帧，T-pose=0、过渡≤0.25 s、脚滑≤5% 均未证。
   - 结论：PAUSE=`Idle` 符合 brief v2 Q2，不算程序违规；但相对 02 的“举灯”推荐未达成，驻足读起来只是“站着”，角色动画分因此压在 6.1–6.2。

3. **同框统一性 5.5，`cycle1_mixed_cast.jpg` 缺失。**
   - 证据：`patrol_wide_dusk.png` / `signoff_wide_night.png` 中 Rogue 头部接近女孩全身高；46.7% vs 23.9% 的头身比在默认广角直接复现。近景 `patrol_lantern_dusk.png` 里女孩在背景，尚可；同框近景按 brief 本轮不拍。
   - 结论：视觉统一 6.0 是“近景条件分”，同框 5.5 是 Cycle 2 债；没有 `cycle1_mixed_cast.jpg` 就无法完成 brief §8.3.2 的正式签字条件。

4. **默认广角“守夜人”剪影弱，灯杆/光晕尺寸不足。**
   - 证据：夜间默认 48°/27.5 m，Rogue 的暖色区仅 **27×39 px**（>200 核心 24×24），灯杆约 1–2 px；brief 要求 1080 下光晕 ≥70 px。zoom 0.65 时暖色区 42×54 px，灯体可读，但仍 <70 px。Rogue 身体绿色在草地中偏暗，头部红块是最强识别点，容易被旁边路灯的暖光抢读。
   - 结论：Q7“人形 + 暖光”勉强成立；“竖向灯杆 + 暖光可辨”在默认广角未达成，只在 zoom 0.65 成立。

5. **机位/证据治理缺口。**
   - 证据：发布内近景由 brief 的 **16°/5.8** 改为 **12°/5.2**（04 §2.3），未按“本轮不改机位”签字；canonical 截图 **13:29** 早于代码/文档 **13:33**；缺 `cycle1_face_light.png`、`cycle1_mixed_cast.jpg`、`cycle1_640x360.png`、`cycle1_noon.png`、`cycle1_walk_pause.gif`、canonical 的 `cycle1_wide_night.png`（本评审 13:40 补拍的是 `signoff_*`，不是发布验收图）。
   - 结论：不是画面问题，但会让“通过”不可复核；05 不能拿 12° 的图替代 16° 验收，也不能拿 13:29 图替代 13:33 后代码的验收。
