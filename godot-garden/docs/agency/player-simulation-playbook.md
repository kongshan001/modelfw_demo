# 虚拟玩家面板 · Playbook（参考 MatrAIx / 硅谷101）

> 日期：2026-11-01
> 参考：B 站【硅谷101】《AI 开始预测人类：83 亿虚拟人格、数字社会，与一门押注未来的生意》（BV1bYY463EHT）
> 适用：废墟花园每次可玩版本（截图 + 玩法事实）上线前的**预筛**，不替代真人测试。

## 1. 视频讲了什么（与本项目相关的部分）

- 哈佛/MIT 的 **MatrAIx**：约 **83 亿人格记录**（不是 83 亿个同时跑的聊天机器人），每人格约 **1290 个维度**（年龄/职业/心理/价值观/消费等），用于问卷、Chatbot、网站、App 四类测试环境。
- 一致性：400 项受控测试中 **366/400（91.5%）** 的行为与人格设定一致；问卷/聊天 92–96%，App 操作约 83%。
- 商业化：**Simile、Aaru** 等公司探索“卖模拟 / 卖预测”，用于产品测试、市场研究、未来预测。
- 关键限制：结果**强依赖底层 LLM**（同一人群，GPT-5.5 与 Claude Opus 4.8 的购买犹豫率 98.3% vs 27%）；MatrAIx 定位是**预筛与研究基础设施**，不能替代真人；存在训练数据偏差与隐私风险。

## 2. 我们怎么用（缩小版）

- 不追求 83 亿，**5–8 个高区分度玩家画像**，同一版本、同一材料、彼此盲评。
- 目的：在真人测试前**发现体验问题、生成假设、排优先级**；不是拿分数当市场结论。
- 与现有 agent 流水线的关系：策划/美术/QA/程序/红队是“制作侧”；虚拟玩家是**体验侧**，补上“玩家第一眼/前 5 分钟/是否想继续”的视角。

## 3. 人格 schema（本项目 8 维）

| 维度 | 取值示例 |
|---|---|
| 平台 | PC / 手机 / 低配核显 |
| 游玩时长 | ≤30min/天 / 1–2h/天 |
| 动机 | 治愈 / 挑战 / 美术 / 剧情 / 性价比 |
| 挫折耐受 | 低 / 中 / 高 |
| 操作习惯 | 键鼠 / 触屏 / 手柄 |
| 付费意愿 | 白嫖 / 打折 / 首发 |
| 审美偏好 | Q 版低模 / 写实 / 像素（本项目已排除像素） |
| 怀疑度 | 对 AI 素材/独立游戏的态度 |

## 4. 面板协议

1. **材料**：同一天的截图（同框/近景/广角/夜景/UI）+ 玩法事实清单（任务时长、NPC 数、无音频、目标 60 FPS、CC0 资产）。
2. **任务**：10 秒第一印象 → 前 5 分钟会做什么 → Top 3 问题（标注“看见的”/“推测的”）→ 继续玩意愿 1–10 → 愿望单/购买意愿 → 一条具体改法。
3. **盲评**：人格之间不共享答案；同一模型、同一温度，减少互相污染。
4. **聚合**：共性问题（≥3 人）→ P0；分歧点单独列（不同人群的取舍）；每条都标证据。
5. **验证**：P0 假设用 3–5 名真人玩家复测；合成面板只做预筛，不做“通过/不通过”的硬门。

## 5. 限制与反偏差

- **模型依赖**：换模型可能改变结论；面板必须写清模型/版本/日期。
- **不能证明“好玩”**：只能发现表述、第一眼、理解成本、明显挫败点。
- **画像≠真人**：避免把合成结果当市场数据；涉及付费/留存只作方向参考。
- **证据纪律**：没有截图/玩法事实支持的判断，必须标“推测”。

## 6. 节奏

- 每个可玩版本跑一次（5–8 人，约 10–15 分钟），记录分数与 Top 问题。
- 版本间比较**同一批人格**，看分数与问题是否收敛。
- 真人测试后回填：哪些合成问题被证实/推翻，校准下一次人格 prompt。
