## 2. 新增/残余视觉问题

### P1-1 灯笼顶板/底板发蓝（材质语言冲突）
- **证据**：night y840 x634–671 **(40,57,99)**、x703–718 **(48,67,117)**；6×/2× 都能看到顶面是饱和蓝紫，和暖奶油玻璃对冲。原因是 `frame_mat` 为 `metallic 0.35`、roughness 0.65，暗色金属把冷色环境反射成蓝。
- **改法**：`frame_mat.metallic=0.0`、`metallic_specular=0.0`、`roughness=0.90`；必要时 albedo 改 (0.095,0.075,0.060)。顶/底板保持深棕黑，不参与环境冷反射。
- **验收**：6× 顶/底板 B−G ≤ +10（当前 +42/+50），2× 第一眼读作“黑铁灯罩”，不再读作蓝盖。

### P1-2 官方近景拳-杆证据被截图工具污染
- **证据**：冻结后 `_face_patrol_to_camera` 才转头，灯架不再跟随手；官方图灯架距正确手位约 0.18 m，导致杆只与拳重叠 33%；手动 `_update_lantern_rig()` 后杆进入拳下/拳前，但提梁中段被拳遮住，live 状态杆几乎不可见。
- **改法**：截图工具顺序改为“机位 → 转头 → `set_time` → `_update_lantern_rig()` → `set_process(false)` → 冻结姿态 → 截图”；不要为了截图去改游戏里杆的位置。
- **验收**：1920 12× 官方图杆与拳横向重叠 ≥60% 杆长；同时 6× 仍能读出“手套—横杆—双柱—顶板”四层（若杆被完全遮住，需把杆下移 0.01 m 或杆长加到 0.16 m，再做一次 1× 复拍）。

### P2-1 提梁可见性/材质
- **证据**：`handle_mat=(0.5,0.46,0.38)`；night 受点光后偏灰白，dusk 偏灰；杆在 live 状态被拳遮住。
- **改法**：杆稍微加长（0.14→0.16 m）或把手套/yaw 调 3–5°，让拳“压住”而不是“吞掉”横杆；杆色略暖 (0.52,0.44,0.32)。
- **验收**：6× 杆端双柱至少各露出 1 个柱头，横杆左右各可见 ≥8 px；杆/手套对比 ≥3:1。

### P2-2 广角提灯人过弱
- **证据**：见 §1.4；R≥160 最大连通域 5×7，街灯 255/173–630 px。
- **改法**：不改 core_wide；可在 **12 m 以外** 给玻璃 emission ×1.5（body 已 1.8×）或加一个**小尺寸、灯形**的远距 sprite（α≤0.20，仅 far_t>0.6 显示），保持“无 2D 灯形”需用灯形而非光球。
- **验收**：960 native 提灯人 R≥160 单连通域长边 ≥10；与街灯净距 ≥20 px；不浮空。

### P2-3 UI 底提示对比
- 3.12:1 → 0.55 α 黑底 pill 或 1 px 深描边；验收 ≥4.5:1。

## 5. 风险

1. **把 R 裁切误当已修**：去掉 core_wide 后仍有 86–89% 的 R≥250；只是从“全白”降为“奶油红饱和”，不能对外说“玻璃曝光已修好”。
2. **截图工具继续伪造拳-杆**：冻结后转头 0.18 m 的错位会让下一轮又判“脱手”；先修工具，再调杆。
3. **为压 R 裁切把 emission 降太低**：黄昏/广角会失去暖灯识别；建议先只降 energy（0.371→0.26），不要同时大改 albedo。
4. **广角因去 core_wide 退化**：若远距识别不达标，回加的是“灯形小 sprite/远距 emission”，不是恢复 core_wide 光球，否则白团复发。
5. **ΔRGB 与“玻璃回温”目标冲突**：若坚持 B 的 ≤12，必须 UNSHADED 固定色；若保留黄昏冷白，应正式改写该门。
