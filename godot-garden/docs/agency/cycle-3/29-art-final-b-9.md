## 3. Top 问题与整改参数（按收益排序）

### P0-1 halo 仍开且每帧被重新点亮（第四次复发）
- **问题**：工具的手动 `visible=false` 位于 `set_time()` 之前；`garden_scene._process` 每帧 `_apply_time → world.set_patrol_night → patrol.set_night`，把 core/outer/far/wide 的 visible 与 alpha 全部写回。巡逻自身的 `set_process(false)` 挡不住这个外部直接调用。
- **证据**：探针 18.4/0.0 后 core 0.0265、outer 0.1061、far 0.1061、wide 0.3535，均 visible；6× 近景背景奶黄；广角光斑 79×61；`screenshot_patrol.gd:66-70` 顺序可见。
- **改法（必须落代码，不接受口头）**：
  1. `GardenPatrol` 增加 `halos_forced_off := false`；`set_night()` 内若为真则 `visible=false`、alpha 归 0；
  2. 工具顺序改为：`set_time` → `await` → `_scene.set_process(false)` → **调用一次 `_update_lantern_rig()`** → `_lantern.halos_forced_off=true` → 关闭 5 个 halo → 冻结 → 截图；
  3. 近景显式 `_lantern_halo_outer.modulate.a = min(0.03, ...)`，不要只依赖 core×0。
- **验收**：探针 core α=0、wide α=0、outer ≤0.03；6× 近景背景无大面积光晕；交付图与声明一致。

### P0-2 ΔB +20 仍超门（A 案曝光/雾必须落地）
- **问题**：unshaded 只绕过灯光，不绕过 tonemap 曝光与 fog；固定 albedo 在黄昏仍被 1.404× 曝光与不同雾色整体抬亮。“ΔB=0”是材质层结论，不是屏显层。
- **证据**：纯窗格夜 60.9/64.3 → 黄昏 80.9/85.0，ΔB +20.0/+20.6；关雾后 +15.5/+16.7；exposure 1.404 vs 1.000、glass `disable_fog=false`。
- **改法（推荐 A）**：
  1. `_env.tonemap_exposure` 去掉 `dusk_glow*0.45`，固定 **1.0**；用 `_sun.light_energy` +0.25～0.35、`ambient_light_energy` +0.08 补偿黄昏；
  2. 玻璃/框/提梁全部 `disable_fog = true`；
  3. 曝光固定后把玻璃 albedo 由 (0.45,0.38,0.26) 提到 **(0.82,0.78,0.50)**（G/R≈0.95、B/G≈0.64，与街灯同族；1.0× 曝光下 R≈230，留 250 余量）。
- **验收**：纯窗格夜/黄昏每通道 **|Δ|≤12**、R≥250<3%、G≥250<3%；G/R 0.90–0.96、B/G 0.55–0.65；6× 保留暖琥珀层次，不是奶白平贴纸。

### P0-3 提梁 45% 可见、单柱、悬空 19 px
- **问题**：这轮只加宽（±0.09 / 顶杆 0.20），没有下移与连接；横杆仍在拳顶上方 27 px，纵向不重叠，右端与右柱被前臂吞没；双柱底端 0.02 与顶板上表面 −0.0375 之间仍留 0.0575 m 缝，读作“漂浮的 П 环 + 手在灯顶下方”。
- **证据**：可见率 45.0%；顶杆右半 20/477 px；右柱 63/826；杆 y 655–662 vs 拳顶 y≈689；提梁底 717.6 vs 顶板 737.0（19.4 px）；绿色 nomodel 隔离图可见完整悬空 U。
- **改法（B-8 P0-2 原方案，一步到位）**：
  1. 横杆 y **0.16 → 0.02～0.03**（穿过掌心），长度 **0.20 → 0.18**（±0.09）；
  2. 双柱从顶板上表面 **−0.0375** 连续连到横杆 y，禁止悬空；
  3. `ROGUE_LANTERN_OFFSET.x 0.06 → 0.00`，y 保持 −0.02；
  4. 若右端仍被前臂吃，整体绕 Z **−0.10 rad**。
- **验收**：1920 6× 横杆可见 **≥60%**、两端各露 **≥6 px**、双柱可见、提梁-顶板缝 **≤2 px**；四层可读（手套→横杆→双柱→顶板）；night/dusk/UI 三帧一致。

### P1-1 广角仍为光球，`_wide_core` 恒 false

### P2-1 玻璃偏暗偏棕（新回归）
