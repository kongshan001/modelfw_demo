## 3. Top 问题与整改参数（按收益排序）

### P2-1 提梁亮度=玻璃 101%，且横杆在拳前 6.1 cm（唯一未闭硬门）
- **问题**：提梁连板与双柱已闭，但浅米色 Π 形仍与玻璃同亮度，6×/12× 读作“第二条发光条”；横杆比手心更近机位 6.1 cm，拳在框后。
- **证据**：显示层提梁 **Y=148.4（夜）/150.5（黄昏）**，玻璃 **146.7/149.0** → **101%/101%**（目标 ≤70%）；`HANDLE_DEPTH hand=4.401 bar_center=4.340`；12× 裁切可见右柱压在拳前。
- **改法**：提梁 albedo `(0.5,0.46,0.38)` → **`(0.34,0.31,0.26)`**（unshaded，预计 Y≈101，约 69% 玻璃）；`ROGUE_LANTERN_OFFSET` 的 z 由 0 改为 **−0.04、x +0.03**，或 `_lantern_body.rotation.y −8°…−12°`，让右柱脱出拳影而不再整体前漂；横杆回到掌心 y 0.10→**0.06**。
- **验收**：提梁 Y ≤ 玻璃 70%；6× 下拳前缘压住横杆；右柱 ≥70%、缝 ≤2 px 不回退。

### P2-2 玻璃族色比仍在目标外
- **证据**：夜 G/R **0.923**（差 0.007）、B/G **0.648**（超 0.008）；黄昏 G/R **0.895**（差 0.035）、B/G 0.611（达标）。
- **改法**：玻璃 albedo `(0.50,0.46,0.32)` → **`(0.50,0.48,0.305)`**（起点值）；保持 unshaded、emission_energy 0.15。
- **验收**：显示层 G/R 0.93–0.97、B/G 0.58–0.64；ΔB ≤12、裁切 0% 不回退。

### P2-3 广角 10 px 余量为 0–1 px；线性放大侵蚀像素
- **证据**：960 native 纯玻璃 11×10 / 9×10，长边 10–11；交付 1920 经线性放大后纯色块只剩 14×18（960 等效 7×9）。
- **改法**：不改美术尺寸；在 `cycle1_wide` 固定机位下写死验收值并禁止再动 FOV/距离；若要像素气质，`garden_scene.gd` L282 `TEXTURE_FILTER_LINEAR` → `TEXTURE_FILTER_NEAREST`，或把 UI 副标题“实时像素渲染”改为“实时渲染 · 960×540”。
- **验收**：下一轮同机位 960 native 长边 ≥10 且不再靠四舍五入；UI 文案与过滤一致。

### P2-4 街灯仍是最亮体、玻璃 disable_fog=false
- **证据**：夜/黄昏街灯窗格 R≥250 仍显著，手持灯无裁切；探针 `disable_fog=false`。
- **改法**：街灯 emission 降 10–15%；玻璃/框/提梁 `disable_fog=true`。非硬项。
