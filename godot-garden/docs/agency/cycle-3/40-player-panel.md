# 虚拟玩家面板 · 第一次试点结果

> 日期：2026-11-01
> 方法：`docs/agency/player-simulation-playbook.md`（参考 MatrAIx / 硅谷101 的合成人格预筛）
> 材料：`cycle2_mixed_cast.png`、`patrol_lantern_night.png`、`patrol_wide_dusk.png`、`cycle1_wide_night.png`、`cycle3_ui_pause.png` + 玩法事实（任务 7.4s、无音频、960×540、CC0 资产）
> 性质：**合成人格预筛，不是真人测试**；分数只作方向，不作市场结论。

## 1. 面板结果

| 画像 | 继续玩意愿 | 购买意向 | 一句话 |
|---|---:|---|---|
| 休闲治愈（小周） | 4/10 | 白嫖 | 画面好，但像开发者沙盒；夜太黑 |
| 硬核动作（老K） | 3/10 | 免费试、不付费 | 氛围 7、动作 3；自动战斗像挂机 |
| 美术氛围（Momo） | 6/10 | 愿望单 + 等打折 | 氛围能打，演示感盖过作品感 |
| 剧情世界观（阿岚） | 4/10 | 愿望单、暂不买 | 只有氛围，没有故事 |
| 低配性价比（阿杰） | 4/10 | 白嫖观望，≤20 元再考虑 | 免费技术演示，还不足以卖钱 |

平均继续玩意愿 **4.2/10**；无人愿意首发价购买，1 人加愿望单。

## 2. 共性问题（≥3 人，按提及频次）

1. **无音频（5/5）**：没有 BGM、脚步、打击、环境声，氛围和反馈少一半；硬核玩家直接判“打击感归零”。
2. **内容量不足（5/5）**：任务链 7.4s、1–3 只妖灵、角色复用（Rogue/Rogue_Hooded），“好看没事做”，撑不起价格。
3. **夜景可读性（4/5）**：广角夜近半屏死黑，暗处难辨角色与路；提灯照不到持灯人自己，脸全黑/脚下过曝（美术、休闲、低配、剧情）。
4. **开发工具感 UI（3/5）**：×600 时间条、“实时像素渲染”文案、键鼠提示、光束开关，让玩家觉得在开调试器；手机端直接卡住。
5. **自动战斗/挂机感（3/5）**：自动寻路 + 靠近自动战斗，无闪避/格挡/锁定；硬核玩家 3/10。
6. **叙事缺失（2/5）**：NPC 驻足无台词、章鱼缠石像的谜面被做成普通讨伐；任务卡只有“回到石像复命”。

## 3. 分歧（不同人群的取舍）

- **美术派 6/10** 要“更精致的氛围”，**硬核 3/10** 要“更深的动作”，**休闲 4/10** 要“更少的挫败/更清楚的夜路”，**剧情 4/10** 要“动机与对白”。同一版无法同时取悦，需要明确首发受众。
- 美术派认为红章鱼跳色“割裂”，休闲派则觉得“不够治愈”；硬核/低配则把它当战斗目标。章鱼的定位需要统一（谜题/威胁/奇观）。

## 4. 建议优先级（影响 × 成本）

| 优先级 | 动作 | 影响 | 成本 |
|---|---|---|---|
| P0 | **补基础音频**：BGM + 脚步 + 打击 + 环境虫鸣/水声 | 5/5 画像提及，最便宜的“完整感”提升 | 低（程序化/免费音效） |
| P0 | **夜景补冷色环境光**：无灯处路径/人物/妖灵始终可辨；提灯对持灯人补 5–10% 暖光 | 4/5 画像提及 | 低（参数） |
| P1 | **UI 去工具感**：默认隐藏 ×600/像素渲染文案/光束开关；补触屏提示 | 3/5 | 低 |
| P1 | **叙事最小闭环**：三 NPC 驻足台词气泡 + 接任务时章鱼 3 句对白 | 剧情 4/10 的直接诉求 | 低–中（文本/气泡） |
| P1 | **内容扩到 10 分钟**：3 波敌人 + 1 次强化/技能，手动战斗选项 | 硬核/低配的核心诉求 | 中 |
| P2 | 角色复用缓解：扫园人换独立轮廓（兜帽已区分）/主角服装差异 | 低配“换色复用”观感 | 中 |

## 5. 限制与验证

- 合成人格受底层模型影响大（MatrAIx 的购买犹豫率实验：98.3% vs 27%）；本面板只用于**发现问题与排序**。
- 分数是方向，不是市场预测；不能替代真人测试。
- 下一步：先做 P0 音频 + 夜景补光，再跑同一批 5 个画像，比较分数与问题是否收敛；用 3–5 名真人玩家验证 Top 3 问题。

## 6. 附：为什么用这个方法

MatrAIx 用 83 亿合成人格做产品/问卷/App 预筛，并明确“预筛而非替代真人”。我们没有 83 亿，但可以把它缩成 **5 个高区分度画像 + 同一版材料 + 盲评 + 证据标注**，在每个可玩版本前跑一次，成本约 10–15 分钟，能稳定暴露“第一眼/前 5 分钟/是否想继续”的问题。
