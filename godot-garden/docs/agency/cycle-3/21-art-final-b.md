## 3. Top 问题（按收益排序）

### P0-1 提梁仍不可见（B 近景唯一硬缺口）

- **问题**：3D 垂灯本体保留，但提梁横杆被拳完全包住，近景读作“手压灯顶”，不是“手拎提梁”。
- **证据**：6× 裁切（夜/黄昏/UI）无浅木色横梁；UI 唯一暖灰凸点 **5×6 px (88,65,41)**；夜间唯一横线是顶板边缘 **21×4 px (172,150,161)**；代码横杆 0.14×0.015×0.015 m，位于手锚 +0.012 m，拳宽约 0.16 m。
- **改法**：横杆加宽到 **0.22 m、双柱 ±0.085 m**；或 `_lantern_body` 整体下移 **0.09 m**；或横杆上移 **+0.02 m**。材质保持浅木 `(0.5,0.46,0.38)`，可加 0.05 emission 保证夜间可读；**不要重新引入 billboard 图标**。
- **验收**：1× 截图在拳头两侧各见 **≥6 px** 浅木色横梁；6× 裁切可读出“手套—提梁—顶板”三层；提梁与手套对比 **≥3:1**；不遮玻璃。

### P0-2 固定保持帧仍未接入（污染 B 证据）

- **问题**：三张近景姿态不一致，曝光/脸光读数不可复现。
- **证据**：背景最佳位移 **(0,0)**，灯窗 bbox 夜→UI 横移 **+41 px**、纵移 **+23 px**；玻璃 p95R **202→242**；工具仍只有 `seek`+`pause`，无 `speed_scale=0.0`。
- **改法**：`force_pause` 后等一帧，播 `Interact` 再 `seek(0.35*len)`，随后 `speed_scale=0.0`；或在 `GardenPatrol` 增加 `hold_pose` 标志，FSM 在该标志下不再 `play`。
- **验收**：连续 3 s 手 Y 极差 **≤0.03 m**、animPos 恒定、日志含 `speed_scale=0.0`；三张近景灯体漂移 **≤2 px**；窗格 ΔRGB **≤12**。

### P1-1 玻璃色温分裂 + 顶板泛蓝（风格统一性）

- **问题**：同一盏灯黄昏粉紫、夜间/UI 橙，顶板夜间蓝；不是固定暖白。
- **证据**：黄昏窗格 (218.6,199.3,207.4)（B>G、B/R 0.95）；夜 (194.2,139.9,113.5)、UI (203.2,142.2,108.1)（B 108–114、G/R 0.72）；顶板蓝均值 (50.6,68.7,114.6)，25.8% UI；街灯 R≥250 4.4–15.1%。
- **改法**：近景玻璃改 `SHADING_MODE_UNSHADED`、`emission_enabled=false`，固定暖白目标 **sRGB 均值 R 230–240、G 185–200、B 125–145（G/R 0.80–0.85、B/R 0.52–0.60）**，按 ROI 逐通道校准（R>245 降 0.03、B<120 升 0.04）；`frame_mat` 设 `disable_ambient_light=true` 或 UNSHADED **`(0.08,0.065,0.05)`**；街灯玻璃用同一暖白 ramp，亮度 +10% 以内。
- **验收**：黄昏/夜/UI 三图窗格均值 **ΔRGB≤12**；无窗格 B>G+8；顶板 **B−R≤20**；R p95<245；街灯 R≥250 **<20%**。

### P1-2 广角“暖点”由光晕/地面池承担，3D 玻璃本体暗

- **问题**：B 广角在 1920 图可辨，但最近暖点是 12×19 光晕；3D 玻璃 ~15×18/窗、均值约 (105–130,85–110,60–90)，无 R≥160 像素；读作“暖区+小黑灯”，不是“灯形”。
- **证据**：见 §2.3；native 960/640 下最近光晕仅 **6×9.5 / 4×6.3 px**，只有地面池达标（19×15.5 / 12.7×10.3）。
- **改法（若要求灯形，而非仅暖点）**：给 3D 玻璃加 **仅远距（far_t>0.6）生效**的固定暖白 emission 或 1–2 px 暖框，禁止 billboard 灯形 quad；同时把地面池 alpha 从 0.45 降到 **0.32–0.36**，避免“地面池比灯亮”。
- **验收**：默认广角、无 2D 图标；3D 玻璃暖色连通域长边 **≥10 px（1920）且 ≥10 px（native 960/640）**、均值 R≥160、R−B≥25；与街灯分离 ≥20 px；脸部暖像素 0；不浮空。

### P2-1 验收口径与可读性残留

- **分辨率口径**：代码 `RENDER_SIZE=960×540`，证据 1920×1080，任务书写 640×360；B 的“≥10px”必须写死分辨率，否则最近光晕在 native 下是 6×9.5/4×6.3，“过”与“不过”取决于读法。
- **UI 底提示**：文字 `(160.7,153.8,137.9)` vs 背景 `(137,109,57)`，对比 **1.7:1**；加 0.55 α 黑底 pill 或 1 px 深描边，验收 **≥4.5:1**。
- **街灯主导**：五盏街灯 R≥250 4.4–15.1%，广角最亮体仍是街灯；建议街灯 emission 降 10–15% 或 bloom 上限压 5%，验收手提灯暖区与最近街灯亮度差 **≤25%**。
