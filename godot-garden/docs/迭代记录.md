## 轮次 0 · 2026-10-29 · 初版基线

- **目标**：复刻参考片的“像素化黄昏废墟花园”：640×360 内部渲染、程序化废墟/水池/草/灯/萤火/光束、昼夜循环、女孩沿路径行走。
- **技术方案**：SubViewport 低分辨率 + NEAREST；程序化几何 + 自定义水/草/光柱/云影 shader；时间曲线驱动光照/雾/粒子；后处理做柔光/冷暖分级/dither/暗角。
- **结果**：88–90 FPS @1280×720；昼夜/路灯/萤火/水面/光柱全部可运行。
- **问题**：镜头太远（约 19m 视野）、正午顶光、黄昏橙色滤镜、材质纯色 blockout、后处理全屏 dither 与放大网格冲突。
- **相关文档**：`docs/2026-10-29-废墟花园技术方案.md`（初版参数）。
- **独立评审**：4.3/10（对标参考片）/ 6.5/10（程序化原型口径）；见 `docs/2026-10-29-独立美术评审.md`。

## 轮次 1 · 2026-10-29 · P0-1 镜头 / P0-2 光照 / P0-6 后处理 + 部分 P0-3

- **目标**：按独立评审的 P0 快速见效项，先把“看全园的地图视角”改成有主次的场景，并消除橙色滤镜与后处理噪点。
- **改动清单**：
  - **镜头**：`CAMERA_TARGET=(-1.5,0.8,4.5)`、距离 27.5m、俯角 48°、方位 45°、默认 zoom 1.0；滚轮 0.65–1.7；环绕 ±0.025 rad；相机 0.04 网格吸附；少女缩放 1.45→0.95。
  - **光照**：太阳能量 `pow(day,0.5)×(2.2+dusk_glow×1.4)`；正午太阳 70°（不是 90° 顶光）；方位斜率从 10°/h 降到 0.8°/h，黄昏侧光；环境光改为 `0.32+day×0.3+dusk_glow×0.8+twilight×0.35`；冷色补光 `0.08+dusk_glow×0.45+night×0.15+twilight×0.15`；曝光 `1.0+dusk_glow×0.45`；月亮阴影关闭（开启会从 89–90 掉到 68–79 FPS）。
  - **后处理**：UV 锁定 640×360 源像素中心；移除全屏 2×2 dither + 6bit 量化；bloom 降到 `0.06+lamp×0.1+night×0.04`；暗角 `0.2+night×0.1`；暖/冷分级系数 0.16/0.3。
  - **水面/岸线（部分 P0-3）**：加深水面中心、降低天空反射/自发光、岸线用世界噪声打断、加 4 片睡莲 + 6 根芦苇；路径 2.0→1.8m；UI 副标题随小时变化、移除技术水印。
- **效果对比**：`media/p0_before_after.jpg`（上：17:48 黄昏，下：00:00 深夜；左初版 / 右本轮）。
- **指标**：89–90 FPS @1280×720（内部 640×360）；1920×1080 截图 5 张。
- **结论**：构图主次、光照方向、后处理干净度明显改善；少女/路径/水池成为前景层。但材质仍是纯色 blockout，水面偏平，树冠是光滑球。
- **遗留/下一步**：P0-4 材质、P1-8 地被密度、P1-11 风格路线。

## 轮次 2 · 2026-10-29 · P0-4 材质语言

- **目标**：把“纯色 blockout”升级为有表面语言的低多边形材质：石头有噪声明暗/苔藓/湿石/假 AO；树冠有叶簇色变/透光；石板不再等宽盒子；路径几乎全石覆盖。
- **改动清单**：
  - **`stone.gdshader`（新增）**：世界坐标 value noise 混两档石色；`world_normal.y` 做朝上/侧面假 AO；朝上 + 噪声处生成苔藓；距水池 `POND_RADIUS+1.8` 内压暗 + 降 roughness 做湿石。应用于石径、废墟、岩石、岸边石。
  - **`foliage.gdshader`（新增）**：世界噪声做每簇色相/明暗变化；`BACKLIGHT` 给黄绿透光；轻微风摆。三套绿色材质；每棵树额外 5 个边缘小叶簇（约 15 簇/棵）。
  - **石径**：石板从等宽 BoxMesh 改为 6–8 边 `CylinderMesh` 倒角石板，x/z 非均匀缩放 1.0–1.45 × 0.55–0.8；间距 0.55–0.78m；横向偏移 ±0.28；三套 stone shader 轮换。路面几乎全石，土带只留缝。
  - **其他**：砖/石圈/断墙/柱等继续沿用 stone shader；雕像/祭坛等保持部分纯色材质以控制对比。
- **效果对比**：`media/p0_4_before_after.jpg`（左：轮次 1 的 17:48/00:00；右：本轮同机位）。
- **指标**：89–91 FPS @1280×720；路径 draw call 仍为独立 MeshInstance，后续可 MultiMesh 合并。
- **结论**：石径从“土路 + 小踏步石”变为有厚度/倒角/苔藓的遗址石板；树冠不再像 8 个光滑球；废墟/岸边石有湿/干/苔藓层次。场景仍偏程序化低多边形，和参考片的手绘像素密度差一档。
- **遗留/下一步**：
  - P1-8：3 种草型、400–600 朵花、落叶/碎石/苔藓 decal，提升多尺度细节。
  - P1-7：打破闭环路径、放大主拱门、加前景树/断柱框景。
  - P1-10：水面双噪声法线、岸边深度融合、灯光反射、涟漪。
  - P1-11：**风格路线二选一**（纯像素 640×360 + 调色板/像素 UI，或绘画低多边 960×540 + FXAA/纹理）；当前是“像素化 + 平滑材质”的混合体，先定路线再继续堆素材。
- **相关文档**：技术方案 §13.6；独立评审 P0-4 / P1-8 / P1-11。

## 轮次 3 · 2026-10-29 · P1-8 密度

- **目标**：在 640×360 像素路线内补“多尺度地被细节”：3 种草型、更多花、落叶/碎石、更多废墟/藤蔓，让近景不再只有单一草叶和空石头。
- **改动清单**：
  - **3 种草型**：中草 2800 株（铺底）、短草 1600 株（补缝）、高草 700 株（边缘/水边剪影）；共用十字草叶 mesh，`grass.gdshader` 的 `root_color/tip_color/wind` 各一套 `ShaderMaterial`；3 个 MultiMesh，3 个 draw call。
  - **花**：新增 `flower.gdshader` 与 `_make_flower_mesh()`（十字面片：下段茎、上段极坐标五瓣花）；白色 380 朵、蓝紫 160 朵；尺寸 0.8–1.4×（花头约 0.1–0.15m），只在草缝/空地分布，排除水池、石径 1.6m、石圈 3m。
  - **落叶**：85→140 片，新增第三套橙红材质；尺寸 0.08–0.18m。
  - **废墟**：新增两段断墙 `(14.2,0,8.5)` / `(-6.8,0,-10.4)`；拱门加垂藤（细绿柱 + 3 个小叶球，代码已在 `_create_arch` 内）。
  - **性能**：3 草型 + 2 花型 MultiMesh；FPS 从 89–91 降到 **87** @1280×720（仍 >60，可接受）。
- **效果对比**：`media/p1_density_before_after.jpg`（左 P0-4 / 右 P1-8，上黄昏 17:48 / 下深夜 00:00）。
- **指标**：87 FPS @1280×720；内部 640×360；新增 2 个花材质 + 3 个草材质，draw call 约 +5。
- **结论**：近景草花密度、颜色层次和废墟边缘明显更丰富；白/蓝花在黄昏和夜里能读出“花园”而不是“草地 + 石头”。但花在低分辨率下仍偏“点状”，且 640×360 + 平滑材质的混合风格问题没有解决。
- **遗留/下一步**：
  - **P1-11 风格路线**：纯像素 640×360（调色板 + 像素 UI）vs 绘画低多边 960×540（FXAA/纹理，更接近参考片密度）；建议先做 960×540 A/B 样张再定。
  - P1-7：打破闭环路径、放大主拱门、加前景框景。
  - P1-10：水面双噪声法线、岸边深度融合、灯光反射/涟漪。
- **相关文档**：技术方案 §13.7；独立评审 P1-8 / P1-11。

## 轮次 4 · 2026-10-30 · P1-9 程序化章鱼

- **目标**：引入参考视频（BV1sEpE6pEWK 同类“章鱼 | 程序化动画 | 运动学模拟”）的**程序化触手**技术：Verlet 链、距离约束、地面/石柱碰撞投影、螺旋缠绕、夜间变色，并把它放进花园水池边的石像旁。
- **改动清单**：
  - 新增 `scripts/garden_octopus.gd`：
    - 8 条触手 × 12 个 Verlet 点；重力/阻尼；每个点朝目标做弹簧；每帧 4 次距离约束迭代；基点跟随身体。
    - 碰撞：地面 `y>=0.045`；石像近似为半径 0.6、高 2.2 的圆柱，点被推出柱面。
    - 缠绕：3 条触手（3/4/5）在 `wrap` 状态下沿石像生成半径 0.66、0.65 圈的螺旋目标；身体向石像倾斜。
    - 状态机：9s idle → 7s wrap → 循环；夜间 `sleep` 收拢触手/闭眼/变色。
    - 身体：低多边形球体 + 眼/瞳孔/嘴/白斑；眨眼；脚下软阴影。
  - 新增 `shaders/octopus.gdshader`（身体）与 `shaders/octopus_arm.gdshader`（触手）：
    - 本地坐标噪声色斑；朝上/朝下明暗；12 级量化；夜间偏冷/睡眠去饱和。
    - 触手腹面两排白色吸盘（UV）；身体不显示吸盘。
  - 触手渲染：**静态管网格（36 环 × 8 边）+ 顶点着色器用 `arm_points[12]` uniform + Catmull-Rom 重建**；每帧只更新 8 个 ShaderMaterial 的 points，不做 CPU 网格重建。8 条触手 = 8 draw call；静态网格共享。
  - 集成：章鱼放在石像 `(-1,0,1.8)` 旁；新增 `focus_octopus()` 近景相机；新增 `screenshot_octopus.gd` / `capture_octopus_sequence.gd`。
- **效果对比**：`media/octopus_before_after.jpg`（上：花园全景 无章鱼/有章鱼；下：章鱼近景 idle/缠绕）。动态 GIF 已单独发送。
- **指标**：**80–83 FPS** @1280×720（P1-8 约 87；章鱼约 5–7 FPS 成本）；内部仍 640×360；8 条触手 8 draw call。
- **结论**：章鱼在花园里成立，能读出触手、吸盘、眼睛和缠绕石像；夜间变色/收拢可见。限制：没有实现参考片的“地形采样牵引步态”（石像旁静止）、“单杠摆荡”和“落点预测”；触手仍有轻微分段/环状纹理。
- **性能迭代过程**（重要）：
  - 首版每帧重建 `ImmediateMesh` 管：**42 FPS**（GDScript 逐顶点调用太贵）。
  - 改用 120 个 MultiMesh 圆柱段：FPS 回到 60，但圆柱段之间出现明显缺口/条纹，视觉不可接受。
  - 最终改为“静态管网格 + uniform 数组顶点变形”：**80–83 FPS**，触手连续平滑；这是本轮的关键取舍。
- **遗留/下一步**：
  - 增加地形采样/落脚点与牵引式步态（参考片的“翻越乱石”）。
  - 单杠摆荡（阻尼单摆 + 缠绕约束）与更完整的螺旋路径/落点预测。
  - 交互：点击章鱼切换 idle/wrap/sleep；或让章鱼从水池爬到石像。
  - 触手环纹的进一步平滑（环半径/法线或细分级）。
- **相关文档**：`docs/2026-10-30-章鱼程序化动画-技术笔记.md`；技术方案 §13.8。

## 轮次 5 · 2026-10-30 · 巡园游人（程序化 NPC 巡逻）

- **目标**：给花园加入会自己走动、会驻足做事的 3D 角色，让场景从“静态布景 + 战斗”变成有生活感的园子；沿用章鱼那一轮“全程序化、零外部素材”的做法。
- **改动清单**：
  - 新增 `scripts/garden_patrol.gd`：3 个低多边形角色（提灯守夜人 / 扫园人 / 小狐侍），每人约 20–25 个 `MeshInstance3D`——长袍（上下两段圆柱 + 腰带）、斗笠/狐耳、可转动的头枢轴、四肢枢轴、道具（灯笼 / 扫帚 / 尾巴）、脚下软阴影。
  - **巡逻 FSM**：`WALK`（速度 0.72 / 0.55 / 1.05 m/s，到点判定 0.24m）→ `PAUSE`（随机 1.6–3.4s：提灯人举灯、扫园人扫地、小狐摇尾张望）→ 下一个路点；朝向用 `lerp_angle` 平滑，转弯不瞬移。
  - **路线**（手工按障碍安全距离校验，直线行走、不跑 A*，避免 1m 网格折线感）：
    - 提灯人绕水池 8 点，半径约 7m；避开石像 2.0m 障碍与环池灯柱。
    - 扫园人绕石圈 5 点，半径 4.2m；避开 2.35m 环石与 `(8,1.6)` 石柱。
    - 小狐侍在拱门后方 5 点巡逻；避开两根拱柱（0.75m）。
  - **灯笼**：自发光玻璃 + billboard 光晕 + 1 盏无阴影 `OmniLight3D`；亮度取 `max(night, low_sun×0.55)`，黄昏起就有暖光点，深夜最强。
  - **集成**：`GardenWorld._build_patrols() / set_patrol_night(night, dusk) / set_patrol_visible()`；`GardenScene` 的 `5` 键与 UI「游人」开关、`focus_patrol()` 近景机位、`set_film_camera()` 定点序列机位。
  - **相机避障**：提灯人用「锚点机位」——相机始终朝水池中心方向取景，跟拍时停在水面一侧，不会像固定方位角那样钻进池边树冠；扫园人/小狐用各自固定方位角。
  - **工具**：`tools/screenshot_patrol.gd`（7 张，含同机位有/无对比）、`tools/capture_patrol_sequence.gd`（90 帧，扫园人绕石圈，机位固定在石圈中央）、`tools/probe_patrol.gd`（位移 / 最小间距 / FPS / 开关链路）。
  - **顺带修复**：`garden_hero.gd`、`garden_monster.gd` 的 `lengthSquared()` → `length_squared()`（`Vector3` 无此成员，会让整个场景编译失败）；`garden_world.gd` 任务完成标记对 `MeshInstance3D` 使用 `modulate:a` 的非法 tween（每次交任务报错，且地面光圈不消失）。
- **效果对比**：`media/patrol_before_after.jpg`（上：石圈定点机位，无 / 有扫园人；下：提灯守夜人黄昏 / 深夜）。
- **指标**（1280×720，内部 640×360，关闭垂直同步）：完整场景 **60.2–60.7 FPS**（含主角 / 妖灵 / 任务层）；隐藏巡逻 **61.3**、显示 **60.2**，A/B 成本约 **1.1 FPS**。走位实测最小间距：水池 6.38m、石圈 3.33m、石像 3.32m、拱柱 1.72m（验收阈值 4.8 / 2.6 / 1.8 / 1.0）。
- **结论**：三名角色能持续巡逻、到点驻足做各自的动作；提灯人夜里有一团跟着走的暖光，扫园人绕石圈扫地、小狐在废墟边小跑，园子明显“活”了。低分辨率下斗笠/长袍/扫帚/尾巴的剪影可读；但广角镜头里人物只有十几像素，主要靠灯笼光点辨认。
- **遗留/下一步**：
  - NPC 还没有避让玩家/妖灵、点击互动（打招呼/让路）、或跟随玩家的行为。
  - 路线是手工固定闭环；若要自由巡逻需接 A* + 局部避障。

## 轮次 6 · 2026-10-31 · Cycle 1 多职能协作：提灯守夜人换 KayKit Rogue

## 轮次 7 · 2026-10-31 · 非像素风格 + Cycle 2 角色管线统一

- **用户决策**：不喜欢像素风 → 去掉 640×360 + NEAREST 的像素化输出。
- **渲染切换**：
  - 内部 **960×540 + `TEXTURE_FILTER_LINEAR` 放大 + MSAA 2×**（先试 1280×720，实测 51.7 FPS 被否）。
  - 后处理移除像素对齐/抖动（`post_process.gdshader` 直接采 UV）；相机去掉 0.04/0.02 像素吸附。
  - KayKit / Fox 贴图从 Nearest+Mipmap 改为 **Linear+Mipmap**。
- **Cycle 2 角色**：
  - 扫园人 → **KayKit Rogue_Hooded**（CC0，同骨架/同图集），保留程序化扫帚（跟手），驻足播 `Interact`。
  - 小狐 → **Khronos glTF Fox**（CC0 + CC-BY 动画），缩放 0.0085（约 1.3m 长），Walk / Survey，`yaw = PI`。
  - 提灯人 → 灯笼改挂 **右手 `handslot_r`**，驻足播 `Spellcast_Raise`（举灯意图）；WALK 回 `Walking_A`。
  - 三人都保留程序化回退（`GARDEN_FORCE_PROCEDURAL=1`）。
- **指标**：960×540 + MSAA 2× 实测 **avg 63.3 / min 52**（1280×720 窗口、关 vsync、本机负载噪声）；无头/探针/回退待 QA 复验；狐狸约 1.3m，比例与朝向已实测。
- **效果素材**：`patrol_lantern_dusk/night.png`（非像素近景）、`patrol_sweeper.png`（Rogue_Hooded + 扫帚）、`patrol_fox.png`（glTF Fox）、`cycle2_mixed_cast.png`（Rogue + Rogue_Hooded + 小女孩）、`cycle2_960x540.png`（内部源画面）。
- **结论**：画面从像素块变成柔和 3D，两名人类 NPC 统一到同一骨架/材质管线；小女孩仍是程序化模型，是当前同框最大的风格差。
- **遗留**：材质密度/纹理、广角剪影（灯杆/暖光区）、受控性能复测、小女孩模型；美术/QA 复评分见 `docs/agency/cycle-2/`。
- **相关文档**：`docs/agency/cycle-2/01-brief.md`、`02-art-review.md`、`03-qa-verify.md`；`README.md` 渲染段落。
