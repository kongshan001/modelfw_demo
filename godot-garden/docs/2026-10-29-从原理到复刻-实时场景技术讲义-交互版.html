§01

实时渲染的最小模型

引擎无关

一帧 = 逻辑更新 → 裁剪 → Draw Call → 顶点 → 光栅化 → 片元 → 深度/混合 → 后处理 → 显示。理解这条链，后面所有优化/踩坑都能定位。

CPU

Draw Call

CPU 告诉 GPU“画什么”的指令。数量受节点/材质/状态切换影响。几千株草如果各一个节点，CPU 先爆；实例化把同样网格合成一次提交。

GPU

顶点 vs 片元

顶点着色器按顶点跑，负责位置/风摆/varying；片元着色器按像素跑，负责颜色/光照/discard。降低分辨率省的是片元，不是顶点。

Render Target（离屏渲染）

把 3D 场景先画到一张纹理上，再显示/后处理。像素化、Bloom、小地图、反射都靠它。低分辨率 RT 是“像素风 + 性能”的核心。

色彩空间

贴图 sRGB → 采样转线性 → 光照/混合在线性 → Tonemap → 输出 sRGB。颜色发灰/发黑/过曝，先查这条链，再查参数。

渲染状态

cull（背面）、depth（深度写/测）、blend（mix/add/mul）、unshaded。草要双面、萤火要加法、光柱不写深度。

练习 01：用任意引擎创建 640×360 RT，Point/Nearest 显示；用 Profiler 找到场景 Draw Call 数，指出最大的三个来源。
§02

像素化管线：低分辨率 + 最近邻 + UI 分离

可交互

像素风不是全屏马赛克。正确做法：3D 世界渲染到低分辨率 RT，NEAREST 放大；UI 在 RT 外保持高清；相机吸附减少爬行；后处理对齐源像素。

内部渲染：160×90 → 显示 560×315
默认 NEAREST：硬边像素。拖动滑杆改内部分辨率，观察像素块和细节。

原理与参数

  • 分辨率：640×360 到 1920×1080 是 3×；非整数倍会让像素大小不一致。
  • 过滤：NEAREST/Point；LINEAR 会柔化像素边缘。
  • UI 分离：UI 不进入 RT，否则文字会被放大成马赛克。
  • 相机吸附：world_per_pixel ≈ view_height / render_height；pos = round(pos/snap)*snap。太粗跳格，太细闪烁。
  • 后处理：在 RT 内做；或在放大图上把 UV 对齐源像素中心，见下。

§03

光照与颜色：三盏方向光 + 环境

暖直射 / 冷天光

黄昏不是“整体染橙”。正确结构：暖色直射光 + 冷色环境/补光 + 曝光/Tonemap。亮部暖、暗部冷，物体才有体积。

SUN

主光

方向光，暖橙→暖白；负责长阴影和高光。正午约 70°，黄昏约 25°。

MOON

夜光

冷蓝方向光，低能量；负责夜间轮廓。开阴影会显著吃性能。

FILL

补光

冷蓝，无阴影；专门抬暗部，避免“夕阳一落就死黑”。

diffuse = albedo * max(N·L, 0) * lightColor * intensity
specular ≈ pow(max(N·H, 0), shininess) * specColor
H = normalize(L + V)

§07

水面：噪声、Fresnel、高光、假反射

一层 plane 的视觉

水面不是流体模拟，是一个平面 + shader。核心：深/浅色、噪声波纹、Fresnel、太阳高光、岸边泡沫/反射。

float fresnel = pow(1.0 - max(dot(N, V), 0.0), 2.2);
vec3 col = mix(deep, shallow, 0.22 + fresnel*0.4 + ripple*0.1);
col += glint * pow(max(dot(reflect(-L, N), V),0.0), 70.0);
col = mix(col, deep, depth*0.35);

Fresnel

视线越平，反射越强；远处水面更亮/更像镜子，垂直看更透明/深色。

反射

真平面反射/SSR 贵；假反射用环境色/渐变 + 岸边光斑，低端机足够。

引擎水面做法注意
GodotShaderMaterial + 平面/三角扇透明排序；不透明水面更稳
Unity URPShader Graph/HLSL；Water 插件（HDRP）Planar Reflection/SSR 成本
UnrealWater 插件/自定义材质 + Fresnel/ReflectionLumen/Planar Reflection；移动端降级
Three.jsShaderMaterial + 噪声/Fresnel + Reflector透明排序/深度写
坑：透明排序错；没有法线扰动像塑料板；Fresnel 反了；泡沫整圈均匀像霓虹环。
练习 07：写水面：两层噪声 + Fresnel + 高光；加噪声打断的泡沫环；比较假反射/真反射。

粒子与萤火：GPU 粒子、Billboard、加法

220 只萤火

粒子 = 发射器 + 生命周期 + 颜色/大小曲线。萤火：小、黄绿、加法、Billboard、夜里出现。

发射与生命周期

出生位置/速度、生命周期、颜色渐变、大小曲线；预 warm 让进入夜晚立刻有萤火。

渲染

Billboard 面向相机；加法混合；径向渐变 alpha；通常不写深度。

练习 08：100 只萤火：黄绿、加法、径向渐变，夜里出现白天消失；color ramp 做忽明忽暗。
§09

体积光与大气：真体积 vs 假光柱

丁达尔效应

真体积光 = 体积雾/光线步进；假光柱 = 一个面向相机、沿光线方向的半透明面片。低分辨率下假光柱足够“像”。

right  = dir.cross(to_cam).normalized()
normal = right.cross(dir).normalized()
basis  = Basis(right, dir, normal)
mesh.global_transform = Transform3D(basis, anchor + dir*length*0.5)

假光柱

Quad 局部 Y 对齐光线，Z 对齐相机；Additive；边缘/两端淡出；放在背景树冠处，数量少、alpha 低。

真体积

Unreal Volumetric Fog + Light Shaft 最容易；Godot Forward+ 体积雾；Unity HDRP/自定义；成本高。

坑：面片太大/正对镜头变成斜条纹；没有深度测试穿树；Additive 叠加发白；雾不随时间变色。
练习 09：4 条夕阳束 + 1 条月光束，两端淡出；在 Unreal 用 Volumetric Fog 做同效果并比较成本。
§10

后处理：Bloom、调色、暗角、抖动

最后 10% 的质感

后处理链：亮部柔光 → Tonemap → 调色 → 暗角 → 抖动/量化。低分辨率像素风要注意：dither 必须在源像素格上，不能在全屏放大图上做。

// 8 tap 亮部柔光
base += bloom * u_bloom * 0.55;
// 暖/冷分级
base = mix(base, base*vec3(1.04,0.99,0.92), u_warm*0.16);
base = mix(base, base*vec3(0.9,0.96,1.05), u_night*0.3);
// 暗角
base *= mix(1.0-u_vignette, 1.0, smoothstep(0.82,0.22,length(UV-0.5)));
// CanvasItem shader 挂在显示 RT 的 TextureRect 上
vec2 cell = floor(UV * vec2(640.0,360.0));
vec2 uv = (cell + 0.5) / vec2(640.0,360.0);
vec3 base = texture(TEXTURE, uv).rgb;
// URP：Volume 负责 Bloom/Tonemap/Color Adjustments/Vignette
// 自定义后处理：ScriptableRendererFeature + ScriptableRenderPass
// 或 URP 14+ Full Screen Pass Renderer Feature + Shader Graph
// 注意 renderPassEvent / HDR / MSAA
// Post Process Material（Domain = Post Process）
// SceneTexture:PostProcessInput0 采样场景
// 做 Bloom/调色/暗角，输出 Emissive Color
// 加到 Post Process Volume 的 Post Process Materials (Blendable)
// 注意与 Tonemap/Exposure 的先后顺序
const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));
composer.addPass(new UnrealBloomPass(new THREE.Vector2(w,h), 0.6, 0.4, 0.85));
composer.addPass(new ShaderPass(vignetteShader));
composer.addPass(new ShaderPass(colorGradeShader));
composer.render();

练习 10：加 Bloom + Vignette + 调色，比较顺序；在低分辨率 RT 内做 dither 再放大；用 LUT 做黄昏/夜晚。
